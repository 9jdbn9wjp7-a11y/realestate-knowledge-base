## 阶段一：投标策划与三档方案定位（7 月底 – 8 月）

- 三档差异化方案（高 / 中 / 低档，各主备场）：
  - 高档：西岸 WEST BUND（主）/ 衡复（备），联动上海旅游节
  - 中档：徐家汇书院（主）/ 西岸 WEST BUND（备），联动书院 YUE 汇趣市集
  - 低档：徐汇滨江（主）/ 徐家汇商圈（备），联动上海购物节
- 主视觉统一「链接价值·筑造未来」红色中式手写书法体 + 新中式红灰——**此 slogan 是 JST 的，已禁用**
- 隐性底牌：真实活动＝「徐汇 唐韵中秋」，提案不点破，仅以灯笼 + 中秋作隐性主题
- 9 月场地落定：桂林公园 5 游戏 100㎡ + 龙华会展示 100㎡（备选日晖港广场 / 党群服务中心前广场约 300 平；西岸主推西岸美术馆北广场）

**注意事项**
- 投标期主视觉 slogan 与 JST 绑定，执行方案里必须彻底清除（见 [[04_坑点与血泪注意事项]]）
- 三档方案差异要明显（场地 / 联动节庆不同），但底牌「唐韵中秋」全程不点破
- 研究库 26 篇案例已提炼「福彩 + 文旅」可复用模块，投标站位＝「上海福彩经验升级版」而非从零起步

## 阶段三：双会场落地与空间内容分工（9/14）

**要点**
- 桂林公园＝唐韵主会场（室外），场地名「**水岸雅集区**」；龙华会＝福彩侧并列会场（室内）
- 龙华会现场三处展示面（颜色标注纠正后，见 [[04_坑点与血泪注意事项]] 空间搞混）：
  - **蓝 1–5 静态（前厅）**＝内容主力五面：
    ① 公益金科普三问（官方三问结构）② 责任彩票五知晓（官方五条）③ 上海年度公益金数据（沿用既有年度立牌 / 索源）④ 公益金资助项目受益案例（扶老 / 助残 / 救孤 / 济困，用「公益福彩 关爱儿童」等专题图）⑤ 公益金使用领域分布图（与③「数据 + 故事」互补）
  - **绿 1 动态 LED（中间过渡区）**＝滚动视频（公益宣传片 → 主视觉动态 → 活动信息 → 数据可视化）
  - **黄区 静态（另一侧）**＝形象位（大画面 + 主题「福满申城·唐韵中秋」+ 福彩标识 + 打卡背景），不放公益金科普
- 蓝 1–5 原规划含「联名叙事与标识署名」，9/14 用户撤销该面 → 换公益金受益案例
- 龙华会为唐韵物理分会场 → 展示面**仅用福彩标识，不出现唐韵联名 logo**

**注意事项**
- 同一内容只出现一次（公益故事只在蓝 1–5 讲一遍；绿 LED、黄区不重复）
- 黄区不放需久读图文，只放一眼接受内容 + 打卡
- LED 是唯动态位，片单要排满循环
- 桂林公园户外按蓓娥反馈：**不写红为主**，米白 + 暖光为主调、福彩红仅点睛
- 龙华会三款游戏须「独立设计」，严禁写「复刻 / 照搬桂林同款」

- 三张福彩官方宣传板照片（9/14）确认既有口径：公益金科普三问 / 责任彩票五知晓 / 2025 年度数据 A 字立牌 / 福马献瑞 / 随手公益 乐在上海
- 产出三份交付：

  - 需福彩提供的宣传资料清单 v1.0（25 项底稿）
  - 展示面内容规格模板 v1.0（蓝 1–5 逐面金句 / 正文 / 配图标准）
- 展示面规格模板是用户**主动授权**给福彩的交料标准（单面＝金句≤16字 + 正文 100–200 字 + 配图 1–3 张 + 落款 + 可编辑格式）

**注意事项**

- 清单里「两方标识署名组合」已删除（不出现唐韵 logo）
- 「一、品牌基础与使用规范」福彩已给过，标注已提供不再追

## 阶段五：对外洽谈与文件规范

**要点**
- 乙方写政府 / 业主方公文：政务正式腔、用「我方」；「商请 / 请」；禁「拟请 / 恳请 / 希望愿以」
- 严禁暗示补缺（补强 / 充实 / 注入底色 / 相得益彰 → 改用「与既有…呼应 / 相互成就」）
- 去「政绩 / 痛点」字面，用「公益底色 / 文旅融合 / 共建共治共享」
- A-E 批判框架：判断前过 A 前提 B 依据 C 风险 D 结论 E 缺什么

**注意事项**
- 我方运营资源（如残联）写内部统筹，不请对方协助对接
- 公文标题铁律：写清「我方商请 + 致送对象」，文种用对（如「商请函」而非「清单」）
- 更多铁律见 [[02_铁律速查·品牌文案视觉排版]]
