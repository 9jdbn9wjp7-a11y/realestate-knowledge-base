# 04 坑点与血泪注意事项

> 反复踩过的雷，下回直接避。关联 [[02_铁律速查·品牌文案视觉排版]]。

---

1. **JST slogan 混入**
   「链接价值·筑造未来」是 JST 宝山新厂房奠基仪式的 slogan，多次误入福彩方案。
   → 任何福彩 / 唐韵中秋方案**禁用**；主题用「福满申城·唐韵中秋」+ 灯笼 / 福彩红。

2. **发行宗旨错写**
   v1.6(1)(1) 写"敬老、助学、助残、济困"。
   → 正确＝**扶老、助残、救孤、济困**；凡公益金去向 / 受益群体处仅此四词。

3. **雅黑泄漏**
   早期工具链错写"中文 Microsoft YaHei"，导致正文全落回雅黑小字，每次要浪费时间调格式。
   → 每段 `set_run_font` 显式设 `eastAsia`/`ascii`/`hAnsi`；自检雅黑 0 泄漏（用 `para._p.iter(qn('w:r'))` 后代搜索，find 只查直接子节点会漏）。

4. **主题前后不一致**
   曾混用福满江南 / 福满申城、唐韵在前 / 福彩在后。
   → 统一 **福满申城·唐韵中秋**，福在前；详见 [[03_方案版本迭代史v1.0到v2.0]] 主题定稿节点。

5. **场地命名错**
   桂林公园误写"东园市集 / 市集区"。
   → 正确＝**水岸雅集区**，禁东园市集 / 市集区。

6. **空间区域搞混**
   把平面图上的「1–5 展示面」与那块单独 LED 屏当成同一区域。
   → 三处分离：蓝 1–5 前厅静态、绿 LED 中间过渡区动态、黄区另一侧静态（见 [[01_项目全流程·各阶段要点与注意事项]] 阶段三）。

7. **联名标识过度**
   曾规划"联名叙事与标识署名"独立面、两方标识组合。
   → 龙华会为唐韵物理分会场，**仅用福彩标识**，唐韵不出现；清单里"两方标识署名组合"已删。

8. **误套食安框架**
   把食安展板硬框架（金句≤16 + 简说 100–150 + 配图 1–2）套进福彩展区 12 板块。
   → 福彩不默认套；给福彩出"交料模板"是用户**主动授权**，与误用两码事。

9. **复刻表述**
   龙华会游戏曾写"复刻桂林同款"。
   → 必须"独立设计"，禁复刻 / 照搬。

10. **价格口径**
    供应商报价表误进方案。
    → 方案只写市面参考价，标"非采购价"；报价表是内部成本底稿，不进方案。

11. **桌面 vs workspace lineage**
    桌面 v1.x 与 workspace 过期 v1.x 混淆（两 lineage 并存）。
    → 改前 `ls` 按时间确认最新版；v2.0 为基线原地迭代先备份。

12. **一条意见一个文件**
    早期每次反馈覆盖同版 / 出新文件，版本乱。
    → 一次反馈一次性落版，先锁清单再出下一版。

13. **章编号错号**
    曾"3.5 打卡"落在第二章内（应为 2.x）。
    → 章节增删后同步检查编号连续性（v2.0 已修为 2.6）。

14. **客户诉求未闭环**
    客户 5 条诉求中「5 店联动 / 福彩盲盒数量」未进方案，待确认：店是商场门店还是福彩网点、"买送"的"买"指什么、盲盒预算。
    → 收到诉求先发群里回应稿，进方案前必须确认前提，避免凭空编造。
