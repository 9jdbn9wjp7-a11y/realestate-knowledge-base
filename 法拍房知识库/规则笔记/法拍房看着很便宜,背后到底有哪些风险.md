# 法拍房看着很便宜，背后到底有哪些风险

相信最近很多买房子的朋友都发现，法拍房越来越多了，中介们也是极力推荐法拍房，说拿下就能便宜几十个。

那法拍房到底是怎么回事？说白了，法拍房，就是法院强制执行拍卖的房子。价格经常比市场价低一大截，不少人想着捡漏。但便宜不等于白捡，坑特别多，普通人没搞清楚，很容易踩大亏。

# 第一大风险：房子不一定能顺利收房

这是法拍房最常见的麻烦。

有的房子里面还有原房主、老人或者租客住着。就算你竞拍成功，拿到房产证，人家不肯搬走，你不能自己强行换锁、赶人。

需要再走法院强制执行腾房流程，周期少则几个月，有的拖一两年。花了钱，拿了房产证，却住不进去。

还有“长期租约”，如果存在合法有效的长期租赁（如果签个十年八年），买卖不破租赁，就算你拍下来也得继续让别人住。

# 第二大风险：隐形债务、欠费要买家承担

拍卖公告写的只是房价，但很多隐藏费用不会写全。

原房主欠的物业费、水电费、燃气费、供暖费，有的需要新买家补齐。

部分房子有高额拖欠，几年累积下来，一笔就是几万甚至十几万。这笔钱是额外多出的成本，要算进买房预算里。

# 第三大风险：房屋情况看不见，不能实地仔细看房

多数法拍房，只能短暂看一眼外部，不能进屋仔细查验。

里面墙体开裂、漏水、管线老化、违建改造，你竞拍之前不一定能发现。等过户拿到手，才看到各种问题，维修全部自己掏钱。

# 第四大风险：贷款不一定好批，要准备大量现金

很多人以为可以正常按揭贷款买。

部分法拍房要求短时间内付清全款，时间卡得很紧。就算支持贷款，审批流程特殊，万一贷款批不下来，保证金直接没收，损失很大。

# 第五：也不是全都不能买，什么样可以碰

不是说法拍房一概不能买，适合懂行、时间充足，能承担风险的人。

普通人想买，一定要做好几件事：

1.  认真读完整拍卖公告，把欠费、租赁情况全部看清楚；

2.  尽量实地了解，打听房子里面有没有人居住；

3.  提前咨询法院，确认法院是否负责腾退房屋；

4.  预留一笔额外资金，用来补交各类欠费和维修；

5.  提前确认能不能办贷款，不要赌审批结果。

# 最后

法拍房的低价，很多是把风险折算进去的。

看着省几十万，如果遇到腾房难、巨额欠费，最后反而亏更多。普通刚需家庭，没有足够经验，不建议盲目冲法拍房捡漏。毕竟房子是大部分普通家庭的重资产。
