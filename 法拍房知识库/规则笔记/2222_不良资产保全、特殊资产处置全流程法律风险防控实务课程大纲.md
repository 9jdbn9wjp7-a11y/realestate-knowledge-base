 **讲师：王文博**

**课程基本信息**

**课程名称**：不良资产保全与特殊资产处置法律风险识别、规避与胜诉实操
**授课对象**：银行资产保全部、风险合规部、法务人员、支行行长、清收专员、不良处置经办人员
**课程时长**：一天
**课程目标**：

1. 系统识别不良从【逾期→保全→诉讼→执行→处置→重组→转让】全链条法律漏洞

2. 规避大量银行败诉、执行落空、债权灭失、处置无效典型风险

3. 结合民法典、新公司法、执行司法解释、金融监管新规重塑处置合规体系

4. 掌握穿透追责、资产锁定、瑕疵补救、败诉逆转的实操方法

**第一章****课程导入：当前银行不良处置最大的法律困境（****2025-2026** **最新司法趋势）**

**1.1** **近年银行不良处置四大变化**

1. 法院对金融机构审查**越来越严**（程序瑕疵直接驳回起诉）

2. **新公司法落地**，逃废债方式全面升级，传统清收手段失效

3. 执行难、财产隐匿、关联转移、恶意注销成为常态

4. 监管对不良处置合规、低价处置、程序瑕疵**双罚加重**

**1.2** **银行不良处置高频败诉、回款失败核心原因（法律层面）**

1. 诉讼时效中断瑕疵、催收不规范导致**债权丧失胜诉权**

2. 保全不及时、保全错误、查封顺位风险导致**无资产可执行**

3. 担保效力瑕疵、签字瑕疵、决议瑕疵导致**担保彻底作废**

4. 企业人格混同、抽逃出资、未实缴股东未穿透追责

5. 处置程序不合规导致**抵债无效、转让无效、撤销处置**

6. 催收行为不当引发**名誉侵权、软暴力投诉、消保败诉**

**第二章****不良资产【逾期保全阶段】法律风险点（最容易踩坑）**

**2.1** **逾期催收法律风险（全行最高发败诉点）**

1. 催收主体、催收方式、催收频次**合规边界**

2. 禁止软暴力、骚扰第三人、曝光隐私、上门围堵法律红线

3. 微信 / 短信 / 电话催收**证据有效性与无效情形**

4. 催收话术不当导致客户起诉侵权、银行赔偿案例

**2.2** **诉讼时效中断法律风险（致命风险）**

1. 口头催收、单方记录、无回执**不能中断时效**

2. 催收对象错误（催员工、催第三方、催错人）失效风险

3. 批量催收、集中模板催收被法院认定**未有效送达**

4. 失联客户、注销客户、地址变更客户时效补救方法

**2.3** **诉前保全、诉中保全法律风险（处置最大漏洞）**

1. 保全申请错误、超范围保全、超额查封赔偿风险

2. 保全不及时，资产被先行查封、转移、变卖

3. 轮候查封、首封处置权、分配顺序法律风险

4. 保证金、担保不足导致保全失败

5. 查封后未及时起诉、未及时续封导致**自动解封资产流失**

**第三章****不良诉讼审理阶段法律风险（大量银行败诉根源）**

**3.1** **借款合同、担保合同效力瑕疵风险**

1. 格式条款未提示、利率约定瑕疵、复利罚息无效风险

2. 面签瑕疵、代签、漏签、异地签字导致合同不生效

3. 借新还旧、重组续贷**担保人免责风险（极高频败诉）**

**3.2** **公司担保决议法律风险（新公司法重点）**

1. 无股东会决议、决议瑕疵、越权担保导致**担保无效**

2. 章程限制担保限额未审查风险

3. 母子公司互保、关联担保、一人公司担保特殊风险

**3.3** **夫妻共同债务、配偶担保法律风险**

1. 单方担保未配偶知情 → 担保可撤销

2. 家事代理边界、个人债务与夫妻共同债务区分

3. 离婚转移财产、假离婚逃债司法应对

**第四章****强制执行阶段核心法律风险（执行落空、无财产可执行）**

**4.1** **被执行人财产查询与漏查风险**

1. 仅查房产车辆，遗漏**股权、理财、债权、支付宝微信、公积金**

2. 未查历史流水，遗漏转移资产线索

**4.2** **恶意转移资产、低价转让、无偿赠与撤销权风险**

1. 可撤销交易的法定情形、时间节点、举证要求

2. 银行大量「明知转移却无法追回」典型案例

**4.3** **拒执罪适用难点与法律风险**

1. 哪些情形可移送拒执罪

2. 证据不足导致公安不予立案的常见原因

**4.4** **终本案件法律风险（最大隐形不良风险）**

1. 终本≠终结，长期不跟踪导致财产灭失

2. 终本后恢复执行、续查财产规范流程

**第五章****新《公司法》下特殊资产穿透处置法律风险（****2026** **最新重点）**

**5.1** **未实缴股东追责风险与操作漏洞**

1. 不会加速到期、不会追加股东导致追偿失败

2. 认缴期限过长企业漏判风险

**5.2** **抽逃出资、瑕疵出资追责法律漏洞**

1. 无法识别抽逃行为、不会取证

2. 协助抽逃的董监高、财务人员追责遗漏

**5.3** **公司人格混同（横向** **+** **纵向）处置风险**

1. 关联公司混同但未一并起诉

2. 混同证据不足导致法院不支持连带责任

**5.4** **企业恶意注销、简易注销逃废债处置风险**

1. 注销后不知道可以追责股东

2. 遗漏清算义务人追责路径

**第六章****特殊资产处置合规法律风险（抵债、重组、转让、盘活）**

**6.1** **以物抵债法律风险（银行最高频违规点）**

1. 流押流质禁止条款违规风险

2. 抵债价格过低、程序不合规被监管处罚

3. 未过户、未占有、未公示导致抵债资产被查封

**6.2** **债务重组、展期、减免本金利息法律风险**

1. 违规减息、违规展期导致履职追责

2. 重组后担保人脱保法律风险

3. 虚假重组、借新还旧掩盖不良合规风险

**6.3** **不良资产批量转让法律风险**

1. 转让程序瑕疵、评估瑕疵、公告瑕疵

2. 禁止转让资产、限制转让资产识别

3. 转让后追索权保留、丧失风险

**6.4** **资产招商盘活、出租、处置残值法律风险**

1. 处置程序不公开、不合规引发追责

2. 出租收益归属、抵质押优先级冲突

**第七章****破产程序中银行债权处置法律风险（极易吃大亏）**

1. 未及时申报债权 → 丧失分配资格

2. 优先受偿权申报瑕疵导致降为普通债权

3. 重整方案表决失误导致**大额债权打折清零**

4. 破产撤销权、无效行为对银行存量业务冲击

**第八章****不良处置员工履职风险与尽职免责边界（保护员工）**

**8.1** **不良处置中个人追责高频情形**

1. 保全拖延、诉讼延误、证据丢失

2. 违规处置、低价处置、私下沟通债务人

3. 放弃债权、放弃担保、错误签字

**8.2** **尽职免责完整留痕体系（员工自我保护）**

1. 全流程留痕清单

2. 无法履职、客户恶意逃债的证据固化方式

3. 监管认可的免责依据

**第九章****典型败诉、处置亏损案例复盘**

1. 时效瑕疵彻底丧失债权案

2. 担保决议瑕疵担保无效案

3. 简易注销企业无法追偿案

4. 股东零实缴未穿透追责案

5. 以物抵债程序不合规被撤销案

6. 催收不当消保败诉赔偿案

7. 终本后资产灭失追责员工案

**第十章****全流程法律风险防控标准化操作清单（落地工具）**

1. 逾期催收合规清单

2. 时效保全合规清单

3. 诉讼材料瑕疵自查清单

4. 强制执行财产线索核查清单

5. 新公司法穿透追责核查清单

6. 抵债、重组、转让合规操作清单

**课程总结**

1. 不良处置最大风险不是 “没钱”，而是**法律程序瑕疵** **+** **权利行使不规范**

2. 新法环境下，清收从「跟债务人要钱」变成「穿透全链条追责」

3. 标准化合规处置，是提升回款、避免败诉、保护员工的唯一途径
