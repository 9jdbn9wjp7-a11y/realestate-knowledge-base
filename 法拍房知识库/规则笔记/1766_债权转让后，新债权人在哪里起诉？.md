# 债权转让后，新债权人在哪里起诉？
> 公众号: 谢律成都说
> 发布时间: 2026年10月3日 06:00
> 原文链接: https://mp.weixin.qq.com/s?src=11&timestamp=1791272595&ver=7009&signature=DzJq-ZOWeK6wgHrFHkpR3MPUY4h3fG9qlZZSk9U01MsAv4ws4RQajMjbnvKx1IfBUyv6ESHsH6sCUM9A1eByl2h7I1bKelxGUqMaAUHAr1Sr5exPnJCqpr7m7CNQnNMx&new=1

债权转让后，新债权人能不能随便挑个方便的法院起诉原债务人？很多人觉得：债权已经转到我手里了，我作为原告，当然可以按我的住所地或者我主张的履行地来选管辖法院。法院的态度却很明确：不行。

人民法院案例库入库案例（入库编号：2024-01-2-103-006）丁某平诉莫某江、顾某华民间借贷纠纷案给出了清晰规则：债权受让人对基础合同债务人提起诉讼的，应当依据原合同当事人确定“接收货币一方”所在地。债权转让不会改变原债务人的管辖利益，合同履行地仍按原借贷合同和原合同当事人来确定。

本案与前几篇讨论的实体责任认定不同，核心转向程序问题中的管辖确定，特别是债权转让这一常见操作对“合同履行地”判断的影响。

# 一、案情回顾：债权转让后，受让人在普陀区起诉

案外人丁某国与莫某江、顾某华于2018年5月25日签订《个人借款合同》，约定莫某江、顾某华向丁某国借款100万元。后丁某国将债权转让给丁某平，并通知了莫某江、顾某华。截至2019年5月25日，莫某江、顾某华尚欠到期借款本金50万元。丁某平遂向上海市普陀区人民法院起诉，请求判令莫某江归还借款本金并支付利息，顾某华承担连带责任。

上海市普陀区人民法院审查后认为：丁某平系债权受让人，应依据原民间借贷合同确定合同履行地。现合同履行地与被起诉人住所地均不在该院辖区，该院对案件并无管辖权。遂于2019年6月27日作出（2019）沪0107民初13686号民事裁定，对丁某平的起诉不予受理。

# 二、真正争议：债权转让后，合同履行地怎么定？

本案争议焦点不在债务是否存在，而在债权受让人起诉原债务人时，合同履行地应如何确定，进而决定哪个法院有管辖权。

《中华人民共和国民事诉讼法》（2017年修正）第二十三条规定：因合同纠纷提起的诉讼，由被告住所地或者合同履行地人民法院管辖。

《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第十八条第二款规定：合同对履行地点没有约定或者约定不明确，争议标的为给付货币的，接受货币一方所在地为合同履行地。

法院生效裁定认为：本案系民间借贷纠纷，应由被起诉人住所地或合同履行地人民法院管辖。起诉人丁某平系债权受让人，应依据原民间借贷合同确定合同履行地，故本案合同履行地为原民间借贷合同接收货币一方即案外人丁某国住所地。因被起诉人住所地不在上海市普陀区人民法院辖区，且起诉人未提供证据证明案外人丁某国的住所地在上海市普陀区人民法院辖区，故上海市普陀区人民法院对本案无管辖权。

# 三、裁判规则：履行地仍按原合同当事人确定

裁判要旨明确：债权转让后，债权受让人起诉原债务人的，合同履行地应当依据被转让的基础合同确定。基础合同没有明确约定合同履行地的，应当依据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第十八条第二款规定，并结合民事合同性质、起诉主体、当事人诉讼请求所指向的合同义务等确定合同履行地。

债权转让后，债权受让人虽享有原合同债权人的权利，但债务人的利益（包括程序上的管辖利益）不应因债权转让行为而遭受损害；故合同履行地（包括接受货币一方所在地）与案件管辖法院仍应当按照原合同和原合同当事人确定，不能以债权受让人（新债权人）作为合同当事人来确定合同履行地。

这一规则的核心在于保护债务人的管辖利益。债权转让是债权人单方处分债权的行为，债务人被动接受通知后即成为新的权利相对人，但其原本享有的管辖便利不应因这一转让而发生不利变动。因此，即便新债权人起诉，接受货币一方仍指向原合同中的债权人，而非受让人。

# 四、律师提醒：转让后起诉，管辖仍看原合同

对债权受让人而言，受让债权后起诉原债务人，不能想当然地以自己的住所地作为“接受货币一方所在地”来主张管辖。应先核查原借贷合同是否约定了履行地；若未约定或约定不明，则需查明原债权人住所地，并结合被告住所地综合判断管辖法院。起诉前务必核对管辖连接点，避免因管辖错误被裁定不予受理或移送，浪费时间和诉讼成本。

对债务人而言，收到债权转让通知后，管辖利益并不当然发生变化。若新债权人选择明显不便利的法院起诉，可依法提出管辖权异议，主张仍应按原合同当事人确定履行地。保留原合同文本、转让通知等相关证据，有助于在管辖争议中明确抗辩依据。

对原债权人而言，转让债权时虽无义务主动告知受让人管辖细节，但实务中建议在转让协议中适当提示原合同履行地或管辖约定情况，减少后续因管辖问题产生的沟通成本。

# 结语

本案的核心，不是“债权转让后新债权人可以任意选择管辖法院”，而是“合同履行地仍应依据原合同及原合同当事人确定，债务人的管辖利益不因债权转让而受损”。

人民法院案例库入库案例（入库编号：2024-01-2-103-006）丁某平诉莫某江、顾某华民间借贷纠纷案告诉我们：即便债权已经转让，接受货币一方仍指向原合同中的债权人。管辖法院的确定，不能脱离基础合同本身。

债权转让是商业与民间融资中的常见操作，但程序权利的边界不会因此被打破。起诉前把管辖问题想清楚，往往比事后补救更省事。
