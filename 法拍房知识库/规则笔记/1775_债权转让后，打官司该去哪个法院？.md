# 债权转让后，打官司该去哪个法院？
> 公众号: 律界闲潭
> 发布时间: 2026年9月30日 08:03
> 原文链接: https://mp.weixin.qq.com/s?src=11&timestamp=1791272595&ver=7009&signature=qg-zIcNFARGcSPAqGloSbWlPw3Wd2IalSt3uNsk9oru3l*R1Unu68nN26vZOtIjJXf32y*GhTKbTFbvtgQyCGWunpwQcsiPxSNMU9wLaywMu7Xesjib6P2PNPO5JQ*I1&new=1

债权转让后，受让人起诉原债务人的，合同履行地应当依据原来的基础合同确定。原来的合同没有约定履行地的，接受货币一方所在地就是合同履行地。这里的“接受货币一方”，指的是**原合同中的债权人**，不是债权受让人。债务人的管辖利益不因债权转让而受损——这是本案确立的核心规则。

# 一、一个看似简单的管辖问题

丁某国借了100万元给莫某江和顾某华。后来丁某国把这笔债权转让给了丁某平。丁某平拿着这份转让后的债权，跑到上海市普陀区人民法院起诉，要求莫某江还钱、顾某华承担连带责任。

普陀区法院审查后认为，丁某平是债权受让人，合同履行地应当按照原来的民间借贷合同来确定。原合同的接受货币一方是丁某国，合同履行地就在丁某国住所地。被起诉人住所地也不在普陀区，丁某平又没证据证明丁某国住所地在普陀区。所以，普陀区法院没有管辖权，裁定不予受理。

这个裁定引出了一个实务中争议很久的问题：债权转让后，“接收货币一方所在地”里的“接收货币一方”，到底是原债权人还是债权受让人？

# 二、法律规则的基本框架

《民事诉讼法》第二十三条规定，合同纠纷由被告住所地或者合同履行地人民法院管辖。

《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第十八条第二款进一步明确：合同对履行地点没有约定或者约定不明确的，争议标的为给付货币的，接受货币一方所在地为合同履行地。

在普通的民间借贷纠纷中，出借人起诉借款人还钱，争议标的就是给付货币，接受货币一方就是出借人，所以出借人所在地就是合同履行地。这是没有债权转让时的常规操作。

但债权一旦转让，问题就复杂了：债权受让人是不是取代了原债权人的地位，成了新的“接受货币一方”？如果是，那受让人所在地就成了合同履行地，管辖法院跟着变；如果不是，那还得按原债权人所在地来定。

# 三、两种解释思路的碰撞

一种思路认为，债权转让后，受让人取代了原债权人的地位，成了新的债权人。债务人应当向受让人还钱，受让人是实际接收货币的人。所以，受让人所在地应当是合同履行地。

这种解释听起来符合“接收货币一方”的字面意思，但有个明显的毛病：它把管辖法院的确定权交到了债权人和受让人手里。债权人可以通过债权转让，把管辖法院“搬到”受让人所在地，挑一个对自己方便的法院。债务人对此毫无办法，只能被动接受。

另一种思路认为，合同履行地是合同本身的属性，不因债权转让而改变。基础合同签订的时候，接受货币一方就已经确定了。债权转让是合同权利的移转，不是合同本身的变更。受让人拿到的是原合同的权利，不是创设了一个新合同。

本案采纳的是后一种思路。裁判要旨说得很清楚：债权转让后，受让人虽然享有原合同债权人的权利，但债务人的利益，包括程序上的管辖利益，不应因债权转让行为而遭受损害。所以，合同履行地包括接受货币一方所在地，还有案件管辖法院，仍然应当按照原合同和原合同当事人来确定，不能以债权受让人作为合同当事人来确定合同履行地。

# 四、法理基础：债务人的管辖利益不能受损

本案裁判要旨里最值得琢磨的一句话是：债务人的利益，包括程序上的管辖利益，不应因债权转让行为而遭受损害。

这句话点出了一个重要的法理原则：债权转让不应让债务人的法律地位变差。

实体法上，这个原则早就有体现。《民法典》第五百四十八条规定，债务人接到债权转让通知后，债务人对让与人的抗辩，可以向受让人主张。第五百五十条规定，因债权转让增加的履行费用，由让与人负担。这些规则的目的，都是防止债权转让给债务人添麻烦。

程序法上，这个原则同样应该适用。管辖利益是债务人程序利益的重要组成部分。债务人原本可以在自己住所地或者原合同履行地应诉，这是签合同时就能预见到的。如果债权转让后，管辖法院变成受让人所在地，债务人可能被迫跑到千里之外去打官司，诉讼成本大幅增加，程序利益受到实质损害。

所以，把“接受货币一方”解释为原债权人，实质上是在保护债务人的管辖利益，防止债权转让成为债权人单方面“挑法院”的工具。

# 五、确定合同履行地要看哪些因素

本案裁判要旨还提到，基础合同没有明确约定合同履行地的，应当结合民事合同性质、起诉主体、当事人诉讼请求所指向的合同义务等来确定合同履行地。这给实务操作提供了指引。

从合同性质看，民间借贷属于借款合同，争议标的通常是给付货币。根据《民诉法解释》第十八条第二款，接受货币一方所在地是合同履行地。在债权转让情形下，接受货币一方应理解为原合同中的债权人。

从起诉主体看，起诉的是债权受让人，但他的权利来源于原合同。受让人不能因为受让行为就获得比原债权人更优越的管辖地位。起诉主体变了，合同履行地的确定规则没变。

从诉讼请求看，债权受让人起诉债务人，请求的是债务人履行原合同项下的还款义务。这个义务的履行地，应当依据原合同确定，而不是依据受让人和让与人之间的转让协议确定。

# 六、实务启示

对债权受让人来说，受让债权时应当关注原合同对管辖法院的约定或者法定的管辖规则。如果希望在自己所在地法院起诉，应当在债权转让协议里明确约定，并且让债务人确认，或者直接和债务人重新达成管辖协议。否则，受让人可能得到原债权人所在地或者债务人所在地法院去打官司。

对债务人来说，本案规则提供了程序保障。债权转让后，债务人不用担心被拖到一个完全陌生的法院应诉。管辖利益仍然依据原合同确定，不因债权转让而改变。

对人民法院来说，审查债权受让人起诉的民间借贷案件时，应当依据原合同确定合同履行地，不能以债权受让人所在地作为合同履行地。立案阶段应当要求起诉人提供原合同及债权转让的相关证据，以确定管辖法院。

# 七、结语

本案的裁判规则看起来只是个管辖问题，实际上触及了债权转让制度中一个根本性的平衡：债权人的处分自由和债务人的利益保护之间的平衡。债权转让制度便利了债权流转，但不能成为债权人单方面改变债务人程序地位的工具。以原合同和原合同当事人确定合同履行地，既尊重了债权转让的效力，又保护了债务人的管辖利益，体现了程序法对实体法秩序的维护功能。
