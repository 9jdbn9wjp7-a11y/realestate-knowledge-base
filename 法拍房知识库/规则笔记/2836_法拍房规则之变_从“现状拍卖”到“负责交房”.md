# 法拍房规则之变：从“现状拍卖”到“负责交房”

读懂司法解释与最新指导意见的叠加变化

法拍房曾是少数人的游戏。公告里一句“按现状拍卖、不负责腾退”，就把最大的不确定性留给了竞买人。

2016年，最高人民法院出台《关于人民法院网络司法拍卖若干问题的规定》（法释〔2016〕18号），把司法拍卖搬上互联网，解决的是“公开”；

2024年10月印发的《关于进一步规范网络司法拍卖工作的指导意见》（法〔2024〕238号，共12条），解决的是“规范”。

2026 年 4 月 1 日起，是各地法院**全面落地执行****指导意见**的时间节点，两者叠加，法拍房的交易逻辑正从“买者自负”转向“法院负责查清、交到手”。

# **一、拍前调查：“现状拍卖”不再是免责理由**

《指导意见》第1条把调查写成硬义务：执行法院应当调查财产现状，不得以“现状拍卖”为由免除调查职责。不动产要通过调取登记信息、实地勘察、入户调查，查清权属关系、占有使用情况、户型图、交易税目和税率、已知瑕疵；机动车查登记、违章、排放标准和行驶里程；股权查认缴实缴出资、出资期限、财务报表和股息红利。

第2条专门盯“带租拍卖”：案外人主张租赁权、居住权的，要围绕合同签订时间、租赁期限、租金支付、占有使用情况审查真实性；所提事实有悖日常生活经验和商业交易习惯的，不予支持；恶意串通倒签租约规避执行的，依法追责。

定价也有分工：有大数据的住宅、机动车可以网络询价；厂房、在建工程、股权、采矿权等议价不成应当委托评估。

# **二、披露：“占有不明”被叫停**

第6条要求全面如实披露现状、占有使用情况、已知瑕疵和权利负担，严禁隐瞒或夸大。不动产公告必须公示占有使用情况，不得再用“占有不明”“他人占用”；决定带租赁权、居住权拍卖的，要披露租金、期限和权利人情况；竞买资格限制同样要公示。

对比2016年司法解释第13、14条的“公示＋特别提示”，变化在性质：过去是告知义务，公告写明、提示到位即可免责；现在是查明义务，没查清本身就是执行不规范。信息不对称的成本发生了转移。

# **三、交付：严禁再写“不负责腾退”**

法拍房最大的痛点是“拍到了却住不进”。第8条规定：处置不动产，除法定事由外，执行法院应当负责腾退交付，严禁在公告中声明“不负责腾退”；需要腾退的，要制作腾退预案，先督促被执行人及有关占用人员搬离，仍不搬的依法强制腾退。腾退中破坏财产、妨碍执行的，可罚款、拘留，构成犯罪的追究刑事责任。

2016年司法解释第6条本就要求法院“办理财产交付”，实践中常被打折。公告里是否写明“负责腾退”，会直接影响竞买人数和成交价。

# **四、流拍之后：多一条“自己卖”的路**

按2016年司法解释第26条，流拍后应在30日内于同一平台再拍，降价幅度不得超过前次起拍价的20%，再流拍可以变卖。新规第7条加了第三种选择：二拍流拍后，债权人申请以物抵债、第三人按流拍价购买时，法院应当通知被执行人；其主张以高于流拍价自行处置的，审查后可以准许，期限一般不超过60日。

成交后买受人付清全款的，法院可出具成交过户裁定；只付部分价款、余款申请贷款的，法院协调登记机构同意后也可出具裁定，办理“带封过户”。

# **五、刑事涉财：“1元起拍”被套上缰绳**

个别法院对不动产也搞无保留价拍卖，保证金低、加价小，高价财产以明显低价成交。第5条要求：最后一次流拍，应先征询财政部门、被害人是否接收财产或以物退赔；都不同意才可无保留价拍卖。不动产、采矿权、大宗股票等高价财产确需如此处置的，须合理确定保证金和加价幅度，经合议庭合议后报院领导批准。

# **六、监督：赚“信息差”的钱越来越难**

第9条要求建立重大事项权力清单和台账：起拍价、加价幅度、权利负担、唯一住房拍卖、自行处置、以物抵债等须合议报批、院庭长阅核，不得由执行人员一人拍板。第10条收紧辅助机构：不得使用办案系统和密钥，现场看样须两名以上人员在场，机构及人员、近亲属不得竞买其经手标的，不得泄露竞买人信息。

第11条剑指“拍前调查”“清场收房”“对接法院”式高佣金服务与伪造司法文书骗财，由法院联合公安、住建、市场监管查处；第12条要求全程留痕，接受公众和检察机关监督。

# **七、买受人要做的四件事**

规则变严，不等于风险归零。

一看公告：占有使用是否写明，有无租赁、居住权，税费欠费谁承担，自己是否具备竞买资格。

二算总账：成交价之外还有契税、增值税、个税，以及物业水电欠费与腾退周期。

三守纪律：保证金为起拍价的5%至20%，竞价不少于24小时、结束前5分钟出价即顺延，悔拍保证金不退且不得再参加重新拍卖，贷款提前预审。

四留心眼：户口、学位与房屋质量，仍要自己跑一趟。

对竞买人来说，公告写得更细、腾退有人负责、资格核查更严，是今年最实在的变化。

最大的红利不是价格更低，而是公告里的每一句话，开始有人为它负责。
