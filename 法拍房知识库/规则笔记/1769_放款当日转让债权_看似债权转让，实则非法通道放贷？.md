# 放款当日转让债权：看似债权转让，实则非法通道放贷？

# 摘要

金融放贷业务属于国家特许经营范畴，未经监管批准不得经营性开展放贷业务 。实践中大量无放贷资质商事主体，通过与持牌小额贷款公司合作，采用“借款当日债权即时转让”的交易架构，以债权转让的合法外观掩盖无资质经营性放贷的实质。

本案暴露出商事主体利用债权转让制度规避金融监管的现实漏洞，也引发通谋虚伪表示与违反效力性强制性规定的规范竞合、债权转让形式审查与实质穿透边界、合同无效后的资金占用利息裁量标准、持牌机构通道责任认定等多重法律争议。本文以该案为样本，梳理裁判逻辑，剖析司法裁判中的法律分歧，提炼此类案件审查要件，为同类案件裁判、商事主体合规及金融监管提供参考。

# 一、基本案情

## （一）案件事实

蔡某某与某持牌小贷公司于2022年2月14日签订10万元《借款合同》，月利率1.2%。签约当日，小贷公司放款，同时即刻与无放贷资质的某咨询公司签署《债权转让合同》，将案涉债权转让给咨询公司，蔡某某签署债权转让通知予以确认 。

交易流程存在多处反常特征：第一，借款合同、债权转让合同于同一天完成，咨询公司后续才向小贷公司支付债权转让款；第二，咨询公司尚未支付转让对价，就已经直接收取借款人蔡某某的还款，蔡某某自借款次日起每日向咨询公司转账1400元，累计还款18200元；第三，咨询公司与该小贷公司存在长期业务合作，持续批量受让该小贷公司债权；第四，借款人直接向咨询公司履行还款义务，借款实际收益归属于咨询公司，小贷公司仅提供签约资质通道，未实质参与贷后管理、催收环节 。

咨询公司起诉，请求蔡某某偿还剩余本金81800元，并按照合同约定月利率1.2%支付利息。

## （二）一审裁判逻辑：恪守债权转让外观，认可合同效力

一审瑞安市人民法院采取形式主义审查路径：小贷公司具备合法放贷资质，借款合同合法有效；债权转让合同系双方合意达成，债权转让对债务人生效，咨询公司继受取得借款合同项下全部权利，有权按照原借款合同约定主张本金及约定利息，判决支持咨询公司全部诉讼请求 。

一审裁判思路立足于债权转让制度外观：债权属于可转让财产权利，只要债权真实存在、履行通知债务人程序，受让人即取得债权，受让人是否具备放贷资质，不影响债权转让效力。该思路也是很多同类案件的一审常见裁判观点。

## （三）二审改判逻辑：穿透交易外观，认定假借资质放贷行为无效

温州中院二审摒弃单纯形式审查，综合全案交易细节穿透交易实质：借款合同与债权转让合同同日签署、受让人未支付转让款即收取借款人还款、双方长期批量开展同类业务、还款模式存在高利嫌疑，足以证明，案涉债权转让属于虚假外观，真实交易为咨询公司借用小贷公司持牌资质从事经营性放贷业务，属于无资质主体从事特许金融业务，借贷行为整体无效。

合同无效后，依据《民法典》第一百五十七条的清算规则，借款人应当返还实际占用本金，但原合同约定月利率1.2%的利息请求不予支持；法院酌定自2022年2月28日起按年利率6%计算资金占用损失。二审撤销一审判决，部分支持咨询公司本金返还请求，驳回合同约定利息请求 。

# 二、案件核心法律争议深度解析

本案并非简单债权转让纠纷，实质是商事主体利用债权转让制度规避金融特许监管，案件折射出四大核心争议问题，也是司法实践中的裁判难点。

## 争议一：规范适用的选择——通谋虚伪表示（《民法典》第146条）抑或违反效力性强制性规定（《银行业监督管理法》第19条+《民法典》153条）

本案二审裁判说理同时援引两套规范基础，由此产生教义学层面的争议：本案究竟应当适用通谋虚伪表示，还是直接适用违反金融特许强制性规定认定行为无效 。

第一种路径：通谋虚伪表示规则。《民法典》第146条，行为人与相对人以虚假意思表示实施的民事法律行为无效，隐藏行为按照法律另行评价。本案中，小贷公司与咨询公司之间的债权转让属于“阳合同”，仅为形式；隐藏的真实行为是咨询公司实际出资、收取本息，借用小贷资质对外放贷。阳合同（债权转让）虚伪无效；隐藏行为即咨询公司直接放贷，因无资质而归于无效。该路径重点评价各方主体主观通谋、意思表示不真实，聚焦当事人内心真意与外在表示不一致。

第二种路径：违反效力性强制性规定。《银行业监督管理法》第十九条规定，未经监管机构批准，任何单位、个人不得从事银行业金融机构业务活动，该条文属于维护金融秩序的效力性强制性规定 。《民间借贷司法解释》第十三条第三项明确，未取得放贷资格主体以营利为目的向不特定对象出借资金，民间借贷合同无效。该路径无需探究当事人主观是否通谋，重点审查客观行为是否属于经营性放贷、是否违反金融特许制度，行为一旦满足客观要件即可否定效力。

本案二审裁判同时结合两套规范，也反映司法实践现实：

1.  如果仅适用强制性规定，需要证明咨询公司属于经营性放贷，即面向不特定对象、反复、营利性放贷，本案中双方存在长期批量合作，满足经营性要件；

2.  如果仅适用146条通谋虚伪，需要证明小贷公司与咨询公司存在通谋的主观合意，即双方明知债权转让只是伪装，真实目的是借资质放贷。主观内心合意难以直接举证，司法只能依靠客观交易事实推定主观通谋。

二者并非互斥关系，而是递进关系：客观反常交易事实，既可以推定双方通谋虚伪，同时该隐藏的实际放贷行为本身又违反金融特许强制性规定，两套规范可以共同支撑合同无效结论。实务中大量通道放贷案件，法官更多优先采用“客观行为违反金融强制性规定”路径，降低主观事实的证明难度，实现金融秩序保护的裁判目标。

## 争议二：债权转让制度的边界——真实债权转让与伪装通道放贷应当如何区分

债权转让本是《民法典》合同编项下合法制度，合法债权转让与本案“伪装通道放贷”的区分标准，是同类案件的裁判关键，不能因为存在债权转让即当然认定无效，也不能仅看合同文本而忽略交易实质。结合本案与各地法院同类裁判，二者区分可以归纳为五组实质审查要素：

仅仅具备其中某一项特征，不足以认定伪装放贷；需要多项要素叠加综合判断。如果仅仅单笔债权即时转让，但不存在批量业务、持牌机构承担实质风险，仍属于合法债权转让。

一审法院局限于合同文本，仅仅审查债权是否真实、是否通知债务人，忽略以上实质要素，导致裁判偏差，这也是通道放贷案件一审常见误区。

## 争议三：借贷整体无效，还是仅债权转让行为无效

本案二审的裁判结论是借贷行为整体无效，而非仅仅否定债权转让合同效力，该点存在较大实务争议。

有观点认为：小贷公司本身具备放贷资质，其与借款人之间的借款合同本身合法有效，仅仅小贷公司与咨询公司之间的债权转让合同无效；此时债权不发生移转，仍由小贷公司向借款人主张权利，借款人仍应当按照原借款合同还本付息。

二审并未采纳该观点，其核心理由在于：案涉整个交易架构，自始就是为咨询公司规避监管而设计，借款人签约、还款自始至终被纳入咨询公司的实际控制之下，整个交易链条不可分割。借款人虽然形式上与小贷公司签约，但从还款对象、交易背景看，自始即处于咨询公司实际放贷的交易闭环中，不能将借款合同与债权转让割裂评价。若仅仅宣告债权转让无效，而维持借款合同效力，等于变相纵容持牌机构出卖资质充当通道，架空金融特许经营制度。

该裁判观点的价值导向：对于持牌机构出卖资质、纯粹充当通道的完整交易架构，司法可以对整体交易做一体化评价，否定全部借贷行为效力，而不是简单切割各个合同分别评价。但该裁判思路也应当保持克制，不能无限扩张，只有持牌机构完全不承担风险、仅出卖资质通道时，才可以对整体交易否定效力；如果持牌机构实际参与风控、承担坏账风险，则不能否定基础借款合同效力。

## 争议四：合同无效后的清算规则：本金返还与资金占用利息的裁量

借贷行为被认定无效之后，根据《民法典》第一百五十七条，财产返还，过错方赔偿损失。

1.  本金必须返还：借款人实际占有资金，应当返还本金，本案一审已经将借款人归还的18200元抵扣本金，二审予以认可。

2.  原合同约定利息不予保护：因为借贷行为整体无效，合同约定月利率1.2%丧失请求权基础。

3.  资金占用损失应当支持，但计算标准存在裁判分歧。

本案二审酌定按照年利率6%计算资金占用损失，但当前司法实践存在不同做法：部分裁判采用一年期LPR，部分裁判沿用旧规采用年利率6%，少数裁判基于出借人存在重大过错，仅仅支持存款基准利率计算损失 。

法理层面，资金占用损失属于信赖利益损失，应当结合双方过错分配：无资质商事主体故意设计通道规避监管，存在主要过错；借款人明知或应当知道交易背景的，自身也存在一定过错。本案中法院没有完全剥夺资金占用损失，而是支持年利率6%，体现“不能让非法放贷主体获取合同约定高额利息，同时也不让借款人无偿占用资金”的利益平衡思路。

值得注意：不能再适用原借款合同利率计算占用费，否则等于变相保护非法经营性放贷的收益。

# 三、延伸思考：本案裁判规则的价值与制度隐忧

## （一）本案的积极裁判价值：穿透式审判遏制通道放贷

近年来，大量没有放贷资质的咨询、资产管理公司，借助小额贷款公司、地方金融组织牌照，采用“放款即转让债权”模式，绕开金融监管，批量开展经营性放贷业务，此种模式游走在法律灰色地带，极易衍生高利、暴力催收等风险 。

本案判决确立重要裁判指引：司法不能仅仅停留在书面合同，应当穿透全部交易链条，综合签约时间、资金流向、业务模式、风险承担、收益归属多重要素判断交易实质，否定借持牌资质通道从事非法放贷行为的法律效力，通过民事裁判实现金融风险的源头治理，落实金融业务特许经营原则。该裁判思路与多地高院金融审判纪要、典型案例精神一脉相承 。

同时本案对持牌小额贷款公司产生警示意义：持牌机构不得出卖牌照、充当通道，仅仅收取通道费而不实际开展业务，否则整个交易可能被司法否定效力，自身还将面临监管层面的处罚。

## （二）裁判规则适用边界：需要防止司法过度干预商事交易

该穿透裁判路径不能无限扩张，需要划定边界，避免不当干涉正常债权转让商业实践：

第一，必须区分批量经营性业务与单笔偶发债权处置。如果持牌小贷公司发放贷款之后，因为资产流转需要，偶发转让一笔真实债权，受让人并非持续从事放贷，即使转让时间较短，也不应认定伪装放贷。关键看受让人是否以放贷作为经营活动，是否面向不特定对象批量开展业务。

第二，重点考察风险由谁承担。如果持牌机构没有完全退出风险，仍然对债权承担兜底、回购之外的实质风控义务，则不构成单纯通道。只有持牌机构只提供资质盖章，不承担坏账风险，只收取通道对价，才属于本案的假借资质放贷。

第三，主观层面，不能仅凭客观交易直接推定借款人存在过错。借款人往往只是被动参与交易，很多借款人并不知晓咨询公司与小贷公司之间的私下安排，不应当苛责借款人承担过重的不利后果。

# 四、合规启示

对于商事主体：非持牌机构不得借助债权转让、合作模式变相从事经营性放贷。以债权转让为名，行批量放贷之实，借贷行为存在被法院认定整体无效风险，无法主张合同约定利息，只能主张本金以及有限的资金占用损失。

对于持牌小额贷款公司等地方金融组织：不得将牌照出借给第三方充当通道，要实质开展风控、放款、贷后管理业务，完整承担信贷风险；否则民事层面交易存在被否定效力风险，行政层面会触发监管处罚。

司法裁判层面：审理债权转让类民间借贷案件，不能仅仅审查债权真实性、通知程序，应当主动审查交易背景、批量业务情况、资金流转、风险承担，运用穿透思维；同时严格把握认定标准，区分真实资产流转与规避监管的通道业务。

监管层面：针对“放款即转让债权”的通道业务，应当强化对小额贷款公司资产流转、合作机构的监管，从源头遏制借牌照变相放贷的现象，实现民事司法与金融监管协同治理。

# 结语

通道型假借资质放贷，是金融创新背景下规避特许监管的典型交易模式。在法律适用上，通谋虚伪与强制性规定两套规范的竞合、合同是否一体化无效、资金占用利息标准，仍然存在解释空间。司法在否定规避监管交易效力的同时，也应当严守边界，区分合法债权流转与伪装通道放贷，实现金融风险防控与商事交易自由之间的平衡。
