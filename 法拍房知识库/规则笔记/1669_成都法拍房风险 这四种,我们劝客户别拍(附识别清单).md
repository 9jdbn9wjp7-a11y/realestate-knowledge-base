评估价 120 万，起拍 84 万。

便宜 36 万。

这种标的，我们在成都每个月都能碰到好几个。来问的客户，语气都差不多：

「这个价，不拍是不是亏了？」

但我们的答复，经常是三个字：**别拍。**

因为**成都法拍房风险**这件事，最难判断的从来不是「有没有风险」——每套都有。难的是分清：**哪些能解决，哪些解决不了。**

今天把我们明确劝退的四类情形，连同识别信号，一次说清。

## 一、先说结论：这四类，我们会劝退

看最后一列。①②是**钱的问题**，理论上加预算能解决；③④是**时间和流程的问题**，钱不一定能解决。

真正让我们劝退的，通常是③④。

## 二、第一类：租约查不清的房子

「买卖不破租赁」这条规则，在法拍房上被用得最多，也最容易被做局。

麻烦的不是「房子有租约」——有租约是正常的事。麻烦的是**租约的真假，你在拍前很难完全验证。**

有三种组合同时出现时，我们基本会建议放弃：

· 一次性签了十几年甚至二十年

· 租金声称已一次性付清

· 租金明显低于同片区市场价

规则上，**查封之后才签的租约，不能对抗买受人。**但这句话落到实际，是你要去举证、去提执行异议——耗的是几个月的时间和来回的精力。

所以判断标准不是「能不能赢」，是「你愿不愿意为了这套房，打一场你没准备好的仗」。

## 三、第二类：土地性质不明的房子

划拨地上的住宅，过户前要补缴土地出让金。

这一项的问题不是「贵」，是**不确定**——不同地块、不同用途，补缴比例差异可以非常大，而且要在过户前一次性缴清。

换句话说：**你在出价的时候，并不知道这套房的最终成本。**这就是我们劝退的理由——不是出不起，是没法报价。

具体怎么查、怎么算，我们那篇**成都法拍房税费怎么算**里拆过七项成本，这一步在里面是第二步。

## 四、第三类：唯一住房，腾退周期不明

前面那篇讲过，最高法明确要求：除法定事由外，执行法院应当负责腾退交付。

但请注意两件事的区别——

「法院负责腾退」是权利，
「什么时候能住进去」是时间。
这两件事，不要混为一谈。

房子是被执行人唯一住房、家里有老人或小孩长期居住、当事人配合度低——这些都会把腾退周期拉长，具体多久取决于个案，没人能提前给准话。

对自住买家来说，这个成本很具体：**你一边还着月供，一边还在租房。**这笔账在出价前就要算进去，不能等拍下来才发现。

## 五、第四类：公司产权与多轮查封

房子登记在公司名下，或者被不止一家法院查封——这两类不是不能买，是**链条太长**。

公司产权涉及企业内部决议、可能叠加的税种；多轮查封要按顺序逐个解封；如果房子还没办过产权证，还可能涉及二次过户。任何一环卡住，都是按月计的等待。

我们有句内部说法：**流程每多一环，你的时间表就要多留三个月。**

## 八、参拍前的五分钟自检

|
检查项

 |

过关标准

 |
| --- | --- |
| **租约** |

能确认签约时间在查封之后，或有明确放弃租赁的书面材料

 |
| **土地** |

确认出让 / 划拨；划拨已拿到补缴口径

 |
| **占用** |

公告表述清晰，且不含「不负责腾退」类措辞

 |
| **产权** |

权利人是个人的优先；公司产权已理清过户路径

 |
| **总成本** |

成交价 + 税费 + 欠费 + 资金成本，仍在预算内

 |

五项里有任何一项答不上来，我们的建议都是同一句：**先别出价。**

我们这一行，最难的不是帮客户买到房，
是劝客户别买。

因为劝退这一单，我们收不到钱。但客户一旦踩坑，这个行业的口碑就又少一分——说到底还是我们自己吃亏。
