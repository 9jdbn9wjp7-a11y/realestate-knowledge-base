# 建邺-乐山路99号：458轮抢到市场价9折，是捡漏还是接盘？

> 数据来源：今日头条「依然如梦」9/24 复盘文 + 阿里资产司法拍卖页
> 一句话选题：**13个人贴身互咬458轮、延时394次，最后只比市场价低1折——法拍"捡漏"的错觉有多深。**

- **拍卖平台**：阿里资产·淘宝司法拍卖（南京市玄武区人民法院执行）

- **458轮 + 394次延时**，是 9/24 当天全南京住宅标的「围观 + 轮数双第一」（13935次围观、487人设提醒、13人报名）
