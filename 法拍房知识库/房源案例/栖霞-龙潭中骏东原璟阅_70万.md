# 南京龙潭中骏东原璟阅24套法拍房70万起

> 来源：[[216_南京24套房源惨遭法拍精装大三房仅70万起]] | 2026-07-24

## 房源基本信息

- **位置**：栖霞区龙潭后曹路6号（中骏东原璟阅小区）
- **户型**：125㎡/127㎡大三房
- **起拍价**：70万-73万（单价5600-5800元/㎡）
- **原销许价**：~1.8万/㎡（备案价230万+）
- **折扣**：相当于3折甩卖
- **房源总数**：44套被移送拍卖（目前上架24套）
- **拍卖原因**：开发商与龙信建设集团工程款纠纷，执行标的5700万

## 风险提示

| 风险项 | 详情 |
|--------|------|
| 查封抵押 | 房屋有查封、抵押 |
| 房屋状况 | 长期空置、阳台未封闭、室内渗水 |
| 捡漏空间 | 起拍价比二手房成交均价（5271元/㎡）还高300元 |
| 隐性成本 | 可能拖欠物业费、水电费 |
| 板块流通性 | 龙潭距主城远，短期升值可能性低 |

## 开发商现状

南京骏原房地产开发有限公司（中骏+东原合资）：
- 161条司法案件，涉案1.86亿元
- 59条限制消费令，涉案2545万元
- 项目入网1700+套，仍有350+套未售
