# 供给缩量至17.71亿元

# 消费贷接棒信用卡挑起大梁

本周期（**2026年9月23日—9月30日**）银登中心个贷不良资产转让市场供给规模明显回落，全周共挂牌15个资产包，未偿本金合计17.71亿元，较上一统计周期（83个、196.57亿元）大幅缩量。参与主体覆盖国有大行、股份制银行、城商行、农村中小银行和消费金融公司，底层资产以消费贷、经营贷、信用卡及混合类为主。其中，消费贷以9个资产包、11.45亿元占据主导，占比64.69%；消费金融公司以4个包、6.29亿元成为单类机构最大供给方。与上周信用卡独占73.57%的结构相比，本周供给结构发生切换；同时前九月累计挂牌本金规模已达1,675.60亿元、同比增长25.48%，中长期扩张趋势未改。

# 01本周挂牌整体概况

本周共挂牌15个资产包，本金规模合计17.71亿元。供给呈现“中等规模集中、两端收敛”的特征：\[1,3)亿元区间本金占比64.06%，\[1,000,5,000)万元区间以国有大型银行为主；户均本金集中在\[5,10)万元区间，占比36.72%。本周未出现5亿元及以上超大额资产包，单包规模较上周明显收敛。从贷款类型维度拆分：

消费贷：消费贷资产包共9个，本金合计11.45亿元，占比64.69%，是本周供给的绝对主力。供给主要来自两端：一是消费金融公司集中出包，兴业消金一次性推出5期、6期、7期三个资产包，合计5.93亿元，户均本金稳定在7.38万元至8.55万元，加权平均逾期17至19个月，诉讼比例30.26%至57.84%，起拍价集中在2.97%至3.73%，为本周定价最低的一批；四川锦程消金9期则以0.92万元的超低户均本金、12.61%的高起拍价形成鲜明对比。二是城商行单包突出，河北银行4期以3.01亿元成为本周最大资产包，覆盖河北、天津、山东三地，涉及28,960户、户均仅1.05万元，加权平均逾期29.82个月、均未诉讼，起拍价7.06%。此外，国有大型银行与农村中小银行机构亦有分散供给，工商银行湖北2期（1.16亿元、户均20.78万元）、交通银行陕西1期（0.43亿元、户均3.99万元）、无锡农商行2期（0.34亿元、户均7.38万元）覆盖了不同客群层级。

经营贷：经营贷资产包共3个，本金合计2.93亿元，占比16.54%。中国银行广西3期（1.18亿元）、广发银行北京1期（1.50亿元）、工商银行内蒙古3期（0.25亿元）三笔单包户均本金普遍在12万元以上，明显偏离小额分散的资产逻辑。其中广发银行北京1期加权平均逾期119.94个月、诉讼笔数占比100%，已属深度沉淀资产；中国银行广西3期诉讼比例43.28%、账龄20.85个月；工商银行内蒙古3期账龄最短，为8.16个月。三笔起拍价分别为7.53%、6.33%、5.10%。

信用卡：信用卡资产包共2个，本金合计2.44亿元，占比13.76%。农业银行福建2期（1.57亿元、户均1.07万元）与建设银行河北4期（0.86亿元、户均3.96万元）诉讼比例均为0%，但账龄分化显著——前者加权平均逾期22.21个月，后者拉长至61.38个月；两包起拍价分别为7.57%和5.90%，处于市场中枢附近。信用卡资产由上周的绝对主力（144.62亿元、占比73.57%）快速退居第三位，单周供给的批次驱动特征十分明显。

混合贷（消费贷与经营贷混合）：混合类资产包共1个，为邮储银行上海2期，本金8,872.82万元，占比5.01%，户均本金16.55万元，加权平均逾期13.36个月，诉讼比例16.25%，起拍价10.82%，为本周定价最高的一批资产。本周转让与招商环节的资产特征详情，详见以下附录页。

# 02核心亮点数据深度拆解

## 1.供给结构：中等规模包集中，消费贷与消金机构担纲主力

本周资产本金主要集中在\[1,3)亿元区间，占比64.06%，对应规模约11.35亿元；\[1,000,5,000)万元区间资产则全部来自国有大型银行的小额包；\[3,5)亿元区间仅河北银行4期一包。从单包规模看，河北银行4期（3.01亿元）、农业银行福建2期（1.57亿元）、广发银行北京1期（1.50亿元）、中国银行广西3期（1.18亿元）、工商银行湖北2期（1.16亿元）位居前五，合计8.42亿元，占全市场47.55%。本周无5亿元以上超大额资产包，单包规模较上周（最大包光大信用卡4期10.90亿元）明显收敛，供给由“巨头独揽”转向“分散铺开”。户均本金方面，\[5,10)万元区间占比最高，为36.72%，以消费金融公司为主；20万元及以上区间则以国有大型银行和股份制银行为主，在资产类型上对应经营贷与部分大额消费贷，客群差异显著。

## 2.客群与诉讼：40至45岁客群占比超六成，诉讼比例整体抬升

借款人年龄主要集中在\[40,45)岁区间，本金占比64.57%，为本周最集中的客群区间，其中该区间消费金融公司占比约五成；\[35,40)岁区间以城商行占主导，\[45,50)岁区间则以股份制银行占主导。诉讼维度，资产已诉讼比例集中在\[0%,10%)区间，占比45.08%，低诉资产仍为主体，且该区间以国有大型银行为主；\[30%,50%)及\[50%,80%)区间以消费金融公司为主，80%及以上区间由股份制银行主导。分机构看，全市场加权平均诉讼占比由上一统计周期的10.74%升至27.58%，主要受个别大额包拉动——股份制银行整体诉讼占比高达97.80%（广发银行北京1期100%、中信银行银川1期83.13%），而城商行、农村中小银行机构分别为0.00%和0.31%，机构间资产质量分化依然鲜明。

## 3.定价与账龄：起拍价中枢上移，账龄结构明显缩短

本周个贷不良资产平均起拍价为本金的6.33%，较上一统计周期的5.48%上移0.85个百分点；起拍价集中在\[5%,8%)区间，占比49.24%，\[0%,5%)区间则全部由消费金融公司构成。分机构看，消费金融公司平均起拍价3.80%为最低，农村中小银行机构5.51%、城商行7.06%、股份制银行7.18%、国有大型银行8.29%依次抬升，整体定价水平较上周有所回升。账龄方面，加权平均账龄由上一统计周期的4.71年回落至2.60年，资产逾期账龄主要集中在\[12,24)个月区间，占比54.06%，以消费金融公司为主；\[0,6)个月短账龄资产全部来自消费金融公司，60个月及以上长账龄资产则集中于广发银行北京1期、建设银行河北4期等个别大额包。短账龄资产的集中供给意味着回收窗口更靠前，对催收时效与前端运营能力的要求同步提高。

# 03市场趋势研判

## 1.信用卡退潮、消费贷接棒，供给结构一周内快速切换

上周信用卡资产以29个包、144.62亿元占据全市场73.57%，本周信用卡仅挂牌2个包、2.44亿元，占比降至13.76%；与之对应，消费贷以9个包、11.45亿元、64.69%的占比接棒成为第一大类。此次切换主要由供给节奏驱动——上周光大银行、交通银行集中批量出表，本周则转为消费金融公司（兴业消金三期合计5.93亿元）与城商行（河北银行4期3.01亿元）的分散供给。单周结构性波动加大，说明银登市场供给已进入“批次驱动”阶段，机构出表节奏对市场结构的扰动将更为频繁，，宜以月度或季度维度观察趋势。

## 2.高诉讼、长账龄资产现身，处置能力成为定价核心变量

本周整体账龄回落、低诉资产仍占主体，但个别大额包呈现极端特征：广发银行北京1期本金1.50亿元、加权平均逾期119.94个月、诉讼笔数占比100%；中国银行广西3期诉讼比例43.28%。这类资产多已完成诉讼程序，回收高度依赖执行环节，定价不再单纯取决于账龄与户均本金，而取决于属地司法推进效率与执行回款率。对投资机构而言，此类资产的尽调重点应从“债权本身”转向“执行可行性”，包括管辖法院执行力度、可执行财产状况以及后续催收资源的属地匹配度。

3.前九月累计挂牌1,675.60亿元，同比增长25.48%

把视线拉长，2026年1-9月银登中心个贷不良资产累计挂牌本金规模达1,675.60亿元，本息总规模达2,446.80亿元，累计本金规模同比增长25.48%、本息规模同比增长10.05%。从月度节奏看，1月、3-4月及6-9月均实现同比增长，2月和5月同比下降，其中9月单月同比增长48.08%、本息同比增长14.24%，1月同比增幅最大（本息口径达372.64%）。值得注意的是，本金规模增速（25.48%）显著高于本息规模增速（10.05%），意味着新增供给更多来自本金占比较高、息费沉淀相对较少的资产。

## 4.招商端平安系大额批量预热，后续供给热度有望延续

招商端本周共推出14个项目、本金合计29.02亿元。其中股份制银行3个项目、18.15亿元，全部来自平安银行——信用卡72期（8.55亿元、50,281户）、信用卡73期（0.61亿元、3,441户）与平安99期（8.99亿元、85,029笔），三笔合计18.15亿元，加权平均逾期天数均在1,050天至1,300天之间，且诉讼笔数极少。农村中小银行机构2个项目、2.83亿元，全部来自江苏启东农商行1期与盱眙农商行1期，加权平均逾期天数高达1,476天至1,502天；城商行1个项目、3.04亿元，即河北银行4期（28,960户、户均1.05万元）；国有大型商业银行虽有7个项目，但合计仅4.40亿元，单项目体量偏小；消费金融公司1个项目、0.60亿元，为四川唯品富邦消金11期。平安系与农商行的大额长账龄资产在招商端集中预热，预计后续将陆续转入挂牌环节，市场供给热度有望延续。

# 04结语

9月最后一周，银登挂牌市场供给规模回落至17.71亿元，但结构变化比总量更值得关注：信用卡退潮、消费贷接棒，消费金融公司与城商行成为供给主力，短账龄资产与大额长账龄高诉资产同时登场。拉长到年内看，前九月累计挂牌本金1,675.60亿元、同比增长25.48%，供给扩张的中长期趋势并未改变，变化的是结构——市场正从“批次涌入”转向“分化供给”。对投资机构而言，这意味着赛道正在从抢规模切换到选质量：谁能更准确地为长账龄、高诉讼资产定价，谁能更高效地推进属地司法执行，谁就能在下一轮供给周期中占据主动。
