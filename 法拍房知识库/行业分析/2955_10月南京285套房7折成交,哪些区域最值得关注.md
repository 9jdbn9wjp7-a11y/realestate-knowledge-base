# 10月南京285套房7折成交，哪些区域最值得关注

**核心结论：**2026年10月南京法拍市场共成交285套、总金额6.69亿元，1654人次参拍，整体约7折成交，名义捡漏空间约2.84亿元。

•**量在刚需：**100万以内房源占成交55.7%，浦口、江宁合计占住宅成交46%，低价与近郊是十月成交主基调。

•**漏在二拍：**二拍与变卖平均折扣约5.9折、58.1%，显著低于一拍88.6%——真捡漏集中在二拍及无人竞争的标的。

•**热在主城与稀缺品：**玄武区别墅超市场价80%成交、江北楼盘46人竞拍，优质标的越抢越贵。

* * *

# 市场总览：

# 285套成交6.69亿元，整体约7折

2026年10月1日至10月31日，南京法拍市场累计成交285套标的，成交总金额6.69亿元，1654人次参拍，平均每套约5.8人竞争。整体折扣率为70.2%，即平均约7折成交；相对起拍价的整体溢价率为14.3%。按市场参考价9.53亿元与成交额6.69亿元之差估算，名义捡漏空间约2.84亿元。

# 区域格局：

# 浦口、江宁是供应主力

# 主城与远郊两极分化

从住宅成交看，浦口区63套、江宁区54套，两区合计占全市住宅成交46%，是十月法拍房的供应主力与成交主力；建邺区23套居主城之首，玄武、鼓楼、秦淮、建邺主城四区合计70套。均价上，建邺241万元、玄武222万元领跑，六合、溧水、高淳则在34万—52万元区间，远郊以低价低门槛为主。

折扣率呈现两极：高淳、溧水住宅平均6.5折、7.0折，捡漏空间最大；而玄武区住宅整体折扣率高达97.8%（接近甚至超过市场价），主因太平门东街、太平门街等多套高价房源激烈竞拍。主城好地段并非“更便宜”，而是“更抢手”。

# 拍次结构：

# 二拍与变卖才是捡漏主阵地

十月成交中，一拍193套、占68%，成交3.24亿元，但平均折扣率高达88.6%；二拍80套、占28%，成交3.31亿元，平均折扣率仅58.9%；变卖10套，平均折扣率58.1%。一拍仍是多数成交的来源，但议价空间明显小于二拍——二拍起拍价在一拍基础上继续下调，是十月捡漏房源最集中的拍次。

#  热度与捡漏：

# 竞争越激烈，折扣越小

285套成交中，仅1人参与、以底价成交的标的52套、占18.2%，平均折扣率57.8%（约5.8折）；而10人以上竞拍的36套，平均折扣率110.6%，即平均超市场价约一成成交。热度与折扣率明显负相关——大漏往往出现在无人关注、无人竞争的房源上，而非市场热点楼盘；热度上来后，成交价甚至可能反超市场参考价。

![图片](https://mmbiz.qpic.cn/mmbiz_png/fOn2dZ4QghA1fLDdeb79ddtIpjA8Pz027fkVLia75YoicRKmBF6pMSj6xNZsRZlRHSxevecMG9GJicxxAMASa68fwYe5ic5j70DAPYMl2mQMy0g/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=2)

值得注意的是：底价成交并不等于“没有问题”。52套低竞争房源中不少位于六合、溧水、高淳等远郊板块，或为老破小、非住宅类资产，其流动性、处置周期与再售难度需单独评估。捡漏的收益应扣除后续成本后再判断。

热度最高的标的则呈现“好房子不便宜”的另一面：

-   浦口顶山街道江河欣府3幢一单元2001室（140㎡）起拍97万、46人竞拍，最终212万成交，高于市场参考价138万约53%，溢价率119%；

-   北外滩水城一室28人竞拍至122万；

-   鼓楼区北京西路2号一室25人竞拍至110万。

-   玄武区太平门东街2号7幢别墅更是以1801万元成交，超过市场参考价1000万约80%。

# 结论

十月南京法拍市场量价平稳，成交以200万以内刚需房源为主；整体7折成交、名义捡漏空间约2.84亿元，捡漏机会主要集中在二拍、变卖以及低竞争的远郊和特定标的；主城核心区与稀缺别墅反而高价成交，热度与折扣呈负相关。

本文章仅基于2026年10月1日至10月31日南京法拍成交明细（285套）统计，不含当月流拍、中止与撤回标的；折扣率、捡漏空间均为成交价与市场参考价的比值口径，未计入税费、物业欠费、腾退成本、贷款成本及再售周期，不构成任何投资建议。市场参考价来源于成交明细表内列示值，其评估机构与评估时点未在明细中列明。
