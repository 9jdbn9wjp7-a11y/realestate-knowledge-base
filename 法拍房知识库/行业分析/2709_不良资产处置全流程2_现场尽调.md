回到办公室写报告，才发现关键那一格是空的，只能再跑一趟——一趟就是两天、几百公里、上千块。

所以这篇不讲道理，只给工具：现场尽调纪律、现场六看与八条红线，以及一张能装进一页 A4 的现场尽调表。

# 01 先立三条纪律

现场不是去看房，是去取证。取证就得有规矩：

-   **材料不全不下场。**核心文件缺两件以上，直接改期。缺的不是纸，是你回来无法判断的那部分事实。

-   **清单逐项打钩。**不靠记性，靠表格。现场的记忆只有三小时，报告要用三个月。

-   **全程留痕。**照片带门牌、带时间、带编号；笔录当场签字。没有留痕的结论，在谈判桌上等于没说。

# 02 现场六看：路线和动作

  路线固定：不动产登记中心 → 房子 → 物业 → 周边三家中介 → 社区或邻居。一天最多三套，同小区一次跑完。

**看门。**门牌号、楼栋单元是否与产证坐落一致，门口有没有查封封条、落款日期是新的还是旧的。

**看证。**现场核对产证信息：面积、用途、土地性质、共有情况。名字对不上，后面全停。

**看屋。**结构有没有改动、有没有违建；墙角顶棚有没有渗漏裂缝；水电设施能不能用；装修几年了、还剩多少残值。

**看人。**谁在里面住：业主、租客、老人、还是群租。四种人，四种腾退方案，四种时间成本。

**看费。**物业费、水电气表底数、维修资金，当场记录并拍照。

**看市。**三家中介的挂牌价与挂牌时长、近半年网签成交价、同小区法拍成交价、月租金水平。

六看里最值钱的是**看人**。房子的瑕疵可以用钱修，人的问题只能用时间磨，而时间是最贵的成本。

# 03 八条红线：一条都不能做

1.  **不得强行入户、撬锁。**入户需经权利人同意，或由法院、管理人安排。

2.  **不得撕查封封条。**这是妨害执行，性质比看错房严重得多。

3.  **不得向占有人作任何承诺。**补偿金额、腾退时间，一句"我保证"就可能变成你的义务。

4.  **拍照录像先告知。**涉及个人与家庭隐私的画面，不得外传、不得发朋友圈。

5.  **每张照片带门牌与时间水印。**全景一张、细节若干，同一角度对照拍。

6.  **不拆改、不擅自试水通电。**出了事故，责任在你。

7.  **现场记录当场签字。**双方各执一份，事后不认账的空间就没有了。

8.  **一人不进陌生空置房。**结伴同行，先看楼道与周边，再进门。

# 04 现场尽调表：五栏七类，一页纸

表格不做成几十页的报告，做成一张能打印、能打钩、能签字的 A4。

**五栏结构：**核查项目｜查证方式｜合格标准｜风险信号｜结论。结论只填三个词：**通过、存疑、否决**。填"存疑"的，必须在备注写清补什么材料。

七大类，合计三十四项，正好一页：

-   **一、材料完备度（6项）。**合同、放款凭证、还款流水、催收与时效中断、债权转让通知、利息计算表。

-   **二、权属与担保（5项）。**权利人、共有情况、抵押登记与顺位、查封与首封法院、租赁与占有。

-   **三、实物状况（6项）。**坐落一致、结构与违建、渗漏裂缝、设施设备、装修残值、消防与安全。

-   **四、费用与欠费（5项）。**物业费、水电气、维修资金、土地出让金、欠税与滞纳金。

-   **五、占有人与腾退（4项）。**居住人身份、租约情况、腾退意愿、特殊主体（老人、低保、唯一住房）。

-   **六、市场与变现（4项）。**挂牌价与时长、网签成交价、法拍成交价、租金与去化周期。

-   **七、处置障碍（4项）。**异地首封、查封是否过期、抵押能否注销、是否进入破产或轮候查封。

举两个填法示例。**"抵押登记与顺位"：**查证方式是登记中心查档；合格标准是一押登记有效、顺位明确、余额可核；风险信号是未办登记、顺位被后手超越、抵押范围只覆盖部分份额。**"占有人与腾退"：**查证方式是现场入户与社区走访；合格标准是空置或占有人配合；风险信号是长期租约、老人居住、群租，或拒绝沟通。

   回来二十四小时内做三件事：**给照片编号归档**（房号—项目—序号），**把"存疑"项重新算进可变现净值**，**出结论**——可投、需补材料、否决。三档写清，不留"再看看"。
