**核心痛点**：普通诉讼程序冗长，债务人利用程序拖延时间转移资产。而非诉程序**跳过诉讼环节，直达执行阶段**，大幅提升清收效率！

### 2\. 实现担保物权程序：2021年《民事诉讼法》修订亮点

**法律依据**：

-   **《民事诉讼法》（2021年修订）第203条**：申请实现担保物权，由担保物权人及其他有权请求实现担保物权的人，向担保财产所在地或担保物权登记地基层人民法院提出

-   **第204条**：法院受理后，经审查符合法律规定的，**裁定拍卖、变卖担保财产**；不符合的，裁定驳回申请，当事人可提起诉讼

**2022年《民事诉讼法解释》细化规定（第359-373条）**：

 |
| **第361条** |

 |

### 3\. 公证债权文书强制执行：跳过诉讼的"快车道"

**法律依据**：

-   **《民事诉讼法》第245条**：对公证机关依法赋予强制执行效力的债权文书，一方不履行，对方可向有管辖权法院申请执行，**受申请法院应当执行**

-   **《公证法》第37条**：经公证的债权文书，债务人不履行或不适当履行，债权人可向有管辖权法院申请执行

**核心优势**：

-   **直接执行**：无需经过诉讼程序，直接进入执行阶段

-   **缩短时间**：大幅降低回收周期，降低清收成本

-   **管辖确定**：被执行人住所地或被执行财产所在地法院管辖

**"确有错误"的审查标准**：

-   法院仅审查公证债权文书是否"确有错误"

-   被申请人提出执行异议和证据证明"确有错误"，法院才进行实质性审查

-   **不因当事人异议而简单驳回申请**（与实现担保物权程序的关键区别！）

## ⚖️ 案例解析 | 两大程序实战对比与衔接策略

###

### 【场景设定】同一笔不良债权，三种清收路径如何选择？

**案例背景**：

-   甲银行向乙企业发放贷款1000万元，丙企业提供房产抵押担保，丁企业提供连带责任保证

-   贷款到期后，乙企业违约，丙企业抵押房产价值充足，但各方对债权债务关系存在不同态度

### 【路径一】实现担保物权程序：快速处置抵押物

**适用条件**：

-   仅针对**担保物权**（抵押、质押、留置）

-   不涉及保证人等第三方责任主体

-   担保物权清晰，无实质性争议

**操作流程**：

1.  甲银行向抵押房产所在地基层法院提交申请

2.  提交材料：申请书、抵押合同、抵押登记证明、贷款违约证明、房产现状说明

3.  法院5日内送达丙企业，告知异议权利

4.  法院审查（独任或合议庭）：

-   **无实质性争议+条件成就**→裁定准许拍卖、变卖房产

-   **有实质性争议**→驳回申请，甲银行可另行起诉

6.  凭裁定申请强制执行

**时间优势**：立案之日起**30日内或公告期满后30日内审结**

### 【路径二】公证债权文书强制执行：直达执行阶段

**前提条件**：

-   贷款合同、抵押合同、保证合同**事先经公证并赋予强制执行效力**

-   公证债权文书载明债务人、担保人愿意接受强制执行的承诺

**操作流程**：

1.  甲银行向被执行人住所地或财产所在地法院申请执行

2.  法院审查公证债权文书是否"确有错误"

3.  **无错误**→直接进入执行程序，查封、拍卖抵押房产，执行保证人财产

4.  **确有错误**→裁定不予执行，甲银行可另行起诉

**核心优势**：**一次性解决主债权+担保物权+保证责任**，无需分别主张

### 【路径三】两大程序联合运用：标的不重合时的并行策略

**关键区分：标的是否重合**

**情形一：标的不重合（可同时存在）**

-   **实现担保物权程序**：仅针对抵押房产（担保物权）

-   **普通诉讼程序**：针对乙企业（主债务人）、丁企业（保证人）主张权利

-   **操作要点**：普通诉讼程序**应中止审理**，待担保物权程序审结后决定是否恢复

**保全衔接**：

> 通过普通诉讼程序中的**保全程序**先行查封债务人、保证人有效财产，即使后续普通程序中止，也能在一定程度上保护债权人权益！

**情形二：标的不重合的另一种运用**

-   实现担保物权程序的诉讼请求内容（如“裁定拍卖抵押房产”）**并不当然包含**在普通诉讼程序的“判令被告偿还借款本息”之中

-   两个程序**可以同时存在**，但为避免裁判冲突和资源浪费，法院通常会中止普通程序，待担保物权执行完毕后再行处理。

## ❓实务问答 | 两大程序的实操要点与衔接难题

###

### 实操要点1：实现担保物权程序的三大实务雷区

**雷区一：公告送达的适用争议**

-   **问题**：当事人找不到时，能否适用公告送达？

-   **立法目的冲突**：实现担保物权程序旨在提高效率，但两个月公告期与立法目的相悖

-   **法律依据**：《民事诉讼法》第187条——特别程序案件应在立案之日起**30日内或公告期满后30日内审结**

-   **实务建议**：明确提到"公告期"，说明**可以适用公告送达**，但需权衡效率与程序正义

**雷区二：审查标准的地区差异**

-   **问题**：实质性审查 vs 程序性审查，各地法院不统一

-   **极端情况**：部分法院仅做程序审查，当事人一提异议即驳回申请；部分法院则查明事实后再裁定

-   **复杂案件风险**：一旦对方提出异议，程序可能被搁置

-   **应对策略**：提前评估案件争议程度，对复杂案件直接选择诉讼程序

**雷区三：与普通诉讼程序的衔接障碍**

-   **问题**：当事人同时提起实现担保物权申请和普通诉讼，如何处理？

-   **重庆高院规定**：立案前应询问是否已提起诉讼；若已提起，应释明选择；不撤诉的，裁定不予受理实现担保物权申请

-   **关键规则**：**标的不重合时，两个程序可同时存在，但普通程序应中止审理**

### 实操要点4：程序选择的决策树

**第一步：评估债权结构**

-   仅有担保物权（抵押/质押/留置）→ 优先考虑实现担保物权程序

-   包含保证人、复杂法律关系 → 优先考虑公证债权文书或普通诉讼

**第二步：评估争议程度**

-   无实质性争议 → 实现担保物权程序（30日快速清收）

-   可能有争议 → 公证债权文书（稳定性更强）或普通诉讼

**第三步：评估时间紧迫性**

-   需立即保全资产 → 普通诉讼+保全程序，或两大程序并行+保全

-   可接受30日周期 → 实现担保物权程序

**第四步：评估成本收益**

-   追求最低成本 → 实现担保物权程序（申请费低）

-   追求最高效率 → 公证债权文书（直达执行）

### 实操要点5：与普通诉讼程序的联合运用策略

**策略一：保全先行**

-   无论选择何种程序，**先行通过普通诉讼程序申请财产保全**

-   查封债务人、保证人有效财产，防止资产转移

-   即使后续程序中止，保全措施不解除

**策略二：程序中止与恢复**

-   实现担保物权程序与普通诉讼程序**标的不重合时**，普通程序应中止审理

-   根据担保物权程序审结情况，决定是否恢复普通程序

**策略三：权利救济的互补**

-   实现担保物权程序被驳回 → 另行提起普通诉讼

-   公证债权文书不予执行 → 就争议内容提起民事诉讼
