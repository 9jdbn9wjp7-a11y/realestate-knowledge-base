# 法拍房悔拍故事
> 公众号: 东莞老赵探不良

东莞南城这套房悔拍，12万保证金没了还倒贴？法拍这个坑别踩  东莞南城想买房、或者正在看法拍房的朋友，这条一定看完。南城金域中央那套136平大三房，上个月刚出事——上一轮拍到251万成交，结果买家不要了，悔拍。现在9月3号要重新拍，起拍价225万。  你以为"不想要了大不了不要保证金"？错得离谱。  我干辅拍这大半年，最怕客户冲着起拍价低脑子一热举牌，真到要付尾款了钱凑不齐，悔拍的下场比你想的惨：

第一，12万保证金直接没收，一分不退。

第二，也是最坑的——如果这次重拍价低于上次251万，中间的差价你要补！ 比如这次230万成交，你就得补21万，加上保证金，里外里三十多万没了。

第三，两次拍卖的公告费、执行费全你出。

第四，拒不补钱可能被强制执行，还上失信名单，影响征信。  法拍不是二手房，没有"交个定金反悔商量退"这一说，法院的程序说一不二。

 这套房本身不差：南城成熟地段，136平精装三房，上一轮近8000人围观，流动性有保障。但参拍前必须自己查清三件事：有没有人住、有没有长期租约（清场难不难）；物业费水电欠多少；过户税费到底要交多少。别光看起拍价。  拍之前自己对着查一遍：  1. 保证金多少、啥时候到账，提前留时间  2. 尾款自己能不能在规定期限内凑齐  3. 实地去看房，占没占人、租约、欠费、房子啥样  4. 把税费+欠费+装修+清场全算上，才叫真实总价  5. 心里先定个最高价，别竞价上头——上头是悔拍头号原因  6. 拍卖公告逐字看，悔拍、交付、过户条款看明白  捡漏是有的，但前提是你尽调到位、出价理性。冲动举牌，接不住盘，亏的是自己。

 这套金域中央9月3号再拍，想看完整公告、对比小区二手价、或者帮你粗算参拍要准备多少预算，加我微信，我直接发你。法拍水深，找专业辅拍少踩坑。
