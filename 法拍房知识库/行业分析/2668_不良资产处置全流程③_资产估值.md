# 不良资产处置全流程③：资产估值

  前两篇讲了怎么查、怎么看。这一篇讲最硬的一步：**把查回来的信息，变成一个能签字的价格**。

估值不是算数学题，是做三次换算：**房子值多少 → 你能分到多少 → 今天该出多少**。三次换算做完，报价才有依据。

先给一组现实坐标。中指研究院数据，2026年1—10月全国355城法拍市场挂拍65.4万件、成交18.8万件，整体清仓率24.4%，**成交折价率74.3%**——也就是说，平均成交价只有评估价的七四折。评估价不是价格，成交价才是。

# 01 估值的对象，是未来的现金流

新手最容易犯的错，是给"房子"定价。老手给"现金流"定价。

-   **资产价值：**这套房在市场上能卖多少，扣掉变现折损之后剩多少。

-   **债权价值：**这笔债在你这个顺位上，能分回多少，什么时候分回。

-   **组合价格：**今天愿意为这一串未来现金流付多少，折现之后还剩多少。

三层是递进关系。第一层算错，后面全错；第三层不做，前两层就只是"看起来不错"。

# 02 三个价格，千万别混着用

**市场价。**同小区二手房的真实成交价，反映的是"慢慢卖能卖多少"。它是所有估值的起点，不是结论。

**清算价。**法拍、急售、抵债这类必须限期变现的价格。它有现成的参照系：2026年1—10月，全国法拍住宅成交折价率79.0%，商业67.9%，工业24.5%清仓率对应更深的折让，车位车库清仓率只有9.2%。换成折扣，住宅约让两成，商业约让三成。

**回收价。**你的债权在这一堆数字里，扣完顺位、税费、欠费、处置成本和时间之后，真正能落袋的部分。

一个常见误判：拿市场价九折算"已经很保守"。现实是，法拍住宅平均成交价只有评估价的七九折，而评估价本身往往还高于当前二手成交价。**两道折扣叠起来，才是清算价的真实水平。**

# 03 网络尽调怎么变成参数

查回来的每一条信息，都必须落成一个可计算的参数。落不下来的，等于没查。

**主体存续 → 时间参数。**还在正常经营，腾退与谈判可能三到六个月；已是空壳、法人失联，走公告送达与强制执行，起步十二个月。

**司法状态 → 处置路径与周期。**已首封、已评估、即将挂拍，六个月内有结果；只是终本、没有新线索，要重新申请恢复执行；已进破产，按破产程序重新排队，二十四个月起步。

**资产业态 → 折扣参数。**住宅取清算折扣20%左右，商业取30%上下，工业与车位更狠。同一城市不同板块还要再加码：挂牌半年没成交的板块，折扣上调五到十个点。

**经营现金流 → 是否具备重整价值。**有稳定租金、有在手订单，可以按收益法给出高于清算价的估值；完全停摆，只能按清算价。

**债权顺位 → 受偿率参数。**一押、二押、普通债权，三者的受偿率不是一个量级。这一项直接决定"回收价"。

# 04 现场尽调怎么修正参数

现场不看热闹，看的是**修正项**。每一项对应公式里的一个减号。

1.  **看屋 → 瑕疵扣减。**结构改动、渗漏裂缝、设施失效，按修复报价直接扣；装修五年以上，残值按零计。

2.  **看人 → 时间修正。**有人居住且不配合，腾退周期加六到二十四个月，同时加协商补偿预算。

3.  **看费 → 直接扣减。**物业、水电气、维修资金、划拨地出让金，按现场抄表和书面清单入账。

4.  **看证 → 折扣上调或否决。**划拨地、共有权瑕疵、租约在先，属于"改参数"甚至"直接否"的级别。

5.  **看市 → 去化修正。**三家中介挂牌时长、近半年网签量、法拍成交记录，共同决定这块资产的"卖得掉要多久"。

现场的价值就在这里：**它把网络尽调里那些"可能"，改成了"确定"，或者"确定不行"。**

# 05 三种方法，按业态选

**市场比较法。**首选，适用于住宅和有可比成交的商业。取同小区、同户型、近六个月的成交单价，按面积、楼层、朝向、装修做系数修正，得出市场价，再乘变现折扣。

**收益法****。**适用于有稳定租金的商业、厂房、公寓。用净租金收入除以资本化率，资本化率取当地同类物业的实际租金回报水平，不要套外地数据。

**成本法。**适用于工业厂房、在建工程、没有可比成交的资产。重置成本乘以成新率，再扣土地剩余年限的影响。

法拍或抵债类资产，还有一条经验：**基数用清算价，不用市场价。**市场价是用来判断"天花板在哪"，清算价才是你真正能拿到的钱。

# 06 从资产价值到债权价值

资产值钱，不等于债权值钱。中间隔着三道漏斗：优先费用、担保顺位、普通债权排队。

**第一步，算可分配净值。**可分配净值 ＝ 清算价 － 买方税费 － 欠费 － 处置成本 － 腾退成本 － 应由被执行人负担的执行费用。

**第二步，按顺位分配。**一押先受偿，二押吃残余，普通债权排队。一个示例：净值92万元，一押余额70万元，二押余额60万元，那么一押拿70万元，二押只能拿22万元，普通债权为0。

**第三步，得出回收率。**回收率 ＝ 本顺位可回收金额 ÷ 债权本息。这个比值，才是谈判桌上真正在谈的东西。

# 07 组合估值：概率加权，再折现

动手算之前，普及下计算概念：折扣的分母，到底是本金，还是本息。​不良资产圈里说的"几折"，默认是按本金打折。用本息做分母，会得到一个随催收时间自动变小的数字——利息每天都在长，折扣看着越来越便宜，其实资产一分钱没变。​

三种口径，一条换算公式：​

本金折扣 ＝ 报价 ÷ 本金。这是行业默认口径，也是多数机构的内部审批口径。​

本息折扣 ＝ 报价 ÷ 债权本息（本金＋利息＋违约金）。银行、AMC的批转文件里，这个数叫"债权总额"。​

换算公式：本金折扣 ＝ 本息折扣 ×（本息 ÷ 本金）。​

为什么本金才是分母，三条理由：利息和违约金在诉讼、执行中常被调减，能主张不等于能收回；利息随时间增长，拿它做分母，折扣会失真；估值的锚是抵押物的可变现净值，跟利息没有关系。​

举例：某资产包内债权本息合计500万元，其中本金400万元、利息及违约金100万元。A户：本息200万元（本金160、利息40），房抵，净值120万元，预计12个月回款。B户：本息180万元（本金145、利息35），二押，净值60万元，预计24个月。C户：本息120万元（本金95、利息25），信用类已终本，净值6万元，预计36个月。​

第一步，加总净值。120＋60＋6＝186万元。净值是绝对金额，不受口径影响，变的只是分母。​

第二步，减处置成本。法务、差旅、诉讼、拍辅按25万元计，剩161万元。​

第三步，按时间折现。10%折现率：120÷1.1＋60÷1.21＋6÷1.331≈163万元；扣掉25万元成本，约138万元。​

第四步，两个口径各报一次。按本息：138÷500＝27.6%；按本金：138÷400＝34.5%。所以这个包正确的说法是"本金三折五"，而不是"二七折"。​

口径一混，报价就差出真金白银。假设卖方开口"3折"：​

按本息3折＝150万元，折成本金是37.5%，高于34.5%的上限，不能接。​

按本金3折＝120万元，折成本金30%，低于上限，可以接，安全垫约18万元。​

同样一句"3折"，一个是150万元，一个是120万元，差出30万元。这就是为什么报价单必须写清三件事：分母是本金还是本息、含不含利息与违约金、利息算到哪一天。合同里同样要写清，否则过户之后为"利息截止日"再吵一轮，利润就吵没了。​

组合估值的作用，是把"感觉能赚"变成"算得出来的上限"——而这个上限，只有站在本金口径上才立得住。

# 08 估值表与敏感性，和五个必须披露的假设

报告里放一张六栏表：**科目｜取值｜依据｜乐观／中性／悲观｜敏感性｜结论**。每一行都要有出处，没有出处的行，评审时第一个被问倒。

五个敏感性因素，逐个试一遍：

-   **变现折扣加5个点。**价值直接掉5%，组合折现后大约掉3个百分点。

-   **回收周期各延6个月。**10%折现率下，平均价值降约5%。

-   **处置成本加5万元。**小包影响明显，大包被摊薄。

-   **折现率加2个点。**长周期资产受影响最大，36个月那笔能掉一成。

-   **回收率下调10%。**通常来自二押顺位变化或腾退受阻，影响最直接。

最后，五个假设必须写进报告，不写就等于埋雷：**评估时点**（价格有日期）、**卖方主体与税费口径**（个人还是企业，决定税负）、**腾退情景**（是否含强制腾退）、**处置成本口径**（含不含诉讼与差旅）、**折现率**（自有资金还是融资）。

估值从来不是算出一个精确数字，是给出一个区间、一个上限、和一句"超过就不接"。
