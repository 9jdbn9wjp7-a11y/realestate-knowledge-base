# **不良资产：“最坏时代之下“的最佳“捞金”行业**

   当经济越好，投资越容易赚钱；当经济越差，投资越可能亏钱，这是常理。但是，有这样一个特殊“行业”，却可以成为最不利时期的最佳“捞金”行业，它就是“不良资产处置”。

   除了不良资产，我们找不到一个和房产赚钱前景相当的行业。

   由于不良资产的处置时间相对较长，权利关系大部分时候错综复杂的，涉及到法律、财务、金融、投行、评估、债务化解等等问题，难度不小，因此劝退很多想赚快钱的投资人。

   不良资产能否从潜在的负担转变为宝贵的资源，不仅取决于它们当前的状态，还取决于处置者是否具备识别其潜在价值的洞察力，并能够给出最佳的资产处理方案。就当下的资产管理领域里，由不良资产构成的优质资产包，尤其是房地产类的不良资产项目，不仅是各路财富管理机构争抢的“香饽饽”，也是地方AMC、大型房企的逐利场。

   别人的“最坏的时代”却是不良资产最佳“捞金”时期，对于投资者来说，投资不良资产的理由千千万，都不抵天然价格差、有充足的获利空间这一个。资本都是逐利的，只要有获利空间，同时又能很好的评估风险，那么就值得投资。在这样一个万亿级的蓝海市场里，只有丰富的处置经验和优秀的处置能力，才能在经济下滑的时代依然可以有所斩获。

   “存量时代”的不良资产处置，要做资源盘活重整才能提升价值。

   无论是政策上，还是从市场信息反馈看，整个不良资产行业处于一个喷井的状态。面对不良资产的巨大市场供给，四大资产管理公司（AMC）与地方资产管理公司由于资金、技术等原因需求有限，导致市场形成了大量的业务需求。

   业内测算，目前五大AMC（即全国性金融资管公司：中国中信、中国信达、中国东方、中国长城、中国银河）资本总额约为3600+亿元，按照12.5%资本充足率要求，最多可承接不良资产为3万亿元左右。而这样的承载能力，显然是不足以消化不断扩张的不良资产，预估仍有逾数十万亿级的市场空间提供给各类地方性资产管理机构以及民间机构。

   作为经济下行时代，最佳的“捞金”行业，不良资产处置行业成为了一个盈利的绿洲，能够为投资者提供相对稳定的回报。
