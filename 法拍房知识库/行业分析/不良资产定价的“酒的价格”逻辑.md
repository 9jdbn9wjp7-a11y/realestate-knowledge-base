# 一包不良资产，凭什么卖这个价

在不良资产行业，最没有标准答案的问题就是定价。同一个资产包，有的机构报价三折，有的机构报价五折，有的机构干脆不敢报价——因为说不清它到底值多少钱。市场上充斥着各种复杂的估值模型：现金流折现、清偿率测算、回收率回归……但模型越复杂，离真相往往越远，因为不良资产定价的核心变量不是模型，而是对资产质量的判断。

这篇文章想分享一个朴素但极其好用的定价框架：把不良资产当成酒来定价。酒有茅台、口粮酒、散酒之分，不良资产也一样——先分档，再定价，档位决定价格区间，细节决定最终报价。这套框架在行业交流中被反复印证，它让定价从“玄学”变成了“常识”。

一、为什么用酒来比喻不良资产

酒和不良资产有三个共同点。第一，品质分层极其鲜明：茅台和散酒的价格差几十倍，不良资产包里优质债权和僵尸债权的价值差也是几十倍。第二，价格取决于稀缺性和确定性：茅台贵是因为确定有人要、确定能变现，优质不良债权贵也是因为确定能回收；散酒便宜是因为不确定，不良资产里的坏账便宜也是因为回收不确定。第三，行家看门道：不懂酒的人看包装，懂酒的人看产地年份；不懂不良资产的人看账面金额，懂的人看底层资产、看债务人、看司法状态。

所以“酒的价格”不是一句玩笑，而是一套完整的分层定价思维：先给资产定性分档，再按档位匹配定价逻辑和处置策略。

# 二、茅台档：高确定性资产，定价逻辑是“看回收不看折扣”

茅台档对应的是高回收确定性的不良资产：抵押充足的对公不良、有稳定现金流的核心企业债权、执行程序已进入处置阶段的优质抵押物。这类资产的特点是有硬资产兜底，回收时间可预期，回收率可测算。

对茅台档资产，定价逻辑不是“打几折”，而是“算回收”——以抵押物评估价值和回收周期为基础，测算现金流折现，折现率取行业合理水平。这类资产的成交价可能高达面值的五成、七成甚至更高，但因为回收确定，持有风险低，资金占用效率高。抢茅台的人从来不看标价，看的是确定性和稀缺性——不良资产市场里的机构抢优质资产包，逻辑完全一样。

三、口粮酒档：中等回收预期的个贷与小微包，定价逻辑是“看分层算概率”

口粮酒档是市场规模最大、交易最活跃的档位：个人消费贷、信用卡、经营类信用贷的批量转让包。这类资产没有抵押物兜底，回收完全依赖债务人还款能力和处置能力，定价的核心是“概率”——批量资产包的价值，等于每笔债权回收概率的加权和。

这正是个贷不良批量转让的定价逻辑：按客户分层（良性/灰色/恶意）、账龄（M1到M6+）、区域、历史回收率数据，测算每个分层的回收概率，再乘以单笔金额求和。行业实践中，这类资产的成交价普遍在面值的一到三折之间，信用卡包略高，消费贷包略低——价格差异的本质，是客群质量和处置难度的差异。

口粮酒档是定价技术含量最高的档位：数据越细、分层越准、回收预测越实，报价就越有底气。这也是尽调估值服务商和司法科技公司的价值所在——帮AMC把“拍脑袋定价”变成“数据定价”。

四、散酒档：高风险长周期资产，定价逻辑是“看底线算止损”

散酒档对应的是高风险、长周期、回收不确定的资产：失联率高的长账龄个贷、无资产可执行的僵尸债权、历史遗留的疑难包。这类资产的价格极低，可能只有面值的一折甚至几分钱，但买它的人不是赌回收，而是赌三件事：一是赌司法处置的时间价值（诉讼时效保全、强制执行的可能性）；二是赌债务人未来经济状况的改善（行业复苏、个人收入恢复）；三是赌资产包的组合价值（打包后与优质资产搭配处置）。

散酒档的定价逻辑是“算底线”——这笔资产最差能收回多少、持有成本多少、最坏情况下的损失能否承受。只要底线算得清，散酒也有散酒的生意；最怕的是把散酒当口粮酒买，把口粮酒当茅台买——档位判断错了，价格一定错，处置策略也一定错。

# 五、档位是动态的：同一包资产，价格随处置能力而变

“酒的价格”框架最容易忽略的一点是：同一瓶酒，在不同人手里价值不同。茅台在黄牛手里是行情价，在收藏家手里是传承价；不良资产也一样——同一包资产，在不同收购方和处置方手里，回收率可能差一倍。

有没有司法通道，决定了处置的速度：有赋强公证加持的资产包，执行周期短，回收率上浮；没有司法通道的，只能靠谈判和催收，回收率下探。有没有数据能力，决定了定价的准度：有历史回收数据库和分层模型的机构，能识别出包里的“隐藏茅台”；没有数据能力的，只能按整体折扣报价，要么错过机会要么接盘风险。有没有合规体系，决定了处置的持续性：合规机构能拿到AMC的受托处置订单，能对接银行和消金的源头资产；不合规的机构，再便宜的价格也接不住。

所以“酒的价格”框架的完整表述是：先按资产质量分档定基准价，再按自己的处置能力修正报价。基准价是市场的，修正价是自己的——定价能力，本质上是对自身处置能力的认知能力。

六、定价之外：买酒的人还要会醒酒

买酒不是终点，喝掉才是。不良资产的定价只是入口，真正的价值在处置环节兑现。对应到操作层面：

茅台档要“醒得快”：资产明确、回收确定，就要快速尽调、快速定价、快速交割，抢在竞争对手前面。

口粮酒档要“醒得透”：分层尽调、逐笔测算、制定差异化的处置方案——良性客户走柔性纾困，灰色客户走限时转化，恶意客户走司法通道。

散酒档要“醒得久”：长期持有、动态跟踪、捕捉债务人状态变化的拐点，在行业复苏或司法突破的时机择机处置。

定价模型解决的是“多少钱买”，处置体系解决的是“多少钱回”——两者之间的距离，就是不良资产行业的利润空间，也是专业机构的核心竞争力。

七、结语：让定价回归常识

不良资产定价不需要更复杂的模型，需要的是更清醒的分类。把资产按确定性分成茅台、口粮酒、散酒三档，每一档用不同的逻辑定价，再用自己的处置能力修正报价——这套框架的价值不在于精确，而在于让定价过程可讨论、可检验、可复盘。

**不良资产的价格，不是市场给的，是能力给的。同样一包资产，茅台还是散酒，取决于你的眼光；三折还是五折，取决于你的处置能力。先分档，再定价，后处置——这是不良资产行业最朴素也最有效的赚钱顺序。**
