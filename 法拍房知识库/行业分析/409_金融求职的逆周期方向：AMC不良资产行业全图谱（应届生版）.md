# 金融求职的"逆周期"方向：AMC不良资产行业全图谱（应届生版）

金融专硕、泛商科的同学们，求职时除了券商、投行、银行，有一个方向这两年讨论度越来越高——**不良资产处理（AMC）**。

**一、客观认识：AMC是一个什么样的行业**

AMC的生意一句话概括：**打折收购坏账，想办法把死资产盘活，赚处置差价**。

1999年，为剥离四大行的不良资产，国家成立了信达、华融、长城、东方四家AMC，分别对口接收建行、工行、农行、中行的坏账。

2010年后全面商业化，业务从"收坏账"扩展到企业纾困、破产重整、地产盘活、市场化债转股、问题机构托管等。

这个行业的核心属性是**逆周期**：经济上行期，银行坏账少，AMC业务清淡；经济调整期，不良资产供给放量，AMC的业务机会随之增多。

当前阶段，银行不良资产出清、房地产风险化解、中小金融机构改革、地方债务化解，都在给行业输送业务来源，行业的业务量是充足的。

同时也要客观认识另一面：AMC是重资本、长周期的生意，赚的是"收购价"和"处置价"之间的差价。资产处置周期普遍较长，需要真金白银垫资、需要跑现场尽调、需要和法院、债务人、投资人多方周旋——**这是一个赚专业钱、辛苦钱的行业，不是赚快钱的行业**。

行业整体也正处于从"粗放收包"向"投行化、精细化处置"转型的阶段，对人才的专业要求比过去更高。

对求职者来说，这个转型期恰恰意味着两件事：

一是业务范围拓宽带来了人才需求，五大AMC近年校招都在持续放出业务、法务、财务类岗位；

二是行业越往精细化走，"懂估值、懂法律、懂财务"的复合型人才越稀缺，个人技能的成长空间是实打实的。

**二、行业格局：5+59+N**

目前行业是"**5家全国性AMC + 59家省级AMC + 银行系AIC + N家非持牌机构**"的格局。

-   **全国性AMC（5家）**：中国信达、中信金融资产（原华融）、中国东方、中国长城、中国银河资产。持金融许可证，可在全国范围内收购不良资产，是国家队。

-   **地方AMC（59家）**：2012年后各省陆续设立。按2025年7月出台的《地方资产管理公司监督管理暂行办法》，地方AMC须立足本地、原则上不得跨区域经营，是"省级队"。

-   **银行系AIC（5家）**：五大行旗下的金融资产投资公司（工银、农银、中银、建信、交银投资），主攻市场化债转股，校招同样值得关注。

-   **N家非持牌机构**：外资（橡树、贝恩等）和民营不良投资机构，市场化程度最高，但招人少、偏好有经验的熟手，不是应届生的主战场。

**三、五大AMC逐一拆解**

**1\. 中国信达——行业老大**

1999年成立的国内首家AMC，2013年在香港上市，也是首家上市的AMC。2025年9月，财政部持有的58%股权划转中央汇金，正式进入"汇金时代"。资产规模行业第一，全国33家分公司，还有南洋商业银行、信达证券、金谷信托、信达金租等9家平台子公司。地产纾困、破产重整的代表性案例最多，校招体量五大里最大。总部北京。

**2\. 中信金融资产（原中国华融）——中信系成员**

原华融，2021年风险暴露后由中信集团参与重组并成为第一大股东，2024年初更名中信金融资产。背靠中信集团银行、证券、信托的全牌照资源，业务协同空间大，近年校招动作是五大里最积极的（秋招、春招、管培生多批次开放）。总部北京。

**3\. 中国东方——汇金控股71.55%**

2025年6月完成股权划转。旗下有东兴证券、中华联合保险、大连银行，金控结构完整，风格稳健。总部北京。

**4\. 中国长城——汇金控股73.53%**

2025年最早完成划转，规模在四家原AMC中最小，目前聚焦主业、结构调整，中小企业纾困和并购重组是特色方向。总部北京。

**5\. 中国银河资产——最年轻的第五家**

2020年由建投中信转型获批、2021年初正式展业，是时隔20多年新批的第一张全国性AMC牌照，汇金系（银河金控旗下）。体量相对较小，走轻资产、投行化路线，主打重整、咨询、特殊机遇投资。招人少而精，门槛不低。

**关于分公司**：五大AMC每家在全国设有30家左右省级分公司。

**分公司是校招的主力入口**——总部岗位少、门槛高，分公司招人更多、门槛相对友好（基本要求重点院校硕士，部分岗位985/211优先），做的是所在省份不良收购处置的一线业务，反而更能接触完整项目。

选择时可以留意：分公司的业务活跃度与所在省份的经济体量直接相关，东部业务大省的项目机会普遍更多。

**四、地方AMC**

地方AMC里重点看几家：

-   **浙商资产**：地方AMC的头部，市场化程度高，待遇在业内口碑很好，base杭州；

-   **山东金融资产、江苏资产、广州资产、深圳资产**：经济大省和一线城市国资背景，项目源充足；

-   **湖南财信资产、湖北资产、中原资产**等：省级国资控股，区域深耕，适合想回家乡发展的同学。

地方AMC的特点是：只能在本省展业，业务与区域经济深度绑定，所以**选地方AMC本质是在选省份**——经济大省的地方AMC，项目源和待遇都更有保障。

**五、应届生能投什么岗位**

从各家最新校招公告看，应届生开放的岗位主要五类：

1.  **业务开发/项目经理岗**：不良资产的收购、尽调、估值、管理、处置，以及问题企业纾困、房地产盘活等。出差多、成长快，全流程跟项目，是招人最多、锻炼最狠的岗位；

2.  **风险管理/业务审查岗**：交易结构审查、风险识别与防范；

3.  **法律合规岗**：诉讼执行、合规审查。AMC司法处置业务量大，**法考是硬加分项**；

4.  **财务/审计岗**：估值核算、报表编制、审计项目，CPA优先；

5.  **管培生与综合岗**：研究发展、人力资源、综合文秘、党建纪检等。另外注意一个新动向——中信金融资产2026年校招已开出**人工智能和数据应用研发岗**，行业数字化转型在创造新的岗位类型。

专业要求：金融、经济、财会、法律为主，同时明确欢迎理工背景——信达分公司的公告里，数学、物理、化学、生物、电子、计算机、机械、能源等专业都在招聘范围内，"金融+理工"复合背景是真加分。

**六、门槛和待遇**

**门槛**：总部岗位基本硕士起步，两财一贸及985为主；

分公司以重点院校硕士为主。持CPA、法律职业资格、CFA、注册资产评估师等证书者优先，其中**CPA和法考在AMC的含金量最高**——不良资产处置本质是财务+法律的活。有银行对公、券商、信托、AMC或破产方向律所的实习经历，加分明显。

**待遇**：四大AMC总部应届生第一年综合年薪（打包价）普遍在15万—25万元；分公司普通省份综合月薪1万元上下，业务大省和一线城市更高，年终奖与项目业绩挂钩；头部地方AMC待遇不输四大总部。福利是央国企顶配：五险一金之外还有补充医疗、企业年金，公积金顶格缴纳，另有交通、通讯、住房、工作餐等各项补贴，稳定性强。工作强度比投行温和，但项目周期长、出差较多。

横向看，这个待遇包的本质是"**央企的稳定性+投行的技能包**"，适合追求稳健起步、看重长期技能积累的同学。

**七、职业发展路径**

-   **起步**：校招/管培生进入，业务、风控、财务轮岗1—2年后定岗；

-   **专业线**：业务助理→项目经理→高级经理→业务总监，核心能力是"懂估值、会谈判、能抗压"；

-   **跳板价值**：这是AMC最值得关注的一点——不良资产处置、破产重整、重组并购的经验是金融圈的硬功夫，做几年后跳特殊机会基金、并购基金、信托、投行、企业投资部都有明确认可度。行业越往精细化处置转型，有完整项目经验的人越稀缺；

-   **一句话**：这是一个需要时间沉淀、"越老越吃香"的赛道，前三年学东西，五年后开始兑现。

**八、校招节奏与秋招准备（本章是实操重点）**

AMC校招和券商、银行有一个最大的不同：**没有全集团统一的网申入口和时间表，总部和各分公司各自发公告、各自收简历，节奏完全错开**。

信息分散是这个赛道最大的隐性门槛，很多人不是条件不够，而是根本不知道公告发了。

先把真实节奏摆出来（以2026届校招为样本）：

-   **9月中下旬**：中信金融资产总部秋招网申开启（9月18日—10月19日），这是五大里动作最早的；信达江西分公司等同月启动；

-   **10—11月**：信达各分公司公告密集发布，北京分公司11月14日—12月15日报名；

-   **12月**：信达山东等分公司截止（12月26日）；东方、长城总部及分公司陆续启动；

-   **次年2—4月**：补录和春招，信达安徽分公司2月24日—3月16日，中信金融资产春招4月17日—5月18日（含管培生）。

**流程**：报名→资格审查→笔试→性格/在线测评→多轮面试→**实习考察**→体检→**政审外调**→入职。

两个环节要特别提醒：一是部分公司设有**考察性实习**（信达山东等明确写入流程），实习表现直接影响录用；二是央国企金融机构的**政审外调和亲属回避**是硬程序，简历信息务必真实。

**笔试面试考什么**：笔试以行测类（言语、逻辑、资料分析）+ 专业题（金融、财务、法律基础）+ 性格测评为主，风格接近银行总行笔试；面试重点考察对不良资产行业的理解、财务法律基本功和沟通应变能力，**能聊出具体不良处置案例的人明显占优**。

**秋招实操建议（按时间线执行）**：

1.  **研一/大三暑假（6—8月）**：实习窗口。争取AMC分公司、地方AMC、银行资产保全部、破产重整方向律所的实习；CPA能考几科考几科。

2.  **9月**：建立**信息监控清单**——五大AMC官网的"人才招聘"栏目、目标分公司的页面、51job校招专区、国聘网，每周固定刷两次。注意信达等公司的特色：总部和33家分公司**分别发公告、邮箱投递**，错过一个页面就错过一个机会。

3.  **9—12月**：海投。策略是"总部冲一冲+目标省份分公司做主力+头部地方AMC保底+银行系AIC顺手投"。每人每司一般限报1—2个岗位，业务岗优先。

4.  **11月—次年1月**：笔面试期。行测提前刷题（和考公、银行笔试互通），专业部分重点复习财务分析、估值基础、破产法和不良资产处置流程。

5.  **次年2—4月**：春招补录。秋招没上岸的，春招（尤其管培生批次）是第二次机会，别放弃。

**九、什么样的同学适合去**

**适合**：目标金融核心圈但卷不动头部券商基金的；看重央企平台稳定性的；能接受出差、尽调跑现场、项目周期长的；愿意用前几年时间换一套硬核技能包的金融、法律、财会硕士。

**需要想清楚再来的**：追求短平快高起薪的、不想出差应酬的、期待"风口躺赢"的——这个行业没有躺赢，处置好每一笔资产靠的是真功夫。

**写在最后**

AMC是一个业务逻辑独特、逆周期属性鲜明的行业：它不靠市场行情吃饭，靠的是处置资产的专业能力。

它给不了你投行的高光起薪，但能给你央企的稳定性、一套"财务+法律+估值"的复合技能包，和一条越走越宽的退出路径。校招信息分散是它唯一的"隐性门槛"——而信息差，恰恰是最早准备的人的福利。
