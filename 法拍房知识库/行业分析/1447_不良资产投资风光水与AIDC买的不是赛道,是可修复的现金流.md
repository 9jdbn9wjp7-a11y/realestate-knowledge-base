# 不良资产投资风光水与AIDC：买的不是赛道，是可修复的现金流

风电、光伏、水电和AIDC都有重资产属性，但不能套用同一套抄底逻辑。真正值得收购的，是经营基础仍在、困境原因可拆解、追加投入可封顶的项目。投资人的工作不是证明行业有前景，而是把“谁付钱、凭什么收钱、修复多少钱、多久能退出”逐项核实，再决定买资产、买股权还是买债权。

# 一、先区分“股东缺钱”与“项目不赚钱”

建议优先筛选三类线索：原股东其他业务失血、项目被迫出售；资产仍有经营现金流，但到期债务过重；设备或运营失效，且修复成本可以验证。银行及AMC处置、司法拍卖、破产投资人招募和企业非核心资产转让，都是值得追溯的渠道，但必须回到原始公告核验标的范围。

风电要拆资源、设备与消纳；光伏要拆发电、用电客户与电价；水电要拆来水、生态约束与工程安全；AIDC即面向人工智能计算的数据中心，要拆供电、可交付容量与付费客户。资源耗竭、永久停运、客户需求不存在，不能归入“短期资金困难”。

筛选顺序建议固定为：能否合法经营、是否存在真实付款方、清障能否形成闭环，最后才是收益率。前三项任一缺少关键证据，应暂缓报价，不以调高折现率代替尽调。没有客户的机房与客户稳定但股东失血的机房，不能因都在拍卖而使用同一折扣。

# 二、先锁定资产边界，再讨论折扣

拟收购清单应分别列出土地房屋、设备、线路、合同、应收款及许可状态，并注明所有权人、使用期限、抵押或租赁关系。风机可能属于融资租赁公司，光伏屋顶不属于电站，GPU可能属于客户，水电取用水条件也不能当成永久产权。

行政许可原则上不得转让，法定例外须依条件和程序办理。因此，拍下设备或取得股权，不等于项目相关许可自动延续，更不能把法院裁定当作行政审批的替代品。

# 三、三种收购路径，分别测算代价

资产收购应核验资产能否完整交付，以及合同和手续能否承接；股权收购应穿透项目公司的债务、担保、税务和关联往来，另设SPV不会消除历史负债；债权收购应核验有效债权、担保范围、顺位及处置程序。债权受让人取得的是债权及相关从权利，不是当然的经营控制权。

签约前让法律、工程、运营和融资人员共同形成一页路径对比：总投入、最迟接管日、必要第三方同意、失败后的退款或止损安排。不可只比较名义成交价。

债权交易另核受让主体资格、出让方制度及公告限制；涉及国资、金融债权或破产财产的，先确认必要评估、公开交易及批准程序。交易结构的作用是分配风险，不是绕开交易规则。

# 四、把四类资产放进同一张现金流底表

统一采用实际回款，扣现金运营支出、现金税费、营运资金占用和必要维持性资本开支，先得到融资前的项目现金流。风光另拆机制结算和历史补贴，水电另做丰枯分季，AIDC另拆服务收入与代收电费。风光上网电价市场化后，历史结算价不宜直接外推。

报价上限可按未来可取得的净现金流现值倒推，再扣尚未纳入模型的整改投入与交易费用；从项目价值转成股权价，还要扣净债务等必要调整。折现率必须与现金流口径匹配，同一笔改造费、债务或应收款不得重复计算。

# 五、用交割条件限制投入，而不是只靠承诺

建议把付款分成权利交割、清障验收、经营验证三个阶段，分别绑定抵质押处理、关键合同承接、设备测试和实际回款。保留价款须有明确释放标准；长期无法完成前置条件，应约定可执行的解除及返还安排。司法处置则须服从公告和法院程序，不能套用私下分期。

股权交易还应核验控制权变更条款，防止银行提前收贷、客户解除合同或原运维商停止服务。接管预算至少覆盖必要运维、人员和安全支出，不能把收购款花完后再找维修资金。

形成“资料—责任人—截止日—付款影响”四列表：例如并网合同缺失由卖方补齐，设备检测由独立机构完成，银行同意函由融资方出具。文件未到位时，对应资金不得释放；必要经营费用可通过获授权的专户定向支付，但不能变成向原股东无条件输血。

# 六、退出先找买方，不先写估值倍数

向潜在电力运营商、基础设施投资人或数据中心运营商核实其收购门槛，再倒排整改和运营资料。把长期持有、整体出售和失败处置分别测算；未获确认的扩容、补贴、融资或资本市场退出，只能作为备选。

投决材料最终必须回答：困境是什么、由谁修、花多少钱、用什么证据验收。若只有行业增长故事，没有可核验的修复任务和回款来源，再低的折扣也不应成为出价理由。

进入投后后，应每月更新原收购假设：实际产出、实收单价、停运或空置、累计追加投入、剩余债务和最新退出净回款。若成本上升而回收不增，应按预设阈值重新投决；承认原方案失效，比维护一份漂亮的初始收益测算更重要。
