**某国外企业寻求国内合作**

✓

**公司简介**

**Krysteline专为材料加工行业提供定制型解决方案。**Krysteline以独特的内爆系统技术为核心，能够快速地对各种尺寸的材料进行处理，包括玻璃、陶瓷、矿物、矿石和炉渣等，且经济高效。Krysteline的内爆机（玻璃破碎机）以其独特的功能，将能量传导至目标原料，通过可控的力度，实现材料的高效分离。

✓

**公司优势**

**Krysteline的独特技术可以实现废玻璃的100%再利用。**

Krysteline在废物处理行业拥有超过20年的经验，设计并制造各类相关机械设备，其中涵盖简单的单机装置，以及多功能净化设备处理系统。不管玻璃废料的尺寸及质量如何，Krysteline都能为其提供合适的加工解决方案。除了与重熔行业合作之外，Krysteline独特的专利技术可以使玻璃废料得到100%的重新利用。

Krysteline的设备种类多样，能提供2吨/小时——30吨/小时不等吞吐量的加工设备。相关技术可作为独立操作中的独立部分、现有工厂的补充设备、或直接作为一站式方案交付给用户。

内爆玻璃破碎机可在将原料玻璃尺寸减小的同时不会破坏附属材料。重新生成的材料可通过一系列的筛分网、磁力分离器以及高温干燥器进行材料分离。

✓

**公司战略**

**Krysteline的战略是，发展可能的合作伙伴关系，将玻璃废料加工成高质量的最终产品。**

Krysteline将接近80%的技术和服务从英国总部和工厂进行出口，进一步加强了与海外分销商及代理商的战略联盟。Krysteline在广泛的市场和应用领域起主导地位，同时探索其技术的新用途。Krysteline的海外战略合作伙伴不仅具有强大的工程能力，同时在其专业领域具备相关精炼产品的专业知识。

✓

**合作需求**

Krysteline致力于发展牢固可靠的商业合作关系，面向中国开放: 技术加盟 / 合作建厂 / 设备销售等商业模式

**某新能源投资公司寻求光伏企业合作**

✓

**公司简介**

上海某新能源投资有限公司系集团系统二级公司，于2005年7月28日揭牌成立。截至2012年底，公司总资产逾千亿元，年营业收入约300亿元，连续11年位列中国企业500强。

公司在风能、太阳能、环保以及节能等领域的开发上均取得了实质性的突破，在上海可再生能源行业已初具影响力。

经过十五年的发展，特别是近三年的快速发展，公司新能源装机规模不断增长，已先后在上海、内蒙、河南、陕西、安徽、河北、湖南、江苏等地区开发、建设、运营了一批发电效益优良的新能源项目。
