# 什么是尽调？为什么买不良资产之前一定要尽调？

很多人第一次接触不良资产时，容易产生一个误解：“不良资产不就是打折出售吗？只要价格够便宜，买下来不就行了？”

实际上，真正进入特殊资产投资领域后，价格往往不是第一个需要回答的问题。

在决定买不买之前，更重要的问题是：

  【 这到底是一项什么资产？

它的债权是不是真的？

抵押物到底在哪里？

产权是否清晰？

有没有查封？

有没有其他抵押？

债务人还有没有偿债能力？

未来到底能不能处置？】

这些问题，都需要通过一个重要环节来回答：

尽调。

# 一、什么是“尽调”？

“尽调”是“尽职调查”的简称。

简单来说：

尽调就是在投资或者收购一项特殊资产之前，对资产的真实情况进行全面调查、核实和分析。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/qZALCc5RYFfPcIkojnJcRLDPrRAse4tiaaoXjuNFFhmmOcndkV34bacpRRJvKXbibcSvKEpLTOhXd0bsueaN3ibIZL5mqVMcCrJk8vQGxTrP2s/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=1)

如果把购买普通商品比作买一辆二手车，那么尽调就相当于：

查车辆登记信息→看维修记录→检查发动机→看有没有事故→判断真实车况→再决定多少钱可以买。

买不良资产也是一样。

只是调查的对象从一辆车，变成了：

债权+债务人+抵押物+法律关系+处置路径。

所以，尽调不是简单地“看看资料”。

而是要尽可能回答：

“这项资产真实是什么情况？”

以及：

“如果我接手，最终能够怎么处置？”

# 二、为什么买不良资产之前一定要尽调？

因为：

不良资产最大的风险，往往不是价格高，而是你根本不知道自己买到了什么。

举一个简单的例子。

某笔债权：

账面金额：1000万元

抵押物：

一套评估价值1500万元的商业房产。

乍一看，是不是感觉非常不错？

债权1000万。

抵押物1500万。

似乎“以房抵债”就可以解决问题。

但如果进一步尽调，可能发现：

房产虽然评估1500万元，但市场真实成交价只有1000万元左右；

同时存在其他查封；

抵押顺位也不是第一顺位；

商业物业还存在长期租赁；

债务人正在涉及其他诉讼；

实际处置周期可能需要数年。

这时候，原本看起来非常漂亮的资产，实际投资逻辑就完全改变了。

所以：

尽调的作用，就是把“看起来有价值”，变成“知道价值到底在哪里”。

# 三、尽调到底要查什么？

对于特殊资产来说，尽调通常不是只查一个方面。

可以简单理解为：

“五看”

第一看：看债权

首先要确认：

这笔债权到底是不是真的？

包括：

借款合同；

借据；

还款记录；

利息情况；

逾期情况；

债权金额；

债权转让情况；

相关交易文件。

因为投资人购买的往往首先是一项债权。

如果债权基础存在问题，后面的抵押物再漂亮，也可能产生重大风险。

所以第一步不是看房子。

而是：

先把债权关系搞清楚。

# 第二看：看抵押物

如果这笔债权有抵押物，那么就要重点调查：

抵押物到底是什么？

例如是一套房子，就要进一步确认：

房产位置；建筑面积；土地性质；权属情况；抵押登记；抵押顺位；查封情况；是否存在租赁；是否存在其他权利限制。

特别需要注意：

“有抵押”不等于“抵押物一定能顺利处置”。

抵押物有价值，只是第一步。

真正重要的是：

这个价值能不能最终转化成回款。

# 第三看：看债务人

很多人分析不良资产时，只盯着抵押物。

但实际上：

债务人本身同样重要。

需要调查：

企业为什么会出现风险？

是：

暂时性的资金链紧张？

行业周期下行？

经营失败？

融资结构出现问题？

还是企业已经基本失去经营能力？

如果企业还有经营价值，那么债务重组、引入投资人、恢复经营等方式都有可能成为处置路径。

反过来，如果企业已经没有实际经营价值，那么处置思路可能完全不同。

所以：

判断一笔不良资产，不能只看“有什么资产”，还要看“为什么会变成不良”。

# 第四看：看法律风险

这是特殊资产尽调中非常关键的一部分。

需要重点关注：

有没有诉讼？

有没有执行？

有没有查封？

抵押顺位是什么？

债权是否合法有效？

抵押权是否有效？

有没有其他权利人？

资产能不能正常处置？

这些问题往往直接决定资产未来的处置难度。

比如：

同样是一套市场价值1000万元的房子。

A房产：

产权清晰，没有复杂权利负担。

B房产：

存在多轮查封、多个权利主体、复杂租赁关系。

虽然两套房子的市场价格可能接近。

但对于投资人而言：

它们绝不是同一种资产。

# 第五看：看未来怎么退出

这是很多新手最容易忽略的问题。

很多人看到资产以后，第一反应是：

“这个资产多少钱可以买？”

但专业投资人往往会反过来问：

“我以后怎么把钱拿回来？”

这就是退出路径。

比如：

司法拍卖→协议转让→债务重组→以物抵债→资产盘活→重新运营→出售退出

不同的资产，需要匹配不同的退出方式。

如果一个项目买入价格很低，但未来根本没有清晰的退出路径，那么“便宜”本身并没有太大意义。

# 四、尽调真正解决的是一个核心问题

可以把整个尽调过程理解成一个公式：

资产表面价值≠ 实际投资价值

真正的投资判断，需要把：

资产价值

减去：

法律风险

处置成本

时间成本

资金成本

市场变化

再结合：

退出路径

最终才能判断：

这项资产到底值不值得买。

所以尽调实际上是在完成一个过程：

看到资产→看懂资产→识别风险→测算价值→判断能否处置→决定是否投资

五、为什么“不良资产越便宜”，反而越需要尽调？

这是一个很有意思的问题。

很多人认为：

“既然已经这么便宜了，风险应该也没什么了吧？”

恰恰相反。

![图片](https://mmbiz.qpic.cn/mmbiz_png/qZALCc5RYFdkKDTia7ak68giaAlOXZM1icrUS5TicwbKTZJ7ibgIHAKsYZUPZUQwOf4HtRBm6baT4NmibPYm7bn2yc5efdy3Hibdn7tERIylmT0XKI/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=2)

有时候：

资产越复杂，价格可能越低。

但价格低的背后，可能隐藏着：

产权问题；执行问题；债权问题；抵押问题；价值问题；处置周期问题；资金成本问题。

所以：

低价可能意味着机会，也可能意味着风险已经非常复杂。

专业投资人不是看到“三折”就兴奋。

而是会先问：

“为什么是三折？”

如果能够把这个问题解释清楚，才有可能进一步判断：

三折到底是真的便宜，还是只是看起来便宜。

# 六、尽调不是为了证明“这个项目能买”

还有一个非常重要的认知：

尽调并不是为了给投资找理由。

真正专业的尽调，应该允许投资人得出三个不同结果：

第一种：值得买

风险可控，价格合理，退出路径清晰。

第二种：可以谈，但需要调整价格

项目本身存在价值，但风险较高，需要通过价格折扣覆盖风险。

第三种：不值得买

即使价格看起来很便宜，也无法解决核心风险。

所以：

尽调的价值，不是帮助投资人“买下一个项目”，而是帮助投资人避免买错一个项目。

# 七、普通人如何理解“尽调”？

如果把买不良资产比作买一套房子。

普通买家可能只看：

地段+面积+装修+价格

而特殊资产投资者还要继续看：

债权+产权+抵押+查封+诉讼+执行+价值+成本+时间+退出

这就是为什么：

特殊资产投资不是简单的“低价买资产”。

它更像是在做一道复杂的判断题：

这个资产发生了什么？

风险在哪里？

风险值多少钱？

我有没有能力解决？

解决之后还能剩下多少价值？

# 结语

在特殊资产行业里，有一句话非常值得记住：

“尽调不是投资的附属环节，而是投资决策的一部分。”

一项资产看起来再便宜，如果没有经过充分调查，就很难知道：

你买到的是机会，还是风险。

而真正专业的投资者，也不会只问：

“这个资产多少钱？”

而会先问：

“这个资产到底是什么？”

因为只有把资产看懂，才能真正算清价格；

只有把风险看清，才能判断价值；

只有把退出路径想清楚，才知道这项投资到底有没有意义。

不良资产投资的第一步，从来不是“出价”，而是“尽调”。
