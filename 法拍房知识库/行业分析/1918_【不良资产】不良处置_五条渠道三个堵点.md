# 【不良资产】不良处置：五条渠道三个堵点
> 公众号: 产投融笔记
> 发布时间: 2026年10月11日 08:00

> **摘要**：银行不良余额保持高位，净息差收窄让利润核销空间变小，处置压力正在从"慢慢消化"变成"必须提速"。本文拆解五条处置渠道各自的代价、资本补充为什么是前提、中小银行为什么更难做，以及三个至今没打通的基础设施堵点。

## 一、压力从哪来：三重挤压同时发生

银行处置不良的紧迫感，来自三个方向同时收紧：

| 压力源 | 具体表现 |
| --- | --- |
| **不良余额高位** | 存量规模不小，且结构在变化——地产类、零售类、区域中小银行类都在释放 |
| **净息差收窄** | 依靠利润消化不良的空间变小，过去"用盈利慢慢核销"的路子在变窄 |
| **处置时效要求提高** | 风险出清节奏加快，拖延处置的代价上升 |

三者叠加的结果很直接：**过去可以"拖着等经济回暖"，现在拖不起了。** 批量转让、资产证券化这类能快速出表的手段，重要性明显上升。

## 二、五条渠道，各自的代价不同

| 渠道 | 怎么做 | 优点 | 代价 / 约束 |
| --- | --- | --- | --- |
| **现金清收** | 催收、诉讼、执行、处置抵押物 | 回收率相对高 | 周期长、司法依赖重 |
| **呆账核销** | 用拨备和利润冲销 | 出表最彻底 | 消耗资本与利润，需符合税前列支条件 |
| **批量转让** | 组包转让给资产管理公司 | 快速出表、回收确定 | 折扣率较高，需真实洁净转让 |
| **资产证券化** | 打包发行不良资产ABS | 出表+回收部分资金 | 门槛高、成本高，适合标准化资产 |
| **重组 / 债转股** | 债务重组、以股抵债、引入投资人 | 可能回收更高 | 周期长、管理参与度要求高 |

**选择哪条路，本质上是在"回收率、速度、资本消耗"三者之间做取舍。**

现金清收回收高但慢；核销最快但吃资本；批量转让折价但确定；ABS 优雅但门槛高；重组潜在回报高但需要能力。多数银行的实际做法是组合使用——按资产类型分类处置。

## 三、资本补充是前提，不是配套

政府工作报告提出拟发行特别国债支持国有大型商业银行补充资本；金融监管部门也提出研究多元化补充中小金融机构资本。

这件事和不良处置是什么关系？

**资本是处置能力的天花板。** 核销要消耗拨备和资本，转让折价形成的损失也要资本吸收。资本不足，银行即便想处置也没有空间——不良只能挂在账上。

所以补充资本不是"锦上添花"，而是**为处置腾出空间的前置动作**：资本厚了，才敢核销、才敢折价转让、才敢把风险真正出清。

## 四、中小银行为什么更难

同样是处置不良，大行和中小银行面对的完全不是一道题：

| 维度 | 国有大行 | 中小银行 |
| --- | --- | --- |
| 资产结构 | 相对标准化，易组包 | 结构复杂，抵质押物不规范 |
| 议价能力 | 资产包规模大，买方竞争激烈 | 单包小、分散，议价弱 |
| 处置渠道 | 多元化 | 依赖本地资源 |
| 司法效率 | 跨区域协调能力较强 | 受属地司法环境影响大 |

更现实的问题是：**中小银行的不良里，抵押物往往不够标准。** 房产可能有瑕疵、土地性质复杂、保证人多而分散、债权文件不完整。这类资产组包时定价难，买方尽调成本高，最后只能大幅折价。

有观点指出，要打通中小银行不良处置的"最后一公里"，需要强化地方政府属地责任、加快司法处置效率——**这不是银行一家能解决的事。**

## 五、思路要变：从"事后处置"到"全生命周期"

有业内专家提出，银行不应把不良资产管理停留在事后被动处置，而应将风险管控前移，构建贯穿贷前、贷中、贷后的全生命周期管理机制，以主动经营思维替代消极清收导向。

这个转变落到操作层面，是三件事：

**第一，贷前就把"好不好处置"考虑进去。** 一笔贷款发放时，抵押物的变现难度、保证人的可执行性、债权文件的完整性，就已经决定了将来处置的难易。这些在放款时是可控的，出险后则不可逆。

**第二，贷中持续跟踪而不是等到逾期才动。** 早期预警、提前介入、主动重组，成本远低于事后清收。

**第三，把自己放进生态而不是独自消化。** 有条件的不应只把自己定位为不良资产的被动持有者，而应主动成为特殊资产生态圈的节点——与资产管理公司、特殊资产投资人、资产服务商、产业投资人、司法与拍卖渠道、律所、评估机构协作，形成分工明确的处置合力。

## 六、三个没打通的基础设施堵点

**堵点一：估值定价。** 不良资产的定价缺乏统一标准，买卖双方信息不对称严重，定价往往靠经验而非模型。这导致成交率低、议价成本高。

**堵点二：信息披露。** 资产包的底层信息透明度不足，买方尽调成本高、周期长，反过来压低报价。

**堵点三：司法协作。** 诉讼、执行、拍卖各环节的效率，直接决定处置周期。司法资源紧张地区，一笔抵押物处置拖上数年并不罕见。

这三条都不是单个机构能推动的，属于行业基础设施。**但它们决定了处置效率的上限。**

## 七、核查清单（买方视角）

| 核查项 | 具体动作 | 高危信号 |
| --- | --- | --- |
| 债权文件完整性 | 核查合同、借据、凭证、担保文件、催收记录 | 关键文件缺失 |
| 诉讼时效与执行时效 | 逐一核对，确认未过时效 | 多年未催收、时效中断证据不足 |
| 抵质押物状态 | 核实权属、查封顺位、实际占用情况 | 存在在先查封、长期租赁占用 |
| 保证人可执行性 | 核查保证人现状与财产线索 | 保证人失联或无财产 |
| 债务人经营状况 | 核实是否持续经营、有无重整可能 | 已停产、涉多起执行 |
| 转让合规性 | 确认真实洁净转让，无抽屉回购安排 | 附带回购或隐性担保 |

最后一条是底线。监管对不良资产转让的真实性要求很明确——抽屉回购、虚假出表是被明令禁止的行为。

## 八、分类处置的实务思路

| 资产类型 | 建议方向 |
| --- | --- |
| 抵押物优质、权属清晰 | 优先自行清收，回收率最高 |
| 抵押物有瑕疵但债务人有经营能力 | 考虑重组，争取持续经营价值 |
| 分散、小额、无抵押 | 批量转让或证券化，快速出表 |
| 涉及停工项目、债权关系复杂 | 引入产业投资人，走重整路径 |

核心原则是：**别用同一种方式处理所有资产。** 分类越细，整体回收率越高。打包一股脑卖掉最省事，但往往也最亏。

还有一个趋势值得注意：**处置能力正在成为差异化竞争力。** 同样是不良资产，有的机构能挖出重组价值，有的只能打折卖掉。差距不在资金成本，而在产业理解、司法资源和处置网络——这些都是长期积累，短期补不齐。
