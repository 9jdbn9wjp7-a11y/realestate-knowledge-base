# 一、从「打骨折」到「拼手速」，剧本换了

2025年，法拍房还是一幅「量价齐跌」的图景：全年挂拍 71.9万套，同比下降6.6%；成交16.9万套，下降4.4%；成交金额2536.2亿元，下降23.6%；平均折价率74.1%，清仓率仅23.5%。不少房源要经历一拍、二拍甚至变卖，层层降价才等来一个买家。

但剧本在2026年春天换了。3月，常州武进一套198平方米住宅，起拍价198万元、评估价283万元，最终19人报名、80轮竞价，以近440万元落槌，较起拍价溢价122%，比评估价还高55%。同期上海徐汇滨江一套法拍住宅以5071万元成交，23人报名、92轮竞价，成交价较评估价高出14%。

平台数据也印证了热度：3月第四周，北京法拍房成交率升至71%、平均溢价率16.18%，上海为71%与17.28%，深圳成交率62%、平均溢价率超过20%。

从「折价甩卖」到「溢价争抢」，背后是二手房阶段性回暖与核心资产预期的修复。对购房者而言，第一件要放下的事，就是把法拍房和「七折」画等号。

# 二、65.4万件与24.4%：放量不等于好买

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MEprVJBIvrQBfRXQp1hfqcAuibEian0GDc7aams3ibl1h72bKy8X2yCqscdicRHAZnLgJXHqepSRmDicdVF07ItooicKy7lSoWGZdzNj3199ytgL0/640?wx_fmt=jpeg&watermark=1#imgIndex=1)

▲ 配图2｜供给放量，但成交金额增速明显落后于件数增速

中指研究院11月9日发布的监测，给出了今年最完整的一张切面：2026年1—10月，全国355城累计挂拍各类法拍房源 65.4万件，同比增长31.6%；成交18.8万件，同比增长34.6%；成交总金额2552.8亿元，同比增长19.0%；整体清仓率24.4%，较上年同期提升1.6个百分点；成交折价率74.3%。

把三个增速并排看，信息量比总量更大：件数涨了三成四，金额只涨了一成九。中间这十几个百分点，是「以价换量」留下的缺口——放量的主力是单价更低的房源与更深的折让，而不是价格整体回升。

另一组数字同样值得留意：每100件交易截止的拍品，最终成交的只有约24件。住宅是绝对主力，成交13.7万件、同比增长46.6%，清仓率38.4%；而商业仅16.3%，车库／车位只有9.2%，超过九成流拍。住宅成交均价7974元／平方米，同比下降6.4%。

结论并不复杂：供给在放量，流动性在改善，但定价权仍握在买方手里。这叫存量出清加速，不叫行情反转。

# 三、74.3%的另一面：一线收窄，三四线深折

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MEprVJBIvrT9ibHVPZ8jD8w0SH8eQNceIglkiaaDmWe0jQnsWia1aHaAJP2bIkMRRUSicn82pumOBLmGV7eicpO4JuHMTXXJ5sFyZGz5ZE3cggN0/640?wx_fmt=jpeg&watermark=1#imgIndex=2)

▲ 配图3｜同样是法拍住宅，不同城市的去化效率相差近32个百分点

「法拍房普遍打七折」是流传最广的误读。74.3%是全国平均折价率，它掩盖的是一场剧烈的结构分化。

按城市能级拆开：1—10月一线城市法拍住宅清仓率 64.2%，成交均价33293元／平方米；三四线城市清仓率仅32.5%，均价4805元／平方米，两者相差近32个百分点，二线居中。重点城市更能说明问题——深圳以154.2亿元成交金额居首，清仓率71.0%，成交折价率92.4%，几乎贴着评估价成交；上海清仓率79.4%，北京53.8%。上半年一线城市法拍住宅清仓率60.9%、均价33369元／平方米，杭州超过69.6%，而三四线仅约29.7%。

换句话说，折价从来不是统一发放的折扣券，而是资产流动性的价格。区位优越、配套成熟、产权干净的标的，正被真实竞争把价格推回市场价；远郊、房龄老、有硬伤的房源，即便折上再折，也未必等得到买家。

对普通购房者的含义很直接：别用「相对评估价打了几折」做决策，要用同小区、同户型近三个月的二手房真实成交价做锚。评估价是参考，市场价才是标尺。

# 四、渠道只有一条正路：认准名单库

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/MEprVJBIvrTcdI1aZBT35UHCZRsHszSvSkde1Hc0AZjLXBQEEJZMzDmVOCWl8vibAeXJxm2dc2KRcQKJu39WYUwpibgIY3Rep0EQ8ic8ZfZMA8/640?wx_fmt=jpeg&watermark=1#imgIndex=3)

▲ 配图4｜全流程公开，不存在「内部房源」与官方佣金

先厘清概念：法拍房是人民法院在执行程序中，依法对被执行人财产强制变价以清偿债务的房产，不是中介口中的「特殊房源」。2017年起，网络司法拍卖全面替代传统委托拍卖，房源公示、竞价、成交全程在线公开、接受监督。

渠道只有一条正路：最高人民法院网络司法拍卖平台名单库。各地法院常用的入口包括淘宝（阿里资产）、京东拍卖、人民法院诉讼资产网、公拍网、中国拍卖行业协会网、北京产权交易所等，具体以执行法院公告和名单库为准。

规则也是透明的：不动产拍卖应提前30日公告；竞价周期24小时，倒计时最后5分钟内有人出价即自动延时5分钟；一拍起拍价不得低于处置参考价或市价的70%，流拍后二拍最多再降20%；保证金一般为起拍价的5%—20%，未竞得原路退还。

请记住三句话：没有「内部房源」，法院不向买受人收取看房费与佣金，凡以「包低价」「包腾房」「法拍服务费」「代办贷款」名义收费的，均非官方安排。更有个别机构诱导用经营贷、消费贷凑尾款，这条路风险极高，务必远离。

# 五、政策三条线：限购、税费、贷款

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/MEprVJBIvrTD3gP9iaIMeelbcMq7y2ibKA3srJfwZaia98yW02EKC9GekkWk18jC7neVZHPo89PPQBqGMXg9ywpf9POYXzU1vClKWxf19X5Ll4/640?wx_fmt=jpeg&watermark=1#imgIndex=4)

▲ 配图5｜折扣是结果，总账才是成本

限购。最高人民法院《关于人民法院司法拍卖房产竞买人资格若干问题的规定》（法释〔2021〕18号）自2022年1月1日起施行：司法拍卖房产受所在地限购政策约束，不具备资格的竞买人法院不予准许；成交后出具裁定前要审核资格证明，虚构资格可能导致拍卖无效并承担赔偿，情节严重的还会被罚款、拘留乃至追刑责。「买法拍房绕开限购」早已是旧剧本。

税费与欠费。依《网络司法拍卖若干问题的规定》第30条，税费原则上由法定主体各自承担，公告另有约定的从约定。实操中买受人常需先垫付原业主税费，再凭票据向法院申请从案款中退还；划拨土地、历史过户还可能产生土地出让金。物业、水电暖欠费按公告处理，法律上属原业主债务，垫付后可依法追偿。

资金与贷款。多数标的仍要求成交后短期（常见7—15日）付清全款，法院不兜底银行审批。好消息是2026年门槛在松动：杭州省直公积金法拍贷最高306万元、最低利率2.1%，肇庆操作细则自8月15日实施，北海推出「带封过户＋带封抵押」，苏州、中山、常州等地也已试点。但放款时滞与法院付款期限的错配，仍要开拍前完成预审并备足备用金。

# 六、从举牌到拿房：规则边界在哪里

补一颗定心丸：拍卖成交裁定送达买受人时，物权即发生转移，不必等过户办结。凭《拍卖成交裁定书》《协助执行通知书》《成交确认书》三份文书，可单方前往不动产登记中心办理过户，无需原房主出面配合；裁定送达后应及时办理登记，久拖产生的税收滞纳金由买受人自担。

交付方面，法院以腾退交付为原则，不清场为例外。对拒不搬离的占有人，执行法院可依法强制腾退；但「买卖不破租赁」、已登记的居住权、案外人实际占用等法定情形，会拉长收房周期。查封或抵押在先、之后倒签的长期租约，不能对抗拍得人，但仍需提前向法院核实占有情况与腾退预案。

最后是悔拍的代价：保证金不予退还，若二次拍卖成交价低于原价，还需补足差额，且不得再参加该标的竞买；恶意哄抬价格、阻碍处置的，可被罚款、拘留，构成犯罪的依法追责。竞价前设好心理上限，比事后后悔便宜得多。

# 七、七道尽调：把「便宜」换算成「总账」

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MEprVJBIvrRYWo5luhbDibv0OIfRsaoJD2MJwZNuLhNmunOknvjFvuedyajueibQpdwf210TVvjh0zicBfnd2epCvBffaDqscSzRDcY6yog8g8/640?wx_fmt=jpeg&watermark=1#imgIndex=5)

▲ 配图6｜功课做在举牌之前，折扣才真正属于你

第一，逐字读完拍卖公告、竞买须知、标的物调查表与瑕疵提示，那是这套房子的「体检报告」。第二，实地看样，确认是否有人占用、装修是否破损、有无渗漏与违建，图片不等于全貌。第三，到不动产登记部门核产权性质、土地出让金、抵押查封与居住权登记。第四，核租约备案与实际占有，警惕倒签长期租约。

第五，算总账：成交价＋税费＋历史欠费＋维修基金＋翻新成本＋腾退时间成本，再与同小区二手房真实成交价对比，只有综合总价仍有明显优势才值得参与。第六，落实资金：保证金比例、尾款期限、贷款预审、备用金，一并留出约两成缓冲。第七，确认法院腾退预案，优先选择公告写明「已腾空」「空置」「法院负责交付」的标的。

一句话：法拍房低价是风险折价，收益来自尽调与信息差，不是闭眼抄底的捷径。

# 结语：值得买吗？答案在人不在房

值得，但有前提。它更适合资金充足或已锁定合规贷款、有时间实地尽调、只瞄准人口净流入城市核心板块、以自住为目的、能接受交付周期的购房者；不适合高杠杆、依赖放款时点、无暇看样、只想短炒，或把「七折」当收益承诺的人。

从行业视角看，法拍放量是存量出清的一环，它对市场预期的影响大于其成交占比。2026年「挂拍、成交双增，金额增速落后」说明买方仍占定价主动，但核心资产已率先出现竞争；更深一层的变化，是司法处置与住房保障的衔接——广州南沙88套法拍住宅今年初全部成交，其中超60套由属地国企拿下，业内预判后续或改造为保障房、人才公寓。资产处置正在被纳入更大的住房供给框架里。

所以，真正该问的不是「能不能捡漏」，而是「这套房子的风险，我是否算得清、扛得住」。读懂市场，先读懂价格背后的风险。
