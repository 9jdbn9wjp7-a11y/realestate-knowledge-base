模块一：贷后管理与风险预警

教学目标：掌握贷后检查流程优化方法，建立存量贷款动态监控与风险信号识别能力，构建高风险客户分类管理与干预机制。

1.1 贷后检查流程优化与关键节点控制

l贷后检查的制度依据与基本框架

l贷后检查的类型：首次检查、日常检查、特别检查

l关键节点控制清单：

¡资金用途核实与流向追踪

¡还款来源变化监测

¡担保物价值变动与权属状态

¡借款人经营状况与财务指标异动

¡关联人与关联交易变化

l贷后检查报告的标准化撰写要点

l常见问题：贷后检查流于形式、检查频次不足、问题未及时上报

l【案例】某农商行因贷后检查不到位导致不良暴露延迟的教训

1.2 存量贷款动态监控与风险信号识别

l存量贷款动态监控的体系框架

l风险信号的六大维度：

¡财务信号：现金流恶化、负债率攀升、利润下滑

¡非财务信号：管理层变动、涉诉涉访、环保处罚

¡行业信号：行业景气下行、政策调控影响

¡担保信号：抵押物贬值、保证人代偿能力下降

¡交易信号：结算归行率下降、资金他用

¡外部信号：工商异常、税务欠缴、征信恶化

l风险信号分级：关注类、预警类、高危类

l风险信号触发后的处置路径与时效要求

l【演练】根据案例企业财务与经营数据，识别风险信号并分级

1.3 高风险客户分类管理与干预机制

l高风险客户的分类标准：按风险程度、按担保方式、按行业特征

l分类管理策略：

¡重点监控类：提高检查频次，加强担保物跟踪

¡预警干预类：约谈、追加担保、压缩授信

¡退出清收类：制定退出方案，启动保全程序

l干预工具箱：风险提示函、贷款重组、提前收回、诉讼保全

l早期干预的成本收益分析：早干预 vs 晚处置

l【研讨】本行高风险客户管理现状与改进方向

模块二：不良贷款清收实务与激励机制

教学目标：掌握不良贷款成因分析方法，制定清收策略，熟练运用非诉催收与司法清收手段，掌握谈判技巧，设计清收激励机制。

2.1 不良贷款成因分析与清收策略制定

l不良贷款成因的多维分析框架：

¡借款人因素：经营失败、恶意逃废债、突发变故

¡银行因素：贷前调查不实、贷后管理缺位、风险识别滞后

¡外部因素：行业周期、宏观政策、疫情等不可抗力

l成因分析与清收策略的匹配：

¡有还款能力无还款意愿 → 施压清收

¡有还款意愿无还款能力 → 重组盘活

¡无还款能力无还款意愿 → 司法处置

¡恶意逃废债 → 打击追责

l清收策略制定的"一户一策"原则

l【案例】三户不同成因不良贷款的差异化清收策略

2.2 非诉催收技巧与司法清收流程衔接

l非诉催收的层次递进：

¡第一层：电话催收与短信提醒

¡第二层：上门催收与面谈施压

¡第三层：律师函催收与告知后果

¡第四层：关联人催收与社会关系施压

l非诉催收的合规边界：禁止暴力催收、禁止骚扰无关第三人、禁止违法公开信息

l司法清收流程衔接：

¡诉讼/仲裁 → 财产保全 → 判决/裁决 → 强制执行

¡支付令、实现担保物权特别程序等快捷路径

¡执行中的查封、拍卖、以物抵债衔接

l非诉转司法的时机判断与证据准备

l诉讼时效管理：主债权诉讼时效、保证期间、抵押权行使期限

l【案例】一户从非诉到司法的全流程清收复盘

2.3 清收过程中的沟通与谈判技巧

l谈判前的准备：债务人画像、资产线索、底线与目标

l谈判策略框架：

¡强硬策略：适用于有还款能力拒不清偿的债务人

¡瓦解策略：适用于有内部矛盾或关联人可施压的情形

¡共识策略：适用于有还款意愿、需协商方案的债务人

¡极限施压策略：适用于恶意逃废债的债务人

l关键谈判技巧：

¡开局定调与节奏掌控

¡锚定效应与让步节奏

¡沉默施压与情绪管理

¡最后通牒的适用与风险

l常见谈判陷阱与应对：拖延战术、哭穷示弱、转移资产威胁

l【演练】模拟与债务人谈判场景，分组点评

2.4 清收激励机制设计与绩效考核

l清收激励的必要性与制度定位

l激励机制设计的核心要素：

¡激励对象：清收责任人、协助人员、外部合作方

¡激励方式：现金奖励、绩效考核加分、职级晋升通道

¡激励标准：按清收金额、清收难度、清收时效差异化设定

¡激励兑现：清收到账后兑现的流程与风控

l绩效考核体系设计：

¡不良率与拨备覆盖率的考核权重

¡清收完成率与时效考核

¡过程指标与结果指标结合

l常见激励失效原因：标准模糊、兑现拖延、内部不公平

l【案例】某农商行清收激励机制改革后清收率提升 23% 的实践

模块三：多元化不良资产处置方式

教学目标：掌握债务重组、以物抵债、核销、批量转让等多元化处置方式的实操要点，学会设计综合处置方案并进行风险控制。

3.1 债务重组、以物抵债、核销等处置方式实操

l债务重组：

¡重组的适用情形：借款人经营有望改善、短期流动性困难

¡重组方式：展期、借新还旧、调整利率、变更担保、债转股

¡重组的风险分类认定：重组贷款的分类规则（2023 年新规要点）

¡重组中的法律文书与风险控制

l以物抵债：

¡抵债资产的范围与限制：不得抵债的资产类型

¡抵债金额的确定：评估、税费、折扣

¡以物抵债的会计税务处理

¡抵债资产的后续处置：出租、出售、自用

l核销：

¡核销条件：符合"账销案存"要求

¡核销证据材料：追索证明、法院终结裁定等

¡核销后的账销案存管理与继续追索

l各处置方式的比较：周期、成本、回收率、合规要求

l【案例】同一笔不良贷款用不同处置方式的回收率对比

3.2 不良资产批量转让的流程与合规要点

l批量转让的政策框架：《金融企业不良资产批量转让管理办法》（财金〔2012〕6 号）

l批量门槛演变：10 户 → 3 户（银监办便函〔2016〕1738 号）

l不良贷款转让试点：银保监办便函〔2021〕26 号、〔2022〕1191 号

l批量转让全流程操作：

¡资产组包策略：区域/行业/担保方式/关联债务人

¡尽职调查与档案管理

¡估值定价：假设清算法、现金流折现法、市场比较法

¡挂牌与竞价（银登中心机制）

¡合同签订、档案移交、债权转让通知

¡会计出表与税务处理

l合规红线：虚假出表、隐性回购、清仓返租、违规向个人转让

l【处罚案例】近年银保监局对不良转让违规的典型处罚解读

3.3 处置方案设计与风险控制

l处置方案设计的"一户一策"原则

l综合处置方案：单一方式 vs 组合方式（如重组+转让、抵债+出租）

l处置方案决策要素：

¡回收率最大化与处置周期平衡

¡合规性与监管可接受度

¡税务成本与会计出表效果

¡内部审批流程与权限

l风险控制清单：方案合规性审查、关联交易排查、利益冲突回避

l【研讨】给定不良资产案例，分组设计综合处置方案并汇报

3.4 案例分享：成功处置模式解析

l案例一：某城商行通过批量转让一次性出表 8.6 亿元不良的组包与定价策略

l案例二：某农商行以物抵债+资产经营盘活，将不良率下降 2.3 个百分点

l案例三：某银行"重组+债转股"模式盘活困难企业的全流程

l成功模式的共性提炼：方案精准、执行坚决、合规底线守牢

模块四：债权转让法律实务与合规要求

教学目标：掌握债权转让的法律依据与监管政策，熟悉评估、审批、披露、登记全流程，掌握风险隔离与表外管理要点，识别常见法律纠纷与防范措施。

4.1 债权转让的法律依据与监管政策

l《民法典》债权转让规则精讲：

¡第 545 条：可转让性判断；约定不得转让的效力

¡第 546 条：通知主义——未通知对债务人不生效力

¡第 547 条：从权利随主债权转移（担保权、抵押权、利息债权）

¡第 548-549 条：债务人抗辩权与抵销权

¡第 550 条：因转让增加费用的负担

l监管政策框架：

¡《金融企业不良资产批量转让管理办法》（财金〔2012〕6 号）

¡不良贷款转让试点：银保监办便函〔2021〕26 号、〔2022〕1191 号

¡银监发〔2016〕82 号：信贷资产收益权转让的合规要求

¡《海南会议纪要》（法发〔2009〕19 号）：国有银行不良债权转让特殊规则

l可转让资产范围与负面清单

l受让主体限制：批量转让受让方限于 AMC；禁止转让给个人

4.2 转让流程：评估、审批、信息披露、登记

l评估环节：

¡评估机构的选择与资质要求

¡估值方法的选择与适用：假设清算法、现金流折现法、市场比较法

¡评估报告的审核与使用

l审批环节：

¡内部审批链条：资产保全部→风险部→审贷会/资产负债委员会

¡审批权限分级：按金额、按资产类型

¡审批材料清单与质量要求

l信息披露环节：

¡公开转让的信息披露要求：内容、渠道、时限

¡银登中心挂牌披露机制

¡信息披露不实的法律后果

l登记环节：

¡应收账款质押登记的变更与注销

¡抵押权变更登记的办理

¡登记瑕疵的处理与补救

l【案例】某银行债权转让登记瑕疵导致抵押权丧失的教训

4.3 转让中的风险隔离与表外管理

l风险隔离的核心要求：风险与报酬实质转移

l表外管理的条件判断：

¡保留风险敞口的识别：回购义务、担保义务、服务承诺

¡不洁净出表的识别：隐性回购、清仓返租、附带回购条款

l虚假出表的监管认定与处罚案例

l转让后的持续管理：

¡档案移交清单与交接确认

¡通知债务人、保证人、抵押人的证据固定

¡转让后台账管理与回溯机制

l【案例】某银行因隐性回购被认定为虚假出表的处罚分析

4.4 常见法律纠纷与防范措施

l转让合同效力争议：

¡恶意串通、损害国家利益、违反强制性规定的认定

¡国有资产转让程序瑕疵的效力影响

l债务人抗辩与反制：

¡"未收到通知"抗辩：通知方式与证据

¡诉讼时效抗辩：时效衔接管理

¡抵销权主张：债务人对原债权人的抗辩能否向受让人主张

l涉诉债权转让的特殊问题：

¡诉讼中变更原告的程序与材料

¡执行中变更申请执行人的程序

¡破产债权的转让与申报

l利息争议：

¡受让人主张受让日后利息的司法立场（海南会议纪要规则）

¡针对国有企业债务人的利息限制

l防范措施清单：

¡转让前尽职调查清单

¡转让合同条款审查要点

¡通知证据固定标准

¡诉讼主体变更的操作规范

l【案例】典型债权转让纠纷案件裁判观点解析

模块五：风险管理数字化与科技应用

教学目标：理解大数据与 AI 技术在风险预警、贷后监控与清收中的应用路径，掌握数字化风控平台的建设方向。

5.1 大数据在风险预警中的应用

l大数据风控的基本逻辑：数据维度扩展 + 模型自动识别 + 实时预警

l外部数据源的整合应用：

¡工商、税务、司法、海关、社保等政务数据

¡征信系统与反欺诈数据

¡行业景气与产业链数据

¡舆情与社交媒体数据

l风险预警模型的设计：

¡规则引擎：阈值触发型预警

¡机器学习模型：违约概率预测模型

¡知识图谱：关联关系风险传导识别

l预警信号的分级推送与处置闭环

l【案例】某银行大数据预警模型上线后不良率下降 1.8 个百分点

5.2 AI 技术在贷后监控与清收中的实践

lAI 在贷后监控中的应用：

¡智能贷后检查：OCR 识别 + 自动报告生成

¡担保物智能监控：卫星遥感 + 图像识别监测抵押物变化

¡资金流向追踪：图计算识别资金违规挪用

lAI 在清收中的应用：

¡催收智能分案：AI 评估催回概率，匹配最优催收策略

¡智能外呼催收：语音合成 + 对话机器人初筛

¡资产线索挖掘：AI 抓取公开信息关联债务人隐匿资产

lAI 应用的合规边界：算法公平性、数据合规、人工复核机制

l【案例】某银行 AI 清收系统将催回率提升 15% 的实践

5.3 数字化风控平台建设路径

l数字化风控平台的架构分层：

¡数据层：内部数据 + 外部数据 + 数据治理

¡模型层：预警模型 + 评级模型 + 处置模型

¡应用层：贷后监控 + 风险预警 + 清收管理 + 处置决策

¡管理层：驾驶舱看板 + 报告自动生成 + 审批流程

l平台建设的分阶段路径：

¡第一阶段：数据整合与基础预警

¡第二阶段：模型迭代与场景化应用

¡第三阶段：智能决策与自动化闭环

l中小银行的务实路径：轻量化、SaaS 化、合作共建

l建设中的关键挑战：数据质量、模型可解释性、业务与技术协同

l【研讨】本行数字化风控建设的现状与下一步方向
