# 一个「捡漏」故事（示例情景）

王先生以240万拍下一套评估价320万的法拍房，比同小区挂牌价低了近80万。付清全款、办完过户，他拿着房产证去收房时，门开了——里面住着一位七旬老人，拿出一份签署日期早于查封的《房屋租赁合同》，租期20年。房子是他的，但钥匙不在他手里。

这不是段子，而是法拍房交易中最常见、也最棘手的一类纠纷：腾退风险。

# 01｜为什么腾退是法拍房的第一大坑

法拍房的价格折扣，本质上是对风险的定价。而这些风险里，腾退是最难量化的一个。

问题的根源在于一条法律原则——「买卖不破租赁」：

《民法典》第七百二十五条：租赁物在承租人按照租赁合同占有期限内发生所有权变动的，不影响租赁合同的效力。

翻译成大白话：如果房子在拍卖前就已经合法租出去了，你拍下房子成为新业主，原租约依然有效，你得继续让人家住。

更麻烦的是，法院的「交付」和买受人的「入住」是两回事。法院多数情况下负责裁定过户与清场交接，但并不当然负责把占住的人强制迁出——尤其是涉及租约、案外人主张权利的情形。这部分往往要买受人自己去解决。一句话：你买到了所有权，但未必买到了「使用权」。

# 02｜三种占用情形，难度天差地别

不是所有腾退都一样难。竞拍前先判断属于哪一类，风险等级完全不同：

①原业主或家属自住（风险：中）债务人本人或亲属占用，通常不涉及租约。法院清场阻力较小，配合度高的话可在数周内完成。这是最常见、也最好解决的一类。

②真实长期租约（风险：高）租赁合同签订在查封之前、租金真实支付、承租人实际占有。租约受法律保护，你可能要等租约到期，或与租户协商「买断」租赁权——这是一笔额外的、公告里不会写的成本。

③虚假租约/案外人占住（风险：极高）为对抗执行而倒签的租赁合同，或非承租人的第三方占住。这类情形需要诉讼确认合同效力、另行提起返还原物之诉，周期可能长达数月甚至更久，且结果存在不确定性。

# 03｜公告里藏着答案：怎么读腾退条款

很多人只看起拍价和面积，却跳过了公告里最关键的几行字。

重点看这几个关键词：

-   「法院负责腾退交付」—— 相对友好，由法院主导清场；

-   「买受人自行腾退」—— 高风险信号，意味着收房靠自己；

-   「带租约拍卖」「租赁情况详见附件」—— 必须追查租约内容与期限；

-   「不保证交付时间」「按现状交付」—— 把时间风险明确转嫁给了买受人。

示例条款对比（示例文本，仅作说明）：

A 房源：「本院负责腾退并于成交后六个月内交付买受人。」

B 房源：「标的物以现状交付，腾退事宜由买受人自行解决，本院不予负责。」

同样的折扣，A与B的实际价值可能相差数十万。读公告时，请把腾退条款和价格放在同一栏里比较。

# 04｜竞拍前必做的 5 项排查

①实地看样，且要看「人」不只看房子状况，更要看是否有人居住、门口是否有生活痕迹、信箱是否有租户姓名。

②走访物业与邻居物业最清楚谁在住、住了多久、有没有纠纷。这是成本最低、信息量最大的一步。

③查租约备案与查封时间关注租赁合同签订时间是否早于查封。倒签、超长租期（如15年以上）、明显低于市场价的租金，都是危险信号。

④直接询问执行法院承办法官对占用情况通常有基本判断，可咨询腾退安排与既往处理惯例。

⑤做「最坏情况」成本测算假设收房要打一场官司：诉讼费、律师费、延期交房期间的租金或房贷、时间成本——把这些折算进去，再判断这个折扣是否真的划算。

# 05｜万一拍到了占用房：补救路径

如果已经竞得且存在占用，常见路径有三条：

·协商优先：与占用人沟通补偿搬离，通常是最快、成本最低的方式；

·确认之诉：对存疑租约提起诉讼，请求确认合同无效或不具对抗效力；

·返还原物之诉：取得生效判决后申请强制执行腾退。

要提醒的是：这些路径都意味着时间。在资金和居住安排上，务必为「拿不到房」预留缓冲。

# 06｜写在最后

法拍房的便宜，从来不是白给的。

腾退风险之所以值得单开一篇来讲，是因为它直接决定了一件事——你买到的到底是一套房子，还是一场官司。把腾退条款读出弦外之音，把占用情况查到心里有数，再决定要不要举牌。这才是真正的「捡漏」，而不是接盘。后续我们会继续拆解法拍房的其他风险点：税费、学位、贷款、产权瑕疵。关注我们，少踩一个坑，就是省下真金白银。

法拍房既不是洪水猛兽，也不是天上掉馅饼。它的本质，是用信息差换取价格空间：你愿意花在尽调上的每一分钟，都可能转化为真金白银的折扣，或者帮你避开一次代价高昂的失误。理性看待、充分调查、量力而行——这九个字，是所有法拍房交易的前提。
