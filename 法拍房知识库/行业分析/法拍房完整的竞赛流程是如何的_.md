# 法拍房完整的竞赛流程是如何的？

法拍房完整竞拍流程（网络司法拍卖）
主流平台：阿里资产（淘宝）、京东拍卖、人民法院诉讼资产网。整体分为拍前尽调→报名交保证金→线上竞价→付清尾款→法院出文书→缴税过户→收房交房七大环节。
一、拍卖公告阶段（公示≥30 天）
筛选房源，完整阅读拍卖公告、竞买须知、标的物调查表、瑕疵说明，看清：起拍价、保证金、加价幅度、付款期限、税费承担、是否有租约、是否占用、是否限购、欠费情况。
联系辅拍机构预约实地看样，实地查看房屋现状。
尽职调查（关键避坑）
不动产中心查：抵押、查封、共有产权、土地性质
核实：租约、居住占用、物业费 / 水电费 / 暖气欠费、户口问题
预算核算：成交价 + 税费 + 欠费 + 清场成本，设置最高心理上限。
提示：法拍房大多要求全款，支持贷款的房源极少，务必提前预审贷款资质。
二、报名缴纳保证金（获取竞拍资格）
平台账号完成实名认证，付款人 = 未来房产证权利人；多人共有要提前联系法院说明。
保证金一般为起拍价 5%‑20%，建议提前 1‑2 天缴纳，避开银行卡限额、转账延迟。
未拍中：拍卖结束后保证金原路无息退回；
拍中悔拍：保证金直接没收，还要承担二次拍卖差价损失，且不能再次参与该标的拍卖。
三、线上竞价（正式竞拍）
竞价周期一般24 小时；规则：最后 5 分钟有人出价，系统自动延时 5 分钟，循环直到无人出价，价高者得。
出价必须为加价幅度的整数倍，首次出价不能低于起拍价。
策略：前期观望，临近结束出价，严格守住心理预算，超预算直接放弃。
流拍：无人出价，一拍结束；后续进入二拍、变卖，价格会下调。
四、竞拍成功，支付尾款
成交后看公告要求，7‑15 个工作日内，全款打入法院指定对公账户，逾期视为悔拍，保证金没收。
务必确认转账限额，大额资金提前安排；贷款的房源要确认放款时间满足法院期限。
五、法院出具法律文书
全款到账后，法院出具三份核心文件：
✅《拍卖成交确认书》
✅《执行裁定书》
✅《协助执行通知书》
物权自裁定书送达买受人时生效，不需要原房主到场配合。
六、缴税、办理过户
携带法院三份文书、身份证，自行到不动产登记中心缴税过户。
税费按拍卖公告约定承担；很多法拍房是买受人承担买卖双方全部税费，这点拍前一定要看清。
解除原房屋抵押、查封，办理不动产权证。
七、房屋交付、腾退
房屋空置：直接收房，交接水电气物业，换锁入住。
房屋被原房主 / 租客占用：
看公告是否写明法院负责腾退；
有合法长期租约（买卖不破租赁），要按租约执行；
拒不搬离，向执行法院申请强制腾退，周期不确定，存在时间成本风险。
