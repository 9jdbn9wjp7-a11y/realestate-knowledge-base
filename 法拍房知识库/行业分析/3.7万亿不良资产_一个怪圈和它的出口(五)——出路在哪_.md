# 3.7万亿不良资产：一个怪圈和它的出口（五）——出路在哪？

前四篇讲了历史、困境、境外经验和境内的现实。这一篇说出路。

五大全国性AMC有资金成本优势（发债成本约3.5%），有集团协同和跨区域展业能力，可以从项目里优中选优。地方AMC不行。全国约60家地方AMC分化严重，江浙粤头部机构已经能全国展业、发ABS，但大量中西部和弱资质区域的地方AMC面对的是生存问题。

出路不可能只有一条。

**中小银行化险**

2026年，中小金融机构改革化险是监管头号任务。城商行不良率1.85%，农商行不良率2.79%，这些数字背后是大量需要实质性处置的不良资产。

中原资产2024-2025年收购河南省内中小银行不良超200亿，短期盈利承压，但卡位了"区域金融稳定服务商"的角色。山东金融资产截至2025年参与87起破产案件，累计收购不良超220亿。

这不是"收包赚差价"的生意，是"服务换市场"。谁帮地方政府把中小银行的风险化解掉，谁就能在这个区域拿到长期业务资源。拼的是政商协调能力和系统性处置方案，不是谁钱多。

律师在参与中小银行风险化解项目的过程中，法律层面的难点至少有三个。第一个是债权确认——中小银行的信贷管理普遍不规范，有的贷款合同签得不完整，有的担保手续有瑕疵。第二个是地方政府的角色——地方政府想的是"别出事"，AMC想的是"回收最大化"，这两个目标有时候是冲突的。第三个是时效问题——中小银行的不良贷款很多已经拖了很多年，有些已经过了诉讼时效。

**投行化重组加破产管理人**

宁波金资2025年参与杉杉集团破产重整，以49.87亿元收购13.5%杉杉股份股票。长城资产主导金科股份破产重整，1470亿债务、8400家债主，用"小额现金清偿加大额债转股加职工优先"的方案完成。

这类业务的核心门槛是专业。法律能力（破产程序、债权确认、重整方案设计）、投行能力（估值定价、交易结构设计、投资人招募）、运营能力（引入产业方、推动业务转型），三个能力缺一不可。

地方AMC有一个独特优势：破产管理人资格。拿到这个资质，就能在重整全过程中掌握主动权，从资产清查、债权审核到重整方案设计，全程参与，全程收费。山东金融资产87起破产案件的实践证明了这条路走得通。

**轻资产中间业务**

撮合交易、资产证券化服务、尽调外包、评估顾问、交易平台运营，这些"卖铲子"的业务不需要大量资金沉淀，利润率反而更高。

KAMCO的核心经验之一就是做市商模式，不一定要自己持有所有资产，搭建平台、制定规则、连接买卖双方、收取服务费。

2026年不良资产市场的参与主体越来越多：民间资本、个人投资者、外资（橡树资本、黑石等）、金融科技平台纷纷入场。这些新玩家有资金有技术，缺牌照、缺本地资源、缺合规能力。地方AMC能提供这些。

从自己下场打球，变成既当球员又当裁判，甚至建球场收门票。这可能是地方AMC最容易被忽视但最可持续的利润来源。

**律师的新方向——困境企业的合规重建与债务规划**

传统业务正在被卷成一片红海。就拿给银行出律师函来说，批量价格从最初的500-800元一封，卷到现在100-200元。干了很多活，但不赚钱。所有人都在盯着AMC的传统业务——出尽调报告、做催收、代理诉讼——越抢越薄。

所以我也一直在想，有没有一种新的模式，不跟别人在传统赛道上卷。

经过反复调查，我发现一个其实很多同行都看到了、但很少有人去碰的现象：很多所谓的"不良企业"，本身的经营性现金流其实还是可以的。不良爆发的原因，往往不是企业经营彻底不行了，而是某一笔单笔不良引发了系统性崩塌。

这个问题不是没人发现。但相较于传统的诉讼业务——起诉、保全、开庭、拿判决——合规重建和债务规划要复杂得多。一个项目做下来，涉及法律、财务、税务、公司治理，方方面面都要懂、都要碰。做诉讼的律师，靠的是法律功底；做合规重建的律师，还得懂财务、懂经营、懂谈判，甚至要懂银行的风控逻辑。而且周期长、变量多、不确定性大。说实话，不是每一个律师都愿意趟这个浑水。

但像前面提到的那家报表全是编的企业，不在此列。那种企业的问题不是"流动性枯竭"，是从根上就烂了。

真正有救的企业，是那些经营还在、资产还在、只是被一笔不良拖垮了的。它们的债权债务关系，其实处于一个相对平衡的状态。真正让企业"死"掉的，不是资不抵债，而是流动性枯竭。

说到这里，我觉得海航目前的模式就不错。之前我和银行的朋友们探讨过这样一种思路：对于经营还在的企业，是不是可以参考海航模式，成立有限合伙——原股东作为GP，银行以债权出资作为LP，将不良资产转化为有收益权的投资，利息转变为有限合伙的最低收益？

这样做的目的是什么？对银行来说，原来挂在账上的关注类或者不良贷款，通过这种方式出表了，变成了一笔有收益预期的股权投资。对企业来说，债务压力减轻了，经营空间释放出来了，可以继续正常运转。说白了，就是用时间换空间。

但银行的朋友跟我说，这条路很难。这个模式不是一家支行、分行、省行能够决定的，往往需要上报总行。而总行面对的是全国几千上万个业务需求，你这一单不一定排得上优先级。再加上监管层面的顾虑——不良资产出表的合规性怎么认定？债权转股权的会计处理怎么走？这些问题没有明确的操作指引，谁也不敢轻易拍板。地方AMC往往也没有这种勇气来做这样的尝试。

而修复的关键是合规。一个企业为什么会陷入不良？追根溯源，90%以上的问题都能追溯到合规缺失。纳税不规范→银行不敢贷→资金链断裂；社保不规范→用工纠纷→经营受损；公私不分→财产混同→企业主个人被追责。

合规的缺失，既是企业融不到资的原因，也是企业陷入不良的根源。

**基于这些判断，我现在在做的事情，核心思路是两步走：**

**第一步：** 合规重建。 帮企业把纳税、社保、财务、法务这些基础全部补齐，建立规范的治理结构。该交的税交，该买的固定资产买，该建的制度建。你今天省下来的税，就是你明天借不到钱付出的代价。

**第二步：** 债务规划。 在合规基础上，把优质资产和优质项目剥离出来，提升企业自身的造血能力。然后用新的主体逐步收购原有的债务，从而逐步化解原有债务。

说白了，不是帮企业"逃债"，而是帮企业"续命"。先让它变成一个银行愿意帮的合规主体，再让它的债务有时间去消化。

这个模式跟传统的AMC收包处置逻辑完全不同。AMC是低价买入债权，然后处置抵押物赚差价。而这个模式是站在企业这边，从合规到融资到债务化解，做全链条的服务。律师在其中的角色，不再是AMC的"外包工具"，而是企业的"合规架构师"。

两个案例放在一起看——一家是"造假做局"，从根上就烂了；我的客户是"被抽贷拖垮"，资产在、经营在、团队在，只是被一笔逾期堵住了活路。金融机构对待"不良"是一视同仁的。不会区分哪个是"烂透了"的，哪个是"被冤枉"的。但律师可以——做合规尽调，帮企业梳理真实资产和真实经营，区分哪些是真没救、哪些还有救。真没救的，走破产清算。还有救的，做合规重建和债务规划，帮它活过来。

这比帮AMC收包、出尽调报告、发律师函有意义得多。

**周期底部**

2026年，中国不良资产行业处在第四轮周期的底部区域。银行不良3.7万亿还在涨，法拍流拍率超过45%，通道业务被叫停，民营AMC分化，头部机构投行化转型。

中国不良资产市场正在经历类似的转变：牌照套利让位于专业能力，抵押物依赖让位于价值创造，债权思维让位于股权思维，单打独斗让位于生态协同。

对地方AMC来说，最大的风险不是市场不好，是市场不好的时候仍然用旧思维做事。3.7万亿是新一轮周期的起点。能活下来的，不是最大的，是最先完成思维切换的。

作为在一线干活的律师，对这个行业的判断是这样的：未来三到五年，不良资产法律服务市场会经历一次洗牌。那些只能做诉讼清收、出律师函、批量催收的律师和团队，业务会持续萎缩。但那些能够提供综合解决方案的——能设计交易结构、能做破产重整管理人、能帮困境企业做债务规划、能协调多方利益——反而会迎来一个黄金期。

对律师来说，最大的机会不是去卷AMC的尽调和催收，而是跳出来，站到企业那边，做合规重建和债务结构的重塑者。从"帮AMC打官司"变成"帮困境企业续命"，从"服务商"变成"合规架构师"。这条路更难走，但天花板也更高。

合规不是成本，合规是投资。是你借得到钱的门票，也是你困境中翻盘的资本。
