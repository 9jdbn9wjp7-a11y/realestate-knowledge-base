# 法拍知识｜如何看待法拍房成交价高于评估价？

很多购房者选择法拍房最关键的原因就是法拍房价格低，一般情况下，一拍价格是市场价的70%-80%。

但往往最后成交价却大于市场价。

例如，阿里平台曾有一个标的物，**评估价3758500元**，但最后**成交价却是5040000元**！**足足高了1281500元！**

![图片](https://mmbiz.qpic.cn/mmbiz_png/icltNRAnU6jwORrdNc1UNe7EUCMQvkjIDT6JbCV6cKXB3E25fsxYzVn4lq38XMYLias6pyBJSHNvqtialx33QlR0A/640?wx_fmt=png#imgIndex=1)

图源：阿里法拍平台截图

**为什么会出现成交价大于评估价？有以下几个方面原因：**

//

**拍卖时买家的心态**

当有2个以上的买家，资金充足，又特别想要这套房子时，就容易出现轮流抬价，最终以高于市场价的价格完成竞拍。就像上图中的案例，有13人竞拍，轮番竞价，最后成交价大于评估价，也在意料之中。

//

**稀有价值和特殊性**

由于法拍房的特殊性，经常有一些市场上见不到的标的出现。

比如杭州的独栋别墅，不少人惦记着成为这里的业主，可惜平时几乎没有二手房流出，此时出了一套法拍房，那么这些有意向的人必然是轮流抬价，直到一方胜出。

所以**一般只要是稀有的，市场上看不到的，就容易拍卖出高价**。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/icltNRAnU6jwORrdNc1UNe7EUCMQvkjIDhJkOw3iaLAiaymps9nxGibicDw9tdTo3tBdFyuyeXQZ1HF1NdlWED8vkng/640?wx_fmt=jpeg#imgIndex=2)

不仅仅是豪宅，地理位置上很有价值的商铺、写字楼等也经常存在着市场孤品的情况，既然是孤品，而且是有用的孤品，那么必然受到青睐。

//

**潜在价值**

这一点比较好理解，就是买家看好被执行拍卖房产所处的位置的经济发展潜力。

法院对法拍房价值的评估由银行完成，而这个**评估值反馈的是当前价值**，假如多个参拍人都认为这地段大有可为的话，那么就会出现相互竞价到高于市场价的情况。

//

**被执行人原因**

本人委托其他人在出手，不惜悔拍也要将房拿下，只是为了推延时间，防止房子被其它人竞拍走。

有在网上看到这种例子，被执行人连续几次将房子拍下后悔拍，最后悔拍的保证金都够偿还债务了，被执行人实际上只损失了拍卖手续费，最后钱还是回到自己手上。

房子被拍卖到悔拍，再上架拍卖，有几个月的时间差，被执行人在这段时间内凑够了资金，避免了房产被拍卖。

法拍房拍卖，有上述任意因素，出现成交价大于评估价，也就不足为奇了。
