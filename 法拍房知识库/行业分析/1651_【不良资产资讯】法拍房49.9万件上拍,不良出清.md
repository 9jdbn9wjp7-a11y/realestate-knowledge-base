# 【不良资产资讯】法拍房49.9万件上拍，不良出清提速

2026年9月25日 · 老虎投资汇每日精选

不良资产市场正经历“供给放量、定价分化、处置转型”三重变奏。今年前8个月全国法拍房新上拍品49.9万件，同比增长超30%；银行业上半年核销规模超5,000亿元，AMC从“打折收包”转向“重组重整重构”。当前市场已从“捡漏时代”进入“专业运营时代”。

## 一、市场概况

### 法拍房1-8月新上49.9万件，清仓率仅23.53%

据中指研究院数据，2026年1—8月全国355城法拍市场累计新上拍品499,253件，同比增长30.67%；交易截止拍品611,260件，成交仅143,854件，清仓率23.53%，流拍率高达69.80%。全国法拍房成交均价4,960元/㎡，评估均价6,339元/㎡，平均成交折价率74.07%，买方市场特征明显。

📌 来源：中指研究院 / 正兴法拍 2026-09-25

### 银行上半年不良核销超5000亿，国有行“清淤”力度空前

2026年上半年，上市银行密集加大不良资产处置。工商银行核销819亿元，建设银行核销319.93亿元，中国银行核销及转出约426.38亿元，浦发银行核销及处置401.24亿元，华夏银行216.89亿元，光大银行273.60亿元，平安银行核销106.99亿元。全行业上半年处置规模已超5,000亿元。

📌 来源：中国经济时报 / 央视网财经 / 银行半年报 2026-09-25

### 商业银行不良率1.52%，农商行2.83%承压最大

金融监管总局数据显示，2026年二季度末商业银行不良贷款率1.52%，较一季度末微升0.01个百分点。分机构看，大型商业银行1.21%、股份制银行1.23%、城商行1.87%、农商行2.83%。农商行资产质量压力最大，近期多家农村中小银行已在银登中心密集披露转让公告。

📌 来源：金融监管总局 / 中国经济网 2026-09-25

## 二、投资机会分析

### 个贷不良成“新蓝海”，消金上半年挂牌532亿

2026年上半年，24家持牌消金公司挂牌转让不良贷款合计未偿本息532.02亿元，同比增长74.5%。中银消金117.44亿元、招联消金106.29亿元居前。银登中心第二季度挂牌项目约502单，涉及未偿贷款本息和1,011亿元，同比增长14.6%。信用卡、消费贷、个人经营贷逾期资产供给持续增长，个贷不良批量转让已成为银行零售风险化解的重要通道。

📌 来源：银登中心 / 今日头条行业研报 2026-09-25

### 核心城市法拍住宅仍具流动性，上海住宅清仓率近79%

法拍市场呈现显著的区域分化。一线城市法拍住宅清仓率60.9%，上海1—7月清仓率78.5%；二线城市43.1%，三四线城市仅29.7%。9月第三周上海法拍住宅成交75套，成交率78.9%，折扣中位数81.7%；300—500万总价带成交率85.7%，刚需和入门改善仍是法拍市场基本盘。

📌 来源：中指研究院 / 具足财上海法拍周报 2026-09-25

### AMC从“三打”转向“三重”，产业赋能取代财务套利

2026年中报季，9家持牌AMC业绩分化加剧。中信金融资产归母净利68.62亿元创新高，中国信达仅7.84亿元、长城资产约6.63亿元。值得注意的是，信达上半年新增收购金融不良债权1,412.7亿元规模行业第一，但利润有限，说明“收包规模≠赚钱能力”。头部AMC正集体从“打折、打包、打官司”转向“重组、重整、重构”，后续处置能力成为核心壁垒。

📌 来源：金融时报 / 资产界 / 上市公司中报 2026-09-25

## 三、典型案例

### 深振业挂牌6宗深圳物业，初始总价1.7亿元

上市公司深振业A公告，董事会通过在深圳联合产权交易所公开挂牌转让6项深圳地区自有物业，涵盖振业梅苑综合楼、宝丽大厦裙楼、星海名城组团商铺等，总面积8,410.10㎡，初始挂牌总价约1.70亿元。此举是国企优化资产结构、把低效存量“变现去化”的典型样本。

📌 来源：深振业A公告 / 芝言不动产 2026-09-25

### 华闻集团重整收官：引入26亿资金化解40亿债务

海南自贸港文化传媒第一股华闻集团重整计划于2026年6月30日执行完毕，引入资金超26亿元，有效化解近40亿元债务，维护逾5万户小股东和债权人权益。公司资产负债率由83.72%降至31.59%，成为2026年首家通过证监会和最高法重整审查的上市公司，为上市公司重整新规落地提供实践样本。

📌 来源：德恒律所 / 新浪财经 2026-09-25

### 土流集团11个月重整成功，数据资产“双轨管护”成范本

涉农数字龙头企业土流集团破产重整案经天心区人民法院指导高效办结，从法院裁定受理重整申请到裁定批准重整计划仅用时11个月。管理人首创数据资产“双轨管护”、重整方案“同台竞选”机制，成功保留公司完整经营主体，实现职工债权100%全额清偿，成为长沙轻资产数字企业破产重整实践范本。

📌 来源：湖南天地人律师事务所 2026-09-25

### 上海浦东上钢七村31人抢拍，245.5万成交

9月第三周，上海浦东上钢七村一套51.55㎡老房以165万元起拍，31人报名、100次出价，最终以245.5万元成交，折扣率104.5%。同户型在售房源挂牌265万元，法拍成交相当于挂牌价的九二折。该案显示核心城市“低总价+好地段”的法拍房源仍具较强流动性。

📌 来源：具足财上海法拍周报 2026-09-25

## 四、政策动态

### 对公不良贷款“两户组包”转让新规落地

4月29日，国家金融监督管理总局办公厅印发《关于明确对公不良贷款两户组包转让有关事项的通知》（金办便函〔2026〕408号），正式确立对公不良贷款“两户组包”转让合规路径，补齐此前不良贷款处置的政策短板，构建起1户、2户、3户及以上的梯度化对公不良贷款转让体系。试点期限延续至2026年12月31日。

📌 来源：国家金融监督管理总局 / 手机网易网 2026-09-25

### 银登中心延续不良转让费用优惠，个贷批转试点常态化

银登中心发布通知，自2026年1月1日起继续对不良贷款转让业务暂免收取挂牌服务费，并对交易服务费予以八折优惠。不良贷款批量转让试点已延期至2026年12月31日。同时，监管强化不良资产转让真实性审查，严防银行通过转让隐匿风险，严禁“假不良、真融资”。

📌 来源：银登中心 / 央视网财经 2026-09-25

### 不动产查封新规重构法拍处置底层逻辑

法〔2026〕56号文对不动产查封到期自动解封、轮候查封期限起算进行重构，直接影响法拍、以物抵债与首封抵押权博弈的底层逻辑。这一变化要求不良资产投资者更加关注查封顺位、轮候期限及执行时效，避免因程序瑕疵导致资产价值贬损。

📌 来源：法律实务研讨 / 行业培训 2026-09-25
