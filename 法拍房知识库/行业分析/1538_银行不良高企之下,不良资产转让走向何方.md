# 银行不良高企之下，不良资产转让走向何方？
> 公众号: 金科农
> 发布时间: 2026年9月18日 18:05
> 原文链接: https://mp.weixin.qq.com/s?src=11&timestamp=1789830186&ver=6976&signature=HRPb*bTR8PMUniHCy7yf-ScjzLg1Uz0WRsmS8TvtMKF1UtJ9Dkr*do3jxYGdbH3bvyxvSxpzhhLAehbLw9Wp4XDk9nbI4i6gImc5Co3c5wQPpGOyZcqp8CLDmeRgRIkt&new=1

2025年四季度末，商业银行不良贷款余额3.5万亿元，不良贷款率1.50%。数字看似平稳，但水面之下暗流涌动——农商行不良率高达2.72%，城商行紧随其后为1.82%；零售端压力从信用卡、消费贷向经营贷传导，股份制银行更是密集“甩包”的主力军。

一场围绕不良资产处置的深刻变革，正在重塑银行业的资产负债表。不良资产转让，这个五年前还只是“小范围试点”的处置手段，如今已站上舞台中央。

# 一、规模井喷：从47亿到3500亿的跨越

数字最能说明问题。

2021年，个贷不良批量转让试点刚启动时，全年成交规模仅约47亿元，项目数量45单。到了2025年，银登中心挂牌的个贷不良资产本息总额突破3500亿元，同比至少增长78%。成交规模约3291亿元，项目数量增至891单——五年间增长约70倍。

百亿元级资产包“甩卖”从偶发事件变成常态。渤海银行单笔挂牌698.33亿元，华夏银行全年信用卡不良转让超300亿元，兴业消费金融以401.06亿元的转让规模领跑消金行业，创下单笔208.13亿元的行业纪录。

消金公司的参与面急剧扩大。2025年全年，23家消费金融公司累计挂牌234期不良贷款转让公告，未偿本息合计达1180.47亿元，较2024年大幅增长147%。在全国31家持牌消金公司中，参与转让的机构占比已超七成。

进入2026年，出清节奏进一步提速。上半年银登中心转让不良资产规模达1011亿元，结合前5个月商业银行核销不良资产的4868亿元，全行业不良资产处置规模至少超5000亿元。

# 二、供给结构之变：谁在出包，出什么包

这轮不良转让潮的供给端，正在发生结构性变化。

第一，供给主体从股份行向国有大行和消金公司扩散。 2026年上半年，银登中心参与主体中，大行和消金公司增速最快，占比双双突破20%，仅次于股份行。中国银行、邮储银行、建设银行、平安银行等全国性银行高频挂包已成常态，单日更新15则转让公告的场景屡见不鲜。

第二，资产类型从对公向零售全面迁移。 招联首席经济学家董希淼指出，不良资产处置正从公司不良资产为主向公司与零售不良资产并重迁移。信用卡透支、个人消费贷、个人经营贷成为转让主力品类。2026年8月，光大银行一次性挂出12期信用卡不良资产包，合计未偿本息约108亿元，涉及借款人约44.2万户。

第三，资产“账龄”在缩短，“快转模式”成为主流。 以往不良资产包多混合“未诉讼”“执行中”“已判未执”等多种状态，如今越来越多机构选择将核销后的“未诉讼”资产直接打包转让。中银消金2025年全年挂牌88期项目，平均每4天就有一笔资产包在银登中心公告。这种“高频、小额、快转”的打法，帮助机构加速回笼资金，实现资产盘活效率最大化。

第四，分包逻辑从粗放分类转向精准画像。 过去行业多以“逾期天数”为核心维度进行分包，现在部分转让方开始结合资产地域分布、单笔金额和客户画像等维度分类整合，降低受让方后期处置复杂度，提升市场资产匹配效率。

# 三、政策“定心丸”与监管新要求

市场爆发的背后，政策起到了关键催化作用。

2025年12月29日，国家金融监督管理总局正式下发通知，将不良贷款转让试点期限延长至2026年12月31日。这是该试点自2021年启动以来的第二次延期，为金融机构规划中长期资产处置策略吃下了“定心丸”。

与此同时，银登中心推出实质性让利：自2026年1月1日起，继续暂免收取不良贷款转让业务挂牌服务费，交易服务费给予八折优惠。挂牌公告期也从至少10个工作日缩短至5个工作日，大幅提升出让速度。这套“延期+降费+提速”的政策组合拳，显著降低了金融机构的合规处置成本。

但政策暖风之下，监管也划出了更清晰的红线。此次延期通知明确要求各试点机构开展自查、自纠并限时完成专项审计，重点关注尽职调查、估值定价、审批决策、个人不良贷款清收管理等方面，各机构须于2026年5月31日前报送专项审计报告和问题整改报告。

毕马威中国特殊资产合伙人胡雪梅对此评价：“试点政策延期体现监管审慎态度，未来是否进一步放开还要看试点机构专项审计和问题整改情况。”换言之，政策窗口虽然在延续，但监管对合规性和风险管控的要求在收紧。

# 四、AMC的转型：从“清收者”到“价值发现者”

不良资产转让市场的高速运转，离不开AMC这个“接盘方”的深度参与和模式进化。

2025年，中信金融资产与中国信达两大全国性AMC合计收购不良资产超过5400亿元，重点聚焦中小金融机构改革化险等领域。中信金融资产新增收购不良资产债权规模2421亿元，同比增长35%；中国信达收购金融不良资产原值超3000亿元，公开批转市场占比保持行业领先。

但规模扩张只是表象，更深层的变化在于业务逻辑的重构。

中信金融资产董事长刘正均提出，要摒弃简单的买卖资产的理念，主动挖掘和配置优质资产，“带着好资产穿越周期”。这一表述标志着AMC正加速从传统“收购处置型”向“主动经营型”转变，从“清收者”向“价值发现者”和“产业重塑者”转型。

以实质性重组为核心的“投行化”处置方式正在成为行业主流。瞭望智库联合浙商资产发布的《2025中国金融资产管理行业研究报告》指出，打造较强的“投行化”服务意识与服务能力，是AMC提高不良资产价值、获取较高收益、加速市场化改革的有效手段。适用于在细分领域具备专业度、自身产业生态丰富、人才结构多元化的资产管理公司。

市场格局也在走向多元化。全国性AMC加速入场个贷不良批量转让业务，地方AMC仍是受让主力军，“国家队”与“地方军”协同的格局初步形成。

# 五、定价之变：从“一折甩卖”到市场化博弈

不良资产转让的价格逻辑，也在发生微妙而深刻的变化。

个人不良贷款项目的批转平均折扣已降至4.1%，个人消费贷资产更低至3.8%，部分资产包折扣最低至0.2折。低折扣反映了个人不良资产缺乏抵押担保、回收成本高的现实，但也引发了对定价是否合理的讨论。

一个值得关注的变化是：2025年11月起，个贷不良批转招标公告不再公示起拍价，只有AMC登录系统后才可见。这一调整提升了定价灵活性，使转让方能够根据市场反应动态调整策略，避免因公开起拍价过低引发“踩踏效应”。

从银行年报数据看，不同机构在处置方式上的选择正在分化。招商银行全年处置661.88亿元，其中不良资产证券化高达342.32亿元，占比51.7%；中信银行全年处置877.90亿元，不良ABS达425.16亿元，同样占据半壁江山。不良ABS与批量转让的“双轨并行”，正在成为大型银行的标配。

# 六、科技赋能与差异化路径

这轮不良资产处置潮中，科技和差异化策略正在成为新的竞争变量。

AI技术已被广泛应用于贷后催收管理，通过智能分析和交互提升催收效率。部分机构开始将行为数据替代传统财务数据，提升对零售与小微客户的风险识别精度。数字化风控能力，正在从“锦上添花”变为“必需品”。

处置路径的分化则更加鲜明。国有大行和股份制银行依托银登中心，对零售、对公不良资产开展常态化批量挂牌转让；以广州农商行为代表的中小银行则另辟蹊径，推出“全员推介、全员清收”模式，针对大额不良债权灵活化、多元化处置。中小银行受不良资产结构复杂、资本缓冲不足等约束，更倾向于属地化清收或与地方AMC合作，“想转难转”的问题仍待破解。

# 结语：从“出清工具”到“经营能力”

回望五年，不良资产转让从一个边缘化的试点工具，成长为银行风险出清的主力渠道。这背后，是银行业经营逻辑的根本转变——从“重投放、轻退出”的规模扩张模式，转向“向存量管理要效益”的质量效益模式。

正如上海国家会计学院金融系主任叶小杰所言，提前出清不良资产本质上是对低效资本占用的盘活，是银行在信贷增长放缓背景下，向存量管理要效益的必然选择。

展望未来，不良资产转让市场将呈现三条清晰的演进主线：

一是常态化。 处置正从年末时点调节转向全年常态化运作，试点政策虽为年度延期，但市场运转已具备制度化基础。

二是专业化。 AMC的“投行化”转型、资产包的精准分包、AI赋能的智能处置，都在推动行业从“粗放买卖”走向“精细运营”。

三是差异化。 大行靠平台、中小行靠属地、AMC靠专业能力——不同机构正在找到各自的最优解。

对于银行而言，不良资产转让不再仅仅是“甩包袱”，而是一项需要持续投入和精耕细作的经营能力。谁能率先完成从“出清工具”到“经营能力”的认知升级，谁就能在这场资产质量的长跑中赢得先机。
