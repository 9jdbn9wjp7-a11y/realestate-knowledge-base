# 法拍房成交后的流程

拍下只是开始，成交后还有缴款、过户、清场几步。

拍下法拍房只是开始，成交后还要走完缴款、出文书、过户、清场几步。五个阶段一次讲清。

## 第一阶段：拍卖成交 → 平台出具《成交确认书》

在拍卖平台竞价成功后，系统会自动生成《网络竞价成交》，确认竞拍成交。

## 第二阶段：支付尾款 → 出具裁定书等法律文书

1.

2.  竞买人应按拍卖公告规定的时间（通常为成交后 7 至 30 个自然日内），将扣除保证金后的剩余款项支付到指定账户；

3.

4.  逾期未支付的，保证金可能被没收，并可能重新拍卖，原竞买人不得参与再次拍卖。

5.

## 第三阶段：送达《协助执行通知书》 → 解除查封、抵押

相关文书送达不动产登记等相关部门后，由这些机构配合办理产权过户手续。

## 第四阶段：税费缴纳 → 产权过户

竞买人持相关法律文书办理核税，缴纳买方应承担的税费；如拍卖公告要求垫付卖方税费的，需一并垫付。

## 第五阶段：房屋交付 → 清场入住

1.

2.  这是最耗时的环节，短则几周、长则数月，主要取决于占有人是否配合、是否有老人小孩孕妇占用、是否存在合法租约等复杂情况；

3.

4.  如拍卖公告明确标注「法院不负责清场交付，竞买人自行交付」，竞买人需自行通过协商或法律途径解决清退问题，风险较大，建议慎重购买。

5.

## 特别提示

法拍从成交到过户，顺利通常需 1–3 个月（特殊情况除外）；如清场困难，交付时间会更长。务必在参拍前做好充分的尽职调查。
