# 不良资产入行完整逻辑：先想清楚图什么，再搞懂怎么玩

     不良资产通俗讲就是银行、房企、企业、个人逾期欠款、抵押房产土地、烂尾项目、失信债权、执行难判决书债权等资产，整体分为金融不良（银行AMC主流）、民间司法不良（法拍债权、执行债权）、企业非标不良三大类，下面先拆解收益目的，再讲全路径玩法、门槛、风险，贴合普通人/小创业者两种身份分开说明。

    一、入行先回答：你做不良资产到底图什么？（核心定位，决定后续所有模式）

    不同诉求对应完全不一样的赛道，千万别盲目进场

    1. 赚差价（绝大多数人入行初衷）

    低价收债权/抵押物，高价处置变现。

举例：100万本金货款判决书债权，30万打包买下，通过催收、谈判、拍卖抵押物最终回款70万，净赚差价。银行抵押房不良，5折收购抵押债权，过户房产后按市场价出售获利。

    2. 拿优质实物资产（买房/拿地/拿厂房）

    不以快速变现为目的，低价锁定房产、商铺、工业用地、写字楼。

比如市场价150万住宅，通过不良债权模式80万拿下，长期自住或出租，比二手房划算很多，很多圈内人靠这条路径低成本囤物业。

    3. 做居间中介，空手套信息差（零本金入门首选）

    不垫资收购资产，只对接上下游：一手对接法院、银行、律所、执行局拿到不良标的，一手对接投资方、刚需买家，成交收取1%~5%居间服务费，无大额资金风险。

    4. 做配套服务赚稳定现金流（副业/轻资产路线）

    不靠买卖资产盈利，给不良资产业务提供支撑服务：司法尽调、上门催收、房产清场腾房、资产评估、诉讼代理、法拍房代办过户、财税筹划，持续接单赚服务费。

      5. 企业纾困整合（高阶大额玩法）

    接手负债困境企业，剥离债务、盘活厂房设备、重组经营，依靠企业后续经营盈利，适合资本体量较大的玩家。

     6. 避坑避雷反向需求：解决自身债务

    如果你本身有欠款、被执行、房产被查封，也可以反向学习不良逻辑，通过债权置换、债务协商化解自身负债，属于自用型需求。

     五，结合你的自身情况定制入行建议。

    二、分层级讲：不良资产具体怎么玩（从0本金小白→中小资本→专业机构）

     是全流程亲身实操胜过所有理论学习  第一层：0本金小白起步模式（新手首选，零垫资，试错成本最低）

      1. 信息居间中介

    形成垂直赛道优势。我我获取标的渠道：法院裁判文书网、阿里京东法拍平台、本地基层法院执行局、律所、银行信贷部、四大AMC地方办事处。

运营方式：整理查封房产、执行债权、逾期标的信息，发布到房产社群、本地自媒体、同行圈子，匹配投资人，成交抽佣。

优势：不用出钱，只拼信息和人脉；缺点：成交不稳定，极度依赖本地资源。

      2. 副业配套服务

      学习基础司法知识，做法拍房代办、文书代写、执行立案协助、简单债务协商，一单收取几千到几万服务费，慢慢积累行业认知和人脉，为后期收债权打基础。

      第二层：中小散户（5万~50万资金，主流民间不良玩法）

       1. 小额司法债权收购

      重点收购民间借贷、货款欠款、工程款判决书、终本执行案件债权。

     流程：和原债权人签订债权转让协议，法院做债权变更，成为新债权人，后续通过查封财产、拘传被执行人、谈判分期还款、拍卖名下财产回款。

     结合你之前100万货款仲裁案子：你既可以作为债权人自己走仲裁执行，也可以后期把这份生效裁决债权打折卖给不良从业者，也可以收购别人同类货款债权。

       2. 法拍房+抵押债权模式捡房

      两种路径：

      ① 直接参与法院法拍竞拍捡漏；

      ② 收购银行抵押债权，通过债权处置方式过户抵押房产，部分情况比直接竞拍门槛更低，可规避部分竞拍风险。

       3. 个人/小微企业逾期债务协商业务

批量承接信用卡、网贷、企业逾期客户，做停息挂账、分期协商，赚取服务费，现金流稳定。

      第三层：专业资本玩家（50万以上资金，对接持牌机构）

      1. 对接四大国有AMC（华融、信达、东方、长城）+地方省级AMC批量竞标银行打包不良资产包（动辄几千万、上亿的整体债权包），拆分里面的房产、企业债权、个人欠款，分拆处置变现，整包折价往往3~5折，利润空间大，但资金门槛极高。

      2. 烂尾楼盘、大型厂房、商业综合体债务重组，通过债务剥离、引入运营方盘活大宗资产。

      3. 组建律所+尽调团队+清场团队，全链条运营，形成标准化公司 模式。

      三、标准化完整处置通用流程（不管哪种不良资产通用）

       1.. 尽调（最关键环节，决定亏赚）
核查债权真实性、债务人财产线索（银行卡、房产、车辆、股权、应收账款）、抵押物是否存在租赁、是否有多重查封、是否有人占用房产，避免买到“废纸债权”。
       2. 议价收购
和原债权人谈收购价格，签订正式债权转让合同，完成交割、付款。
       3. 司法确权
去法院办理债权申请人变更，把债权人从原持有人换成你，拿到合法执行主体资格。

       4. 处置回款

      路径可选：① 和债务人谈判一次性打折结清；② 申请法院拍卖名下不动产/动产；③ 查封股权、冻结账户划扣资金；④ 债权二次转手卖给其他从业者；⑤ 以物抵债拿下抵押物自用/出售。

       5. 结算收尾

      回款后扣除成本、税费、服务费，核算利润，归档案卷。

     四、新手必须提前认清的行业大坑（入行必看）

      1. 尽调不到位买到“死债权”：被执行人一无所有、无任何财产，债权终身无法回款，本金全亏；

      2. 房产类标的隐性风险：长期租约、恶意占用、老人老赖拒不腾房、多重抵押，拍下房子没法入住；

      3. 法律合规红线：禁止暴力催收、骚扰恐吓、软暴力滋扰债务人，违规会触犯刑法；

      4. 资金周转周期长：一笔债权从收购到回款往往6个月~3年，资金流动性极差，绝对不能用生活费、刚需资金入局；

      5. 行业信息极度不透明，大量居间骗局，警惕号称“内部渠道稳赚不赔”的收费培训、标的兜售。

      五、结合你的自身情况定制入行建议

      你手里本身持有100万货款纠纷，正在走郑州商事仲裁，属于天然自带行业入门标的：

     1. 先走完自身仲裁流程，拿到生效裁决书，申请强制执行，完整走完一遍“债权形成—司法确权—执行处置”全流程，亲身实操胜过所有理论学习；

      2. 这段过程同步接触仲裁委、法院执行局、律师、同行不良从业者，积累本地河南郑州、鹤壁资源；

      3. 先从居间、小额债权副业试水，不要一开始大额垫资收购资产；

      4. 后续可以两条路并行：要么自己把这笔货款债权执行回款，要么熟练后收购别人同类商事货款、工程款仲裁/判决债权，形成垂直赛道优势。
