# 法拍房过户，税局要我替原房主掏增值税？法院：公告白纸黑字，你已签字

你有没有想过，在京东上司法拍卖的房子，为什么起拍价那么便宜？

七折、八折，甚至更低。

便宜是有代价的。代价之一，藏在过户那天的税单里。

2022年10月，广州的彭先生（化名）在京东司法拍卖平台上，竞得白云区法院拍卖的一套房产。拿着执行裁定书去办过户，税务窗口递出一张单子：增值税、城市维护建设税、教育费附加、地方教育附加、契税——全部缴清。

彭先生愣住了。

增值税、个税，按法律规定，卖方才是纳税义务人。我是买方，凭什么替原房主交？

他不服。行政复议，维持。起诉，一审败诉。上诉，二审还是败诉。

一张拍卖公告里的小字，为什么能让他多掏几十万？

今天这起案件——（2023）粤71行终1924号，广州铁路运输中级法院行政判决书，入选"中国2023年度影响力税务司法审判案例"——讲的正是这件事。

# 一、公告里那行小字

先看竞买公告里到底写了什么。

京东拍卖平台发布的《竞买公告》和白云区法院发布的《拍卖公告》，都明示了这样一段话：

> "标的物过户登记手续由买受人自行办理，并承担权属变更手续所涉及的买卖双方所需承担的包括但不限于契税、个人所得税、增值税等一切税、费和所需补交的相关税、费。"

划重点：买卖双方所需承担的一切税、费。

注意，不是"买方应承担的税费"，而是"买卖双方所需承担的"——也就是连卖方那份，买方也一并包了。

彭先生在竞拍前，看到了这段话。他拍下了房子，拿到了《网络竞价成交确认书》，确认书上也注明"请按照《竞买公告》《竞买须知》要求办理相关手续"。

过户那天，他按公告缴了税。

缴完之后，他越想越不对劲。

# 二、彭先生的逻辑：我不是纳税义务人

彭先生的抗辩，法律上站得住脚吗？先看法律规定。

我国税收征管法律法规，对不同税种都明确规定了纳税义务人：

增值税

：销售不动产的单位和个人

个人所得税

：财产转让所得的转让人

契税

：承受土地、房屋权属的单位和个人

也就是说，增值税和个税，法定纳税义务人是卖方。彭先生作为买方，法定的纳税义务只有契税。

彭先生的逻辑链条是这样的：

法律规定了谁是纳税人

我不是这些税的纳税人

税务局向非纳税人征税，依据不足

所以不该由我交

他还搬出了"尚方宝剑"——《最高人民法院关于人民法院网络司法拍卖若干问题的规定》，里面说网络司法拍卖形成的税费由"相应的主体承担"，最高法还发过工作要求，严格禁止在拍卖公告中要求买受人概括承担全部税费。

听起来很有道理。

但法院说：你只说对了一半。

# 三、法院的逻辑：纳税义务和税收经济负担，是两回事

法院的核心裁判，区分了两个概念：

纳税义务

：法律规定谁该去税务机关申报、缴纳

税收经济负担

：这笔钱最终由谁实际承担

这两件事，可以分离。

法官的原话大意是：税、费具有金钱给付的特征，不具有人身专属性，因而税、费的实际承担者可以由当事人约定。我国法律法规，并未禁止纳税义务人与他人约定承担税款。

翻译成人话：法律说卖方是纳税人，意思是卖方得去申报。但卖方该掏的这笔钱，法律并不禁止双方约定由买方来承担。

就像你去餐厅吃饭，账单上写着服务费由顾客承担。你可以说"服务费的法定支付义务人是餐厅"，但你在下单前已经同意了这个条款，吃完饭再反悔，来不及了。

关键在于：你知不知道，同不同意。

# 四、公告的有效性：你知道了，你拍了，你同意了

法院认定彭先生"知道且同意"，基于三个事实：

第一，公告写得清清楚楚。

《竞买公告》和法院《拍卖公告》都明示了税费承担条款，不是藏在某个角落，而是买卖双方"一切税、费"。

第二，他主动参与竞拍。

竞拍不是被强迫的。他在拍前知悉公告内容，仍然出价、竞拍、成交。法律上，这叫"以行为表示接受"。

第三，他持公告材料去缴税。

他去税务所时，提交的正是执行裁定书、拍卖公告、网络竞价成交确认书——也就是说，他自己是拿着这些材料去申报的，缴完之后又说"我不该缴"，前后矛盾。

法院的结论很干脆：

> "其在知晓竞买公告规定相关税费由其承担后仍参与了涉案房产的竞拍并竞拍成功，应视为其已同意按照涉案竞买公告的规定缴纳相关税款。"

一个"视为同意"，堵死了回头路。

# 五、税务局的角色：我只管收税，公告合不合法我管不了

彭先生还有一个角度：拍卖公告本身就不合法——最高法都说了禁止概括承担，法院的公告违法，税务局依据违法公告征税，也违法。

法院同样堵死了这条路。

理由是：税务局对法院作出的竞买公告的合法性，没有法定审查职权。

换句话说，税务局的职责是依据申报材料核定税款，不是审查法院的公告合不合法。你觉得公告违法，去找组织拍卖的法院，别找税务局。

这条裁判要旨，对每一个想通过行政诉讼挑战法拍税费的人来说，都是一记提醒：

税务局：核税的，不是审公告的

法院：你交了钱不服公告，找的不是税务局

找错了被告，打不赢官司

# 六、这个案子为什么重要？

这个案子的典型意义，在于法院第一次清晰地切割了两个概念：纳税义务和税收经济负担。

以前，很多人——包括一些法律从业者——把这两个概念混为一谈。觉得"法律说卖方是纳税人，那卖方就该掏钱，买方凭什么掏"。

这个案子告诉你：法律确实规定了谁是纳税人，但法律并不禁止双方约定谁来实际承担。在合同有效约定的情况下，非纳税义务人自愿替纳税人掏钱，合法有效。

这对法拍市场影响巨大。全国各地的司法拍卖公告，绝大多数都写了类似条款。这个判决意味着：只要公告明示、你知悉、你竞拍，你就得按公告掏钱。

最高法虽然"禁止概括承担"，但司法实践中，各地法院的公告仍大量保留此类条款。法院和法院之间、法院和税务局之间，在这个问题上存在明显张力。本案判决也指出，这"揭示了相关制度建设的迫切性"——制度层面，仍有待厘清。

# 七、给老板、财会、律师的三个提醒

第一，拍前看公告，别只看起拍价。

法拍房便宜，是结构性便宜——税费、清退、抵押、租赁，每一项都是成本。公告里那行"一切税、费"，可能就是几十万。把公告从头到尾读三遍，再决定出不出价。

第二，"知悉+参与"=同意，别想着事后反悔。

法律上，竞拍成功视为接受公告全部条款。你看到了条款还拍，就是同意。事后以"我不是纳税义务人"为由反悔，法院不支持。签字之前，把成本算清。

第三，找对救济渠道。

彭先生输在哪？他告的是税务局，理由是公告违法。但法院说，税务局不审公告合法性。如果你真觉得公告条款违法，应该告组织拍卖的法院——但那是另一个更难的诉讼。选择救济渠道之前，先想清楚被告是谁、审查范围是什么。

# 八、最后

法拍房便宜，是便宜在信息差和风险溢价上。

你看到的折扣，是别人替你承担了风险的价格。当你自己进场，那个"别人"就变成了你。

公告里每一行小字，都是成本。竞拍前没算清的账，过户那天都会找上门来。

彭先生交了学费。这个判决，就是他用真金白银换来的提醒：

签字之前，请把公告读完。
