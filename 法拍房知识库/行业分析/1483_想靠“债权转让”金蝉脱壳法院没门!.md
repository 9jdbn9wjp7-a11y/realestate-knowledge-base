# 想靠“债权转让”金蝉脱壳？法院：没门！

> 发布时间: 2026年9月16日 14:55

欠了一屁股债，手里却有一笔别人欠我的钱。怎么办？有人想了个“妙招”：把这笔债权无偿转让给“自己人”，让法院去执行这笔钱，自己则继续欠着其他债权人的钱不还。这招能行吗？河北高院的最新裁定告诉你：不行！

今天这个案子，涉及一个非常“聪明”的操作：某建工公司自己欠钱不还，被多个法院执行，却把自己对另一个公司的千万债权“无偿转让”给了自己的员工晏某如。晏某如拿着转让协议，跑到法院要求变更自己为申请执行人，想把执行回来的钱装进自己口袋。

法院一眼看穿：这是规避执行！ 最终，河北高院裁定：驳回变更申请！

案情回顾：一场“精心设计”的债权转让

某建工公司与某房地产公司有建设工程施工合同纠纷，邯郸仲裁委裁决某房地产公司支付某建工公司工程款1778万余元及利息、违约金106万余元。裁决生效后，某房地产公司不履行，某建工公司向邯郸中院申请执行。

执行过程中，某建工公司与晏某如签订了一份《债权转让协议书》，约定：某建工公司将仲裁裁决书所载对某房地产公司的全部权利无偿转让给晏某如。晏某如受让后，负责偿还施工期间拖欠的债务。某建工公司配合晏某如申请变更强制申请人为晏某如。

晏某如拿着协议，向邯郸中院申请变更自己为申请执行人。邯郸中院裁定驳回。晏某如不服，向河北高院申请复议。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/WjOdeWDuNW92dKc1p0ug8zZia8uqh9AhJXoGFiaKyBHaibckFfHAb5WFVXrXJWVSkzGdgdoR5fwqQica47C1E6GcEB3mlZmsxpMVahk87gZSd1o/640?wx_fmt=jpeg&watermark=1#imgIndex=1)

河北高院审查发现几个关键事实：

第一，某建工公司自己就是“老赖”。 截至2022年9月19日，某建工公司存在多件作为被执行人的执行案件未能执行完毕。

第二，晏某如明知某建工公司欠债。 晏某如在给某建工公司的《请示报告》中写道：由于公司在邯郸还有其他诸多项目，在邯郸市丛台区法院、邯郸中院已经出现了作为被执行人的案件在执行当中。执行法院欲将扣留案涉项目财产去还公司其他项目的债务。为避免晏某如承包施工的项目经济受损，请求把案涉项目债权转让给晏某如。

第三，转让范围有问题。 仲裁裁决涉及案涉项目1#、2#、3#、4[#楼及地下车库等全部工程](javascript:;)，但晏某如自述只负责3[#和4](javascript:;)[#楼施工](javascript:;)。某建工公司却把全部债权无偿转让给了晏某如。

第四，没有书面认可。 晏某如没有提供某建工公司书面认可其取得生效法律文书确定债权的证据。

河北高院最终裁定：驳回复议，维持原裁定。

法院裁判要点：执行中的债权转让，不是想转就能转

这个案子的核心是：生效法律文书确定的债权转让，法院审查比普通合同债权转让严格得多。

根据《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》第九条：

申请执行人将生效法律文书确定的债权依法转让给第三人，且书面认可第三人取得该债权，该第三人申请变更、追加其为申请执行人的，人民法院应予支持。

注意三个关键词：依法转让、书面认可、第三人取得。

法院在审查时，不是只看有没有转让协议，还要审查：

2.  转让是否真实——是不是真的转让，还是为了规避执行搞的“假转让”？

4.  转让是否合法——有没有违反法律强制性规定？

6.  是否损害其他债权人合法权益——转让后，原申请执行人的偿债能力是否降低？其他债权人还能不能拿到钱？

本案中，某建工公司自己欠债不还，却把千万债权无偿转让给晏某如。晏某如明知某建工公司有未执行完毕的案件，转让目的是“避免自己承包施工的项目经济受损”。这明显是通过转让债权，把本该用于偿还某建工公司债务的财产，转移给晏某如个人，势必降低某建工公司的偿债能力，损害其他债权人的利益。

法院认定：该债权转让行为明显有规避执行之嫌，不予支持变更申请。

法律要点：变更申请执行人，需要满足哪些条件？

结合本案，债权人或受让人要注意以下几点：

第一，必须有书面认可。 光有转让协议不够，原申请执行人必须书面认可第三人取得债权。这是法定条件，缺一不可。

第二，转让必须“依法”。 如果原申请执行人自身有未清偿债务，且已进入执行程序，无偿转让债权明显损害其他债权人利益的，法院不会支持。

第三，债权范围要清晰。 转让的债权必须明确，不能把不属于受让人的债权也打包转让。本案中，晏某如只负责3#、4[#楼](javascript:;)，却受让了全部债权，明显不合理。

第四，不能规避执行。 如果转让的目的是为了逃避原申请执行人的债务，法院会穿透审查，认定转让无效或不予变更。

给债权人的警示：别想靠“转让”逃债！

这个案子给所有想通过债权转让规避执行的“老赖”们敲响了警钟：

第一，法院不是傻子。 你自己欠一屁股债，却把债权无偿转给别人，法院一眼就能看出你在转移财产。这种操作，不仅变更申请执行人会被驳回，还可能被认定为拒不执行判决、裁定罪。

第二，债权转让不能损害其他债权人利益。 你的债权也是你的责任财产。你把债权无偿转走，其他债权人就少了一份受偿的可能。法律不允许你通过这种方式“金蝉脱壳”。

第三，员工、亲友不是“避风港”。 把债权转给员工、亲友，看似安全，实则风险巨大。法院会审查转让的真实性、合法性，一旦认定规避执行，转让行为可能被撤销，相关责任人还可能被追究法律责任。

给受让人的提醒：受让债权前，先查清楚！

如果你打算受让别人的生效法律文书确定的债权，一定要做尽职调查：

第一，查转让方有没有未清偿的债务。 如果转让方自己就是被执行人，受让债权后想变更申请执行人，基本不可能。

第二，要求转让方出具书面认可。 这是法定条件，没有书面认可，法院不会支持变更。

第三，明确债权范围。 你受让的是哪部分债权，要有明确约定，不能含糊。

第四，保留真实交易的证据。 如果是有偿转让，保留付款凭证；如果是无偿转让，要能说明合理理由。否则，法院可能认定转让不真实。

结语：执行程序中的债权转让，法院严把关

生效法律文书确定的债权，不是普通的合同权利。它已经进入强制执行程序，背后涉及申请执行人、被执行人、其他债权人等多方利益。法院对债权转让的审查，必须严格。

这个案子告诉我们：想通过债权转让规避执行，门都没有。 法律保护合法的债权转让，但绝不允许利用转让损害他人利益、逃避债务。

记住：欠债还钱，天经地义。想耍小聪明，最终只会搬起石头砸自己的脚。
