# 南宁买法拍房怕踩坑？实地看房需要注意哪些？

      上个月，一个南宁粉丝拍下青秀区一套法拍房，价格便宜了15万。过完户去收房，发现里面住着人，还说签了十年租约。他回头翻公告，才发现自己拍之前根本没去现场看过。

他问我怎么办。我说你拍之前怎么不去看一眼。

      法拍房最大的风险，不是价格，是盲买。今天老谭把实地看房要盯的6个地方，一次讲清楚。想在南宁、广西拍法拍房的，先收藏。

# 一、拿公告对现场，提防隐形地雷

去现场第一件事，拿法院公告，实地比对。

       公告写房子空置，你到现场一看，里面住着人。公告写没有租约，邻居告诉你，这房子早就租出去了。

       这不是个别现象。被执行人在查封前后，完全有可能把房子偷偷租出去，或者给别人设立居住权。你拍下来才发现房子跟公告不符，麻烦就大了。

记住：不要只看公告字面意思。亲自去不动产登记中心核实，有没有抵押、有没有居住权登记、有没有备案租赁。

# 二、看墙角、看天花板，别被装修迷惑

看房别光盯着客厅地板、厨房瓷砖。真正的隐患藏在细节里。

    看墙角。墙角承载结构受力。发现严重裂缝或水渍，说明可能渗漏，甚至影响承重。这种房子拍下来，后期维修成本很高。

     看天花板。抬头看有没有水渍，漆面是否均匀。有明显水痕的，大概率是楼上漏水或防水层出了问题。

     看窗户和阳台。有没有渗水痕迹，密封胶有没有老化。广西回南天多，防水没做好，住进去就是噩梦。

# 三、查违建，别等过户才发现要拆

法拍房大多是现房，留意卧室私密性和隔音。

      更要紧的是，核查有没有违规改造。有些原业主大改过结构，打掉承重墙、阳台改房间、顶楼加建。如果相关部门要求恢复原状才能过户，这笔拆改成本就是你出。

       南宁不少老小区和自建房，违建很普遍。拍之前去不动产中心调档，看原始测绘图和现状对不对得上。

# 四、算清隐形账单，总成本可能超预算

法拍房表面价格诱人，背后跟着一堆欠费。

        去物业核对清楚，拖欠的水电费、物业费到底多少。这笔钱大概率要买家承担。我见过南宁有房子拖欠物业费十几年，加上滞纳金，几万块。

      户口和学位也要查。法院只管过户，不管户口。原房主赖着不迁，你的户口落不进去。买学区房的更要注意，提前去物业、辖区派出所或学校，问清落户政策和学位占用情况。别等孩子报名被卡住才后悔。

# 五、摸清占用情况，评估腾房难度

      房子现在有没有人住？住的是原房主还是租客？租期还有多久？配合搬离的意愿如何？

这些问题直接决定你后续收房要花多少时间和精力。

     现场跟邻居、物业多打听，问问这家人好不好说话，有没有人来讨过债，有没有人经常来闹。这些信息公告不会写，但对判断腾房难度很关键。

# 六、了解真实市值，别盲目出价

      去附近中介门店转转，看看同小区近三个月的二手房实际成交价，对比一下两年前的价格走势。

       南宁有些片区跌得厉害，挂牌价和真实成交价差一两千一平。你按挂牌价去设竞拍底线，很容易拍贵。

做到心里有数，才能设定合理的出价红线。超过红线，坚决放手。

# 最后说几句

买法拍房，绝不是拆盲盒。想捡漏，就得靠脚底板跑出来的专业调研。

      前期准备越足，后期麻烦越少。看房这关过了，腾房、过户、税费那几关，才有底气往下走。

      我是广西老谭，深耕本地法拍实务。看中哪套法拍房，拿不准有没有坑，直接把公告发给我，我帮你一条一条排查。
