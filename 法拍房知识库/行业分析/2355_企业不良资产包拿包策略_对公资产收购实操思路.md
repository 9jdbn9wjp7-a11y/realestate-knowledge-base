      在不良资产圈，大家常说：处置决定收益，但拿包决定底线。一包遴选失当，后续处置团队即便具备较强处置能力，也很难修复预期 IRR；标的遴选得当，处置环节推进压力会显著降低。对公企业不良包，债务人大多是工商企业，经常连带担保、股权质押、在建工程、土地厂房混在一起，还有破产、预重整、债务重组的可能性，筛选、谈判、竞价的逻辑，和分散的个贷包差异巨大。

# 一、渠道策略：不止蹲拍卖，分一级、二级、定向勾包

      很多从业者仅关注阿里、京东拍卖标的，优质对公大包很少直接投放公开网拍渠道。圈内主流拿包渠道分为三类：

      银行、全国性 AMC 一级批量转让：银登中心挂牌、AMC 公开推介会，属于一手源头包，资产信息相对完整，体量偏大，很多是组包出售。技巧：维护好银行资产保全部、各 AMC 办事处常态化对接，提前锁定推介清单，等正式挂牌前就完成初步摸排，不要等公告出来才启动尽调。

      地方 AMC、机构二手流转包：地方 AMC 收进来之后，因资金周期、处置方向、属地协同需求，对外分转、分包。优势是很多包已经完成一轮尽调，风险点有前置披露；技巧：优先看属地本地包，本地机构熟悉当地法院、园区、债务人背景，后续处置协同成本更低，也是现在省属国企、纾困基金最偏好的渠道。

      定向 “勾包”（拆包、挑单）：银行原本是一个混合大包，里面有优质抵押债权，也有无抵押、处置难度较高的债权。圈内一个高频技巧：和出让方沟通拆包、摘单，只拿清单里有抵押物、有重整价值的企业债权，审慎承接处置难度较高的债权。

      破产管理人、府院联动纾困项目：预重整、破产程序里的债权包，很多由管理人对外招募投资人。这类包核心不是拍卖竞价，而是和债务人、债权人委员会、地方专班谈重组方案，适合产业资本、地方纾困平台。

# 二、筛包技巧：先做分层，审慎研判低账面折扣标的

      对公包在业务实践中，容易出现账面折扣优厚，但底层存在担保悬空、抵押物存在优先权利负担等隐性资产瑕疵的情形。行业通用筛选标准：优先标的：债务人主体仍在经营、有土地 / 厂房 / 核心设备抵押、有实控人连带担保、正在推进预重整 / 债务重组，具备盘活价值；审慎研判标的：纯保证无抵押、债务人吊销多年、抵押物有在先工程款优先权、长期有效长租、大量欠税、多轮查封叠加； 审慎排除标的：债务人无任何可执行财产、担保方为空壳主体、涉非法集资等刑事查封资产。

      一个实用圈内经验：看 “可回款路径”，而不是只看抵押物评估价。企业包回款路径分三类：抵押物司法拍卖回款、债务人经营现金流重组还款、产业投资人接盘重整。只要其中一条路径落地存在重大障碍，估值就要大幅打折。

      另外，组包里要做 “加权穿透”：一包里面十几户企业债权，不要用平均折扣判断好坏，单独拎出每户的抵押、查封、诉讼状态，把 “核心标的” 和配套债权分开算账，很多大包就是用好标的带动配套债权一起打包出让。

# 三、尽调拿包核心技巧：对公包尽调是出价的前提

      行业共识：未穿透尽调支撑的报价，具备较高不确定性。对公企业尽调，重点和个贷不一样：

      工商穿透：核查股权结构、历史出资、有没有抽逃出资、关联企业互保圈，对公包重要的或有风险集中在连环担保链，一户风险爆发，多家连带，资产互相查封；

      财产线索核验：不动产登记、首封 / 轮候查封顺序、抵押登记时间，重点排查工程款优先权、承租人优先购买权、税费优先权，这些权利优先级经常高于普通抵押权；

      诉讼与执行卷宗：看之前终本原因，是暂时无财产，还是财产早已发生转移、隐匿；是否已经进入破产程序，破产受理后停止计息、个别清偿失效，会直接改写收益测算；

      实地走访：厂房是否正常生产、抵押物是否被占用、租户租赁关系是否真实、当地政府对于企业是否有纾困保生产的诉求。很多对公项目，地方维稳、保就业诉求会直接影响处置方式，单纯司法拍卖路径未必具备可行性。

      圈内实操技巧：尽调分两轮。第一轮低成本粗筛，用公开信息、出让方提供档案快速判断要不要进场；第二轮深度尽调，聘请律师、评估机构进场，锁定最高可承受价（底价红线），一旦报价突破该阈值，终止竞价参与。

# 四、竞价与谈判策略：四种交易模式，打法各不相同

      对公企业不良包常见出让模式：密封暗标、英式多轮竞价、协商谈判、重组招募，技巧完全不一样。

      密封暗标（一次性报价）：银行、AMC 批量转让最常用，无法获知竞争对手报价。圈内经验：不要报在底价刚好压线位置，同时准备两套方案，一套基础报价、一套附带重组方案的增值方案。对公项目出让方有时候不只看价格，还看收购方盘活运营能力，能否配合府院纾困工作。

      网络多轮加价拍卖：竞争激烈、抵押物清晰的标的容易走这个模式。主要风险为竞价情绪化推高成本。技巧：提前把最高红线明确，到价直接停，不与对手反复拉锯。

      协商议价模式（定向转让）：适合复杂重整项目、属地协同项目。谈判筹码不止出价，还可以配套方案：比如承诺持续帮扶企业复工、承接职工安置、配合地方纾困，用综合方案争取更优价格、付款节奏（分期支付、保证金后置）。

      联合拿包：也是高频玩法。AMC、产业投资人、地方平台组队拿对公大包：AMC 持牌、产业方负责后期盘活运营、地方平台协调属地资源，分担资金压力、分散风险，也是最近困境企业纾困项目的主流模式。

# 五、容易被忽略的拿包配套策略

1.  资金节奏匹配：对公包处置周期普遍很长，动辄 2-4 年甚至更久，尽量匹配长期低成本资金，短期限资金投向对公大包容易出现资金成本侵蚀全部收益的情形；

2.  属地资源优先：异地企业包审慎参与，异地法院、异地执行、异地工商调查沟通成本极高，同等标的，本地团队可实现的 IRR 往往优于外地机构；

3.  拿包和处置方案同步设计：进场竞价前，就要想好拿到之后是走司法拍卖、债务重组、引入产业投资人，还是放进破产服务信托架构。方案不同，可承受的收购价格完全不同。

# 六、结语

      对公企业不良资产包，比拼的不是报价高低，而是信息尽调、标的研判、资金配套、属地协同、处置路径规划的综合能力。市面上总结的拿包实操要点，核心逻辑可以概括为：先锁定回款路径，再出价；先划定风险承受边界，再参与竞争。账面折扣优厚不等于优质标的，退出路径清晰、风险可控的标的，才具备参与价值。
