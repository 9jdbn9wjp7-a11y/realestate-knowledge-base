# 01

# 两组数字：受理骤降，池子却满了

先看法庭那头的"出口"。下面这张表，是2019年以来人民法院裁定受理A股上市公司破产重整的家数：

![图片](https://mmbiz.qpic.cn/mmbiz_png/upmPPXlHJpZOeHcfia64LzHd0QicicMZ3MSWdOFMH2kKmmYz1R6jYEQwCGPsrOYwhLYPC3ay47o0klv5XBFFyib41IXCnxicfqyiaQRDVrxcWwpCw/640?wx_fmt=png&from=appmsg#imgIndex=0)

数据来源：深交所《证券市场导报》"2010—2025年人民法院受理A股上市公司破产重整案件数量"表；锦天城《中国上市公司破产重整2025年度报告》；2026年数据据上市公司公告及公开统计。

2020至2025这六年，年均受理约14家，最低的一年（2022）也有10家。而2026年走到10月底，只有2家——且这两家的重整投资协议其实都是在2025年签的（华闻产投协议签于2025年5月、财投于2025年10—11月；西发签于2025年12月），属于上一年的"存量兑现"。

更具反差感的是另一头——"入口"不仅没收窄，反而更挤了。据公开统计，截至2026年6月，A股及北交所共有227家 ST/\*ST 公司（\*ST 135家、ST 92家）；处于法院预重整程序的上市公司约24家，另有约9家在推进庭外重组。换句话说：想进重整的门排起长队，但门只开了两道缝。

这就是2026年最反常的地方——不是没人签协议，而是签了协议、却迟迟进不了法院。

# 02

# 为什么"晚"？强监管把"保壳式重整"的捷径封了

#

断崖发生在2024年底到2025年。三道制度闸门几乎同时落下：

·2024年12月31日，《关于切实审理好上市公司破产重整案件工作座谈会纪要》（下称《纪要》）发布；

·2025年3月14日，证监会《上市公司监管指引第11号——上市公司破产重整相关事项》（下称《11号指引》）施行；

· 同步落地的，是交易所退市新规与配套自律监管指引。

《11号指引》划出的"三条红线"几乎重塑了重整的经济结构：资本公积转增比例不得超过每10股转增15股；重整投资人入股价格不得低于市场参考价的50%；控股股东/实控人认购股份锁定36个月、其他投资人锁定12个月。

更关键的是"价值审查＋整改前置"：资金占用、违规担保原则上要在进入重整程序前完成整改；年营收低于3亿元的上市公司，获批概率大幅降低；对"不具备重整价值"的，监管明确导向是"通过退市或破产清算等方式有序出清"。

效果立竿见影。2025年新规落地后，30余家申请公司中仅约14家拿到监管"路条"（预重整备案/受理的前置认可），大批壳公司被挡在门外。到了2026年，这道闸口收得更紧——前面那2家受理，是2025年的尾巴；2026年新签的协议，至今没有一家借此"转正"为法院正式受理。

# 03

# 池子里的20+家：签了协议，却卡在"受理"前

#

把截至2026年10月下旬、已进入预重整（含庭外重组）且已签署重整投资协议的上市公司梳理一遍，大约有20家。它们的共同特征是：协议签了、投资人定了、钱也备了，但卡在"法院受理"这道司法门槛前——而预重整本身没有司法强制效力，庭外重组更只是各方自主协商。

# 04

# 谁在和时间赛跑：今年不"完"就退市的名单

这是最冷酷的一节。按现行上市规则，因2025年年报财务指标（期末净资产为负、扣非前后营收低于1亿元、审计意见为非标等）被实施\*ST的公司，必须在2026年年报消除相关情形，否则将被终止上市。

而破产重整要真正"救命"，完整路径是：法院受理 → 批准重整计划 → 执行完毕。通常从受理到执行完毕需要数月到一年。到2026年10月底，距离年报披露窗口只剩两三个月——对绝大多数仍卡在预重整阶段的公司而言，"年内完成"几乎是不可能完成的任务。

已经主动发出"可能被终止上市"风险公告、且明确将重整视为保壳唯一出路的代表公司包括：

·\*ST纳川（300198）：2025年末净资产-1.48亿元、营收低于1亿元，若2026年报仍触及即终止上市；目前仅处于预重整阶段，尚未获法院受理。

·\*ST香雪（300147）：2026年一季度末净资产已转负至-4.71亿元，与中选投资人广药资本的预重整投资协议"仍在协商"，进度条卡住；若年内法院未批准重整计划、期末净资产仍为负，退市几成定局。

·\*ST春兴（002547）：2025年末净资产为负，目前仅为庭外重组，公告明确"能否于2026年度内完成存在重大不确定性"。

此外，前述预重整池中大量\*ST公司（如西发、亿晶、沐邦、棒杰、赛为、易录、启环、泉为、新元、西旅、雪浪、瑞和等）均因2025年报财务指标被\*ST，2026年是它们的"curing year"。一旦重整未能在年底前执行完毕、相关财务指标未消除，明年年报季就将直面终止上市。

一个容易被忽略的细节：\*ST西发虽已被法院受理（4月），但截至10月其重整计划草案尚待表决、未获法院批准，更未完成执行——它同样要在2026年内走完"批准+执行"全流程，才能摘掉\*ST帽子。当然，按照经验，既然已经受理，重整计划执行完毕几无悬念。
