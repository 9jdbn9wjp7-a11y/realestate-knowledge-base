# 序言

债权转让中次债务人（即债务人的债务人）向原债务人（让与人）清偿的效力，取决于一个关键事实：其清偿时是否已接到债权转让通知。通知前，清偿有效，债务消灭；通知后，清偿不能对抗受让人，债务人仍负清偿义务，只能向受让人为给付后转而向原债权人追索不当得利。本文以《民法典》第546条及《合同编通则解释》第48条为规范基础，从律师实务视角梳理不同情形下的法律后果、举证要点与风险防范策略。

# 一、规范基础：通知是“对债务人效力”的开关

《民法典》第546条第1款规定：“债权人转让债权，未通知债务人的，该转让对债务人不发生效力。”该条采取通知主义，债权转让在让与人与受让人之间自协议生效时即完成，但要对债务人产生拘束力，须以通知到达为前提。换言之，通知不决定债权是否移转，只决定债务人应当向谁履行方可免责。

《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（下称《合同编通则解释》）第48条进一步将这一规则具体化，即次债务人在接到通知前已向债务人（让与人）履行的，债权人（受让人）请求次债务人履行的，人民法院不予支持；次债务人接到通知后仍向债务人（让与人）履行的，债权人（受让人）请求次债务人履行的，人民法院应予支持。该条为次债务人向债务人清偿的效力判断提供了直接的裁判依据。

# 二、通知到达前：向债务人清偿有效，受让人无权再请求

在通知到达之前，对次债务人而言，债务人仍然是其债权人。次债务人向债务人清偿，产生债务消灭的法律效果，债权人（受让人）无权要求次债务人再次清偿。此时债权人（受让人）的救济路径不在次债务人，而债务人。债权人（受让人）可依据债权转让协议向原债权人主张违约责任，或主张债务人收取该款项构成不当得利。

通知到达的判断采客观标准。次债务人“事实上知悉”债权转让但未收到符合要求的通知，不产生通知效力。债权人（受让人）仅通过自身渠道发布公告、APP弹窗等方式，通常不构成有效通知。律师在代理债权人（受让人）一方时，不能以“次债务人应当知道”替代“通知已经到达”的举证。

# 三、通知到达后：向债务人清偿不消灭债务，次债务人仍须向债权人（受让人）履行

通知到达后，次债务人的履行对象在法律上已经变更为债权人（受让人）。其仍向债务人清偿的，不产生清偿效力，债权人（受让人）仍有权请求次债务人向自己履行。次债务人不能以“我已经还过钱了”为由对抗受让人的履行请求，其与债务人之间的清偿关系，只能另行通过不当得利之诉向债务人追索。

《合同编通则解释》第48条后段还规定，债务人（让与人）未通知，债权人（受让人）直接起诉次债务人的，债权转让自起诉状副本送达时对次债务人发生效力；次债务人因此增加的费用或损失，可请求从认定的债权数额中扣除。这一规则实际上赋予起诉行为以“补正通知”的功能，但起诉状副本送达之前的清偿行为仍然有效。律师在评估是否起诉时，需要将“送达时点”与“清偿时点”的先后关系作为核心事实予以固定。

此外，次债务人在接到通知后对债务人享有的抗辩，可以向受让人主张（《民法典》第548条）；符合法定条件的抵销权亦可向债权人（受让人）行使（第549条）。这意味着“通知后仍向债务人清偿”并非次债务人的唯一“出路”。及时主张抗辩或抵销，才是通知到达后更为理性的应对方式。

# 四、特殊情形的实务处理

一，金融不良债权转让中存在特殊规则。国有企业作为次债务人知道或应当知道债权已转让而仍向原国有银行清偿的，不得对抗受让人的追索之诉；其对受让人清偿后，可向原国有银行提起不当得利返还之诉。这一规则对普通债权转让虽无直接适用力，但其背后“知道或应当知道”的认定逻辑，在通知方式不规范时具有参考价值。

二，保证人的清偿准用同一规则。《民法典》第696条明确，债权转让未通知保证人的，该转让对保证人不发生效力，保证人向债务人清偿仍产生清偿效果。受让人在受让有担保的债权时，应将通知义务延伸至保证人。

三，多重转让中的“最先通知”规则可能间接影响清偿效力判断。《合同编通则解释》第50条以“最先到达债务人的通知”确定债务人的免责履行对象。在多重转让场景下，次债务人向“最先通知的受让人”清偿即可免责；但在通知到达前，其向原债务人的清偿仍然有效。律师需要将“通知到达时间线”作为多重转让案件的基础事实工作。

# 五、律师实务中的风险防范与诉讼策略

对受让人一方，核心工作是“让通知可证明地先于清偿到达”。建议在债权转让协议中明确约定由让与人负责发出通知，并设置相应的违约条款；通知方式优先选择次债务人签收确认、EMS邮寄并保留回执、电子邮件或短信截图，必要时对送达过程进行公证。若让与人怠于通知，受让人可直接起诉，以起诉状副本送达完成通知，但应同步评估次债务人此前是否已经清偿以及由此产生的费用扣减风险。

对次债务人一方，收到任何形式的转让通知后，应立即停止向原债务人付款，转而核实通知的真实性。若通知未附债权转让协议、让与人身份证明等必要文件，可以要求补正，但不宜以“文件不全”为由继续向原债务人清偿。司法实践对通知形式的要求并非绝对严格，继续向原债务人付款的风险显著高于要求补正的成本。如对原债权人享有到期债权或抗辩事由，应在通知到达后及时向受让人主张抵销或抗辩，而非通过向原债权人“抢先清偿”来规避。

对原债权人（让与人）一方，在已经转让债权并通知次债务人后接受其清偿的，面临受让人的违约索赔和次债务人的不当得利返还请求的双重风险。已收款的原债权人不应将“次债务人自愿还给我”视为安全的受领依据。

# 六、结语

次债务人向债务人清偿的效力，本质上是一个通知到达时点与清偿时点的先后比较问题。通知前，清偿有效，风险由受让人承担；通知后，清偿无效，风险由次债务人承担，并可向原债权人转化。债权转让的各方参与者，都应当将“通知”从一项形式性手续，提升为决定实体权利义务走向的关键法律行为来对待。对于律师而言，代理此类案件的首要工作，往往不是争论实体债权是否存在，而是精确还原通知的发出、到达与清偿的时间序列。这正是《民法典》第546条与《合同编通则解释》第48条留给实务操作的核心空间。
