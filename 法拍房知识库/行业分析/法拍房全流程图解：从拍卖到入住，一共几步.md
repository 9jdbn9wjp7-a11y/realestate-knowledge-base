很多人对法拍房感兴趣，但一想到复杂的流程就头大。

去哪里找房源？怎么报名竞拍？拍中了之后怎么办？什么时候能拿到房产证？什么时候能住进去？

这些问题，新手基本都搞不清楚。今天这篇文章，我就用最直白的方式，把法拍房的完整流程一步一步讲清楚。看完你就知道，从看到一套法拍房，到最后拿到钥匙住进去，一共要经历哪些步骤。

# 01 第一步：找房源、做筛选

买法拍房的第一步，当然是找到合适的房源。

很多人不知道去哪里找法拍房，以为要找法院或者找关系。其实不用，现在法拍房基本都在网上公开拍卖，人人都能看。

官方渠道主要有这几个：

阿里拍卖：最大的法拍房平台，房源最多

京东拍卖：第二大平台，房源也不少

公拍网：上海等地用得比较多

诉讼资产网：法院指定的拍卖平台

这些平台都是官方认可的，直接在网站上就能看房源信息、看照片、看拍卖公告，不用花钱。

找到房源之后，第一步不是急着报名，而是先做初步筛选。根据你的预算、区域、面积、户型等条件，先把明显不符合的排除掉，缩小范围。

新手建议：刚开始不要贪多，先锁定2-3个目标小区，重点关注这几个小区的法拍房。看多了你就知道这个小区的正常价格是多少，遇到便宜的才能快速判断值不值得出手。

# 02 第二步：做尽调、查风险

这是法拍房最关键的一步，也是最容易踩坑的一步。

看中一套房子之后，一定要做全面的尽调，也就是调查清楚这套房子的所有情况。不要只看平台上的照片和介绍就出价，那上面的信息可能不全，甚至可能有遗漏。

尽调主要查这些内容：

产权情况：房子是谁的？有没有共有人？有没有抵押？有没有查封？

租赁情况：房子有没有租出去？租约多久？租金多少？

占用情况：房子里现在住着谁？是房主还是租客？腾退难度大不大？

税费情况：过户要交多少税？有没有欠税费？

欠费情况：有没有欠物业费、水电费、暖气费？

户口情况：房子里有没有户口？能不能迁走？

房屋质量：房子有没有质量问题？有没有被损坏？

这些信息，有些能在拍卖公告里看到，有些需要你自己去查，比如去房管局查产权、去小区物业查欠费、去实地看房了解情况。

如果自己不懂怎么查，或者没时间，可以找专业的辅拍机构帮忙做尽调。花点小钱，避免踩大坑，还是值得的。

# 03 第三步：交保证金、参与竞拍

尽调做完，确认房子没问题、值得买，接下来就可以报名竞拍了。

竞拍前需要先交保证金，保证金一般是起拍价的10%-20%。比如起拍价100万的房子，保证金可能是10万到20万。

保证金要在拍卖开始前交，交了之后才能获得竞拍资格。如果没拍中，保证金会在拍卖结束后退给你，一般几个工作日就能到账。如果拍中了，保证金就直接转为房款的一部分。

竞拍的时候要注意几点：

设定心理价位：出价前先想好自己最多能出多少钱，超过这个价就放弃，不要脑子一热就往上加

不要过早出价：刚开始不用急着出价，等快结束的时候再出手，避免过早暴露意图

注意延时机制：法拍房一般有延时出价，最后几分钟有人出价就会延时，不要以为到点就结束了

保持冷静：竞拍很容易上头，尤其是有人跟你竞价的时候，一定要保持理性，不要为了争口气多花钱

# 04 第四步：付尾款、拿裁定书

拍中之后，接下来就是付尾款。

法拍房的付款期限一般比较短，通常是7到15天，具体看拍卖公告的要求。也就是说，你要在很短的时间内把剩下的房款全部付清。

这也是法拍房的一个难点。很多人以为可以像二手房一样慢慢办贷款，但法拍房的付款时间很紧，如果贷款办不下来，就可能违约。

关于法拍房贷款：现在很多法拍房也可以办理按揭贷款，但流程和二手房不太一样，需要提前准备材料、提前审批。如果要贷款，一定要在竞拍前就和银行沟通好，确认能贷多少、多久能放款，避免拍下来之后贷款办不下来。

尾款付清之后，法院会出具《执行裁定书》和《协助执行通知书》，这两个文件非常重要，是你办理过户的关键凭证。

重要提醒：如果拍中之后反悔不买了，保证金是不退的。而且如果下次拍卖价格比这次低，差价还要由你补上。所以竞拍前一定要想清楚，不要随便出价。

# 05 第五步：办过户、拿房产证

拿到法院的裁定书之后，就可以去办理过户了。

过户的流程和二手房差不多，主要是去不动产登记中心办理产权转移登记。但因为是法拍房，需要的材料不太一样，除了常规的材料，还要带上法院的裁定书、协助执行通知书、拍卖成交确认书等文件。

法拍房过户有个好处：不需要原房主配合，拿着法院的文书就能直接办。哪怕原房主不配合、找不到人，都不影响你过户。

过户的时候要交税，税费的问题我们之前说过，一定要提前算清楚，有些法拍房的税费可能很高。

过户办完，拿到新的房产证，从法律上来说，这套房子就完全是你的了。

# 06 第六步：腾退、交房入住

拿到房产证，是不是就可以住进去了？不一定。

如果房子是空的，那当然没问题，直接换锁入住就行。但如果房子里有人住，那就涉及到腾退的问题了。

腾退是法拍房最麻烦的环节之一。有些原房主或者租客会配合搬走，有些则各种耍赖，就是不搬。

腾退的方式主要有几种：

协商解决：和对方好好谈，给点搬家费、给点缓冲时间，让对方主动搬走。这是最理想的方式，成本低、速度快

法院协助：如果对方不配合，可以向法院申请强制执行，由法院出面腾退。但这个过程可能比较慢，需要耐心等待

自行处理：在合法的前提下，通过各种方式促使对方搬走。但一定要注意，不能用违法手段，比如断水断电、强行闯入，这些都是不行的

腾退完成，拿到钥匙，你终于可以住进这套房子了。到这里，整个法拍房的流程才算真正结束。

# 整个流程要多久？

很多人问：买一套法拍房，从头到尾要多长时间？

这个没有标准答案，要看具体情况。

如果一切顺利，房子是空的、没有纠纷、付款也顺利，那从拍中到入住，可能一两个月就能搞定。

但如果有腾退问题、有纠纷、流程不顺利，那可能要半年、一年，甚至更久。

所以，买法拍房一定要有耐心，也要有心理准备，它不像买二手房那么快、那么顺。

# 写在最后

以上就是法拍房的完整流程，一共六步：找房源、做尽调、竞拍、付款、过户、腾退。

看起来步骤不多，但每一步都有很多细节和注意事项。尤其是尽调和腾退这两步，最容易出问题，也最考验人的能力。

如果你是新手，不建议一上来就自己操作。可以先多看看、多学学，了解清楚了再出手。或者找靠谱的专业机构帮忙，花点服务费，但能少走很多弯路、少踩很多坑。
