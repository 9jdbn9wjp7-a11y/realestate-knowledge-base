# 88万元保证金不予退还：法拍房拍中后，还能反悔吗？

看中一套法拍房，交了保证金，跟着出了几次价。

直到竞价结束，才开始担心：价格是不是追高了？贷款能不能及时到账？家里人不同意，还能不能不要了？

这些问题，最好在出价前就有答案。

杭州一套房两次悔拍、合计88万元保证金不予退还的报道，值得准备在成都参拍的买房人看一看。

**先说清楚：88万元是两次悔拍、每次44万元的合计，不是已经证实的某一位买家单次损失。**

## 01｜同一套房，两次悔拍

据《都市快报》2026年7月30日报道，杭州萧山四季华庭一套房源，当年3月6日以330万元成交后发生悔拍；6月14日再次以285万元成交，随后又发生悔拍。两次各有44万元保证金不予退还，合计88万元。查看报道

这是杭州的既有案例，并非今天成都新发生的事件。报道没有明确交代两次悔拍的具体原因，也不能据此断言是贷款失败所致。

我们借它讨论一个参拍前必须弄明白的问题：**拍中之后不想买，代价到底是什么？**

## 02｜没拍中和拍中后不要了，是两回事

有人把保证金理解成“先占个报名名额的钱”，认为只要最后不买，就能原路退回。

网络司法拍卖不是这样。

按照最高人民法院关于网络司法拍卖的规定，三种情况要分开看：

|
参拍结果

 |

保证金如何处理

 |
| --- | --- |
|

 |

其他竞买人的保证金，应在竞价程序结束后24小时内退还或者解冻

 |
|

 |

已交保证金可以充抵价款

 |

 |

如果拍卖未成交，竞买人的保证金也应在竞价程序结束后24小时内退还或者解冻。以上依据该规定第二十三条、第二十四条。最高人民法院原文

换句话说，**“出价没赢”与“出价赢了却不要”，后果完全不同。**

## 03｜保证金，不等于买房首付款

参拍之前，还有一个容易混淆的地方：交得起保证金，不代表付得起这套房。

举一个纯计算示例，与前述杭州案例无关：

假设一套房最终以100万元成交，买受人已交10万元保证金。保证金充抵价款后，尚有90万元房款需要按要求支付。税费及其他经核实应由买受人承担的费用，另行准备。

这90万元中，有多少能通过贷款解决、贷款何时到账，不能只凭一句“这套房能贷”来安排。

最高人民法院关于网络司法拍卖的规定第二十五条要求，买受人应当在**拍卖公告确定的期限内**，将剩余价款交付人民法院指定账户。

因此，不要把别人的付款周期套在自己看中的房源上，也不要默认拍中后可以慢慢筹钱。

参拍前，把这三个问题写下来：

-   • 这套房的尾款截止时间，具体是哪一天？

-   • 可动用的自有资金是多少，什么时候能到账？

-   • 如需贷款，银行对人、房、额度和放款时间分别有什么要求？

**预算表里要写能落实的资金，不能只写希望借到的钱。**

## 04｜贷款没有下来，能自动延期吗？

不能这样默认。

贷款是否获批、能批多少、什么时候到账，需要结合借款人的情况、标的条件以及银行审核结果确认。咨询得到的初步答复，不宜当成最终放款承诺。

如果真的遇到审批或放款延迟，应尽快向执行法院说明情况，提交贷款申请、审批进度、资金筹措等材料，依法申请处理。

**提出延期申请，不等于延期已经获准。**

是否构成悔拍、相关请求能否得到支持，要由法院结合具体事实依法处理。既不能说“贷款没下来就一定免责”，也不宜把所有付款延迟都简单归为恶意悔拍。

最不该做的是：自己停付尾款，等期限过了，再认为“最多扣掉保证金”。

## 05｜损失会不会只到保证金为止？

不要把保证金当成最高损失额度。

网络司法拍卖规定第二十四条明确，悔拍后不退的保证金，会按规定顺序用于支付拍卖产生的费用损失、弥补重新拍卖价差以及冲抵相关债务；重新拍卖时，原买受人不得参加竞买。

此外，《最高人民法院关于人民法院民事执行中拍卖、变卖财产的规定》2020年修正文本第二十二条，对重新拍卖产生的价差、费用损失等责任，以及保证金不足时责令补交、拒不补交时强制执行，作出了规定。法院公布的修正文本

具体是否需要追加承担、金额如何确定，应结合适用规则、拍卖文件、实际损失和法院处理结果判断。

对普通买房人来说，先记住一点就够了：**不要抱着“看错了就损失一笔保证金”的心态试拍。**

## 06｜发现房子真有问题，也只能认了吗？

不是。

“我改变主意了”和“拍卖存在依法可以提出异议的问题”，不能混为一谈。

例如，网络司法拍卖规定第三十一条，对财产说明存在严重失实、导致买受人产生重大误解且购买目的无法实现等情形，规定了相应的撤销拍卖救济条件，同时也设置了例外。

但并不是发现任何瑕疵，都可以不付尾款、要求退还保证金。已经披露的风险、具体失实程度、证据情况，都需要核查。

遇到实质争议，应及时保存公告、照片、看样记录及沟通材料，通过执行异议等合法途径提出主张，必要时咨询专业律师。不要把自行拒付当成解决争议的办法。

## 07｜给成都参拍人的一张出价前清单

不用把每条规则都背下来，但这五项不能省：

**第一，看清买的是什么。** 是整套房还是份额？权属、占用、租赁、交付情况是否核实？不要只看房源汇总表。

**第二，记下付款期限。** 按该标的公告核对账户、截止时间和付款要求，提前处理转账限额等实际问题。

**第三，核实融资安排。** 需要贷款的，参拍前了解具体要求和办理流程，留出时间与资金余量。

**第四，算全支出。** 成交价之外，把经核实需承担的税费、其他费用及必要的后续支出纳入预算。

**第五，写下最高出价。** 这个数字应由可承受的总预算倒推，不要在竞价倒计时里临时上调。

法拍房可以认真研究，但不能靠“先拍下来再说”作决定。

**拍之前多核实一次，往往比拍之后再找补救办法更有用。**
