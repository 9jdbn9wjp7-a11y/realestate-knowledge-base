# 不良资产拿包的胜负手：估值建模与 IRR 测算

      在不良资产批量收购的全流程里，估值建模、IRR 测算，是承上启下的关键一环。尽调摸清底层资产信息之后，所有信息最终都要装进模型，转化成报价上限、收益预判、风险边界。 它不是简单算一笔账，而是把抵押物价值、回款节奏、处置周期、各项成本、资金成本全部量化，推演项目在不同环境下的收益表现，是我们拿包谈判、竞价的底层依据。

# 一、先搞懂：不良资产 IRR 到底是什么？

      IRR，也就是内部收益率，简单理解：在这个收益率水平下，整个项目所有现金流入、流出折现之后，净现值刚好等于 0。 和大家平时看的 “回收率” 有本质区别：

      回收率只看：一共能收回多少钱；

      IRR 同时看两件事：能收回多少钱 + 什么时候收回来。

      不良行业有一句很实在的话：回款早一个月，IRR 上一个台阶；回款拖一年，再好的回收率也可能变成亏本项目。 同样回收总额 1000 万，1 年全部回款和 3 年才慢慢回款，算出来的 IRR 完全是两个项目。这也是为什么现在行业越来越看重现金流时间分布，而不是单纯盯着抵押物评估价。

# 二、一套实用估值模型，里面要装哪些要素？

      很多新手建模，只录入债权本金、抵押物评估价，很容易踩坑。一套能落地的不良估值表，现金流要分【现金流出】和【现金流入】，再叠加多情景假设。 ✅ 现金流出（前期投入，也就是成本端）

1.  资产包收购价款（竞价核心变量）

2.  资金成本：配资利息、过桥成本、自有资金机会成本

3.  处置全周期费用：尽调费、律师费、诉讼费、保全费、评估拍卖费、税费、委外催收服务费、资产维护费

4.  隐性预留成本：腾退清场成本、异议应诉成本、逾期滞纳金、保管费用

✅ 现金流入（回款端，最考验尽调功底） 按照处置路径拆分每一笔回款的时间节点：

1.  协商和解回款：债务人分期、一次性清偿；

2.  抵押物司法拍卖、变卖回款；

3.  保证人财产执行回款；

4.  破产程序分配受偿款；

5.  以物抵债之后资产再出租、二次处置变现。

> 重点提醒：抵押物评估价≠可回款金额。评估价是市场参考价，法拍通常存在折价；叠加长期租约、居住权、占用、轮候查封、税费负担，最后到手的净回款，往往比评估值低不少，这是建模最容易高估的地方。

# 三、行业通用做法：三情景测算

      成熟的资管机构，不会只做一套基准方案，一般同步做三套情景，设置报价安全垫：

基准情景（中性）：尽调判断最有可能发生的情况，按常规处置周期、正常法拍折价、合理和解比例测算，作为目标 IRR 的参考；

乐观情景：债务人主动和解、拍卖溢价、处置提速，IRR 上行；

压力情景（保守版）：拍卖流拍、案外人异议、债务人失联、诉讼周期拉长、催收监管收紧回款不及预期。

      我们的报价上限，不能用乐观情景去出价，一般以压力情景下依然能守住底线 IRR 作为出价红线。 举个简单例子： 一个对公抵押债权包，中性情景 IRR16%，压力情景 IRR 只有 7%。如果公司资金成本 6%，那么出价就要非常谨慎，一旦处置延期，项目收益直接击穿成本线。

      放到现在的个贷不良市场就更明显：未诉资产占比持续走高、催收监管趋严，回款不确定性大幅上升。建模的时候，就要主动下调回款预期、拉长回收周期，不能沿用几年前宽松环境下的回收假设。

# 四、建模测算里，常见的几个误区

1.  误区一：用抵押物价值倒推收购价 很多人习惯：抵押值打个折就是报价。忽略时间成本、资金利息、诉讼周期、税费，看着折扣很低，持有两三年之后一算账，IRR 极低甚至亏损。

2.  误区二：只算总回收率，不分回款时间 把所有回款全部放在到期那一年，模型 IRR 虚高，是新手最常见的 “纸面收益陷阱”。

3.  误区三：成本漏项，忽略隐性支出 清场、异议诉讼、多次拍卖降价、坏账核销的税费成本，这些零散费用累加起来，会显著侵蚀利润。

4.  误区四：一套假设套用所有资产包 抵押类债权、纯信用个贷、破产类债权的回收规律完全不同，个贷包单笔分散、回款慢、单户处置成本高，对公抵押包周期长但回款确定性更强，参数不能通用。

# 五、估值模型，最终怎么指导拿包决策？

      模型输出结果，核心服务两件事： 第一，算出最高可接受报价上限。在银登挂牌、AMC 竞价的时候，心里有明确红线，不盲目跟风抢包，避免高价接盘； 第二，提前预设处置策略。如果模型显示，靠拍卖回款 IRR 很低，那这个包后续就要优先走和解、债转股、盘活运营，而不是坐等司法拍卖。 这也是我们前面提到的：现在不良行业，单纯债权收购模式变少，综合纾困、价值重塑成为主流，估值模型也要同步适配多元化退出路径。

# 六、结语

      估值建模和 IRR 测算，本质上是把尽调发现的风险，提前量化进价格里。模型不是预测工具，而是风险管理工具。再好的模型，底层是尽调的真实性；假设越贴近现实，测算结果越有指导意义。

> 风险提示：本文仅为不良资产投前测算逻辑分享，不构成任何投资、报价建议。资产包实际回款受司法环境、监管政策、债务人履约情况多重因素影响，测算结果和实际收益存在不确定性。
