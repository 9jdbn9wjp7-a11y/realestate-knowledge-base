# 南京法拍房到底能不能买？新手必看这 3 条

后台天天有人问：南京这套法拍房比二手房便宜近一百万，能不能冲？我每次都替他们捏把汗。
便宜是用信息差换来的。新手只盯低价，很容易踩进四个大坑。最要命的是户口和腾退。房子拍下来却落不了户，孩子照样上不了对口学校。原房主拒不迁出，新房主根本没法强制。要是公告里没写“法院负责腾退”，里面还住着老人或租客，你拍下了也拿不到房。
还有两个坑藏在暗处。按“买卖不破租赁”原则，拍卖前签的合法长租约，产权换了依然有效。买家可能只能干等。更扎心的是税费和欠费。过户税、物业费、水电费全得买方兜底。算下来，总成本可能比二手房还高。
所以参拍前必须死守四条底线。不查清欠费不拍，不看样不拍，不核实腾退不拍，不算清总成本不拍。任何一条没做到，就别交保证金。省下的钱根本不够填一个坑。
房子是拿来住的，不是拿来赌的。
