# 法拍房避坑指南
> 公众号: 南宁好房-艳妮
> 发布时间: 2026年11月5日 12:37

法拍房最大的诱惑是“七折起拍”，但司法拍卖不是普通网购，法院按“现状拍卖”，成交后没有七天无理由退货。便宜的那部分，本质是在给你承担的信息差和风险折价。想安全入手，必须把功课做在举牌之前。

一、先读公告，再谈捡漏

拍卖公告、竞买须知、标的物调查表是核心文件，逐字看这几点：

起拍价、保证金比例（通常5%–20%）、尾款期限（一般7–15天）

产权状态：是否商品房、有无房产证、是否划拨土地、有无轮候查封

占有情况：空置 / 自住 / 出租 / 带居住权

税费承担：“各自负担”还是“全部由买受人承担”

是否限购、能否贷款、是否腾空交付

法院自2024年最高法新规后，原则上负责腾退交付，不得在公告写“不负责腾退”；但带真实租约、带居住权的，仍可能短期住不进去。

二、实地看样：比买二手房重要10倍

别只看平台照片和视频。

去现场看房屋质量：漏水、裂缝、违建、装修损坏

敲门确认占用：空置最理想；有人住要问清是被执行人还是租客、老人小孩在不在

走访物业和邻居：查欠费、查历史、查原房主态度

查产权查册：去不动产中心查抵押、查封、共有权人、居住权登记

公告写“未腾空”“带租拍卖”的，谨慎碰；遇到老人独居、恶意占用的，腾退周期可能以年计。

三、租约与占用：买卖不破租赁

这是法拍房最经典的坑。

查封前形成的真实租约：受“买卖不破租赁”保护，拍下也得住不进去，直到租期结束

查封后突击签的长租、一次性付大额定金：可请求法院审查虚假租赁，但打官司要时间

居住权登记：一经登记，同样对抗新房主

判断租约真假看四点：签订时间、是否早于查封、租金是否真实支付、是否实际入住。

四、算清隐性账单：成交价≠总成本

拍前必须做一张总账表：

拍卖成交价

买方契税（首套1%–1.5%，二套1%–2%，三套3%）

卖方税费（若公告写“买方包揽”：增值税满2免、不满2约3%；个税差额20%或核定1%–3%）

土地收益金（划拨地、经适房可能要补，金额不小）

欠费：物业、水电、燃气、供暖、网费、维修基金

腾退成本：诉讼费、清场协调、重新装修

很多“七折房”把税费欠费加进去，实际只比市场价便宜5%–10%，甚至倒挂。

五、贷款与资金：别让尾款卡死你

法拍房多数要求短期付清全款

商业“法拍贷”可提前预审，但必须拍前锁定银行额度与放款节点

公积金贷款仅部分城市试点，别默认能用

保证金拍前24–48小时缴清，成交后转房款；悔拍不退，重拍差价还要你补

举牌前设心理底价：成交价+税费欠费 ≤ 同小区市场价×0.85，才值得举。

六、户口与学位：法院不负责迁出

法院只办产权过户，不迁户口。

拍前带房产证号去派出所查：原户主是否占用、有几个户口

买学区房再去教育局查：学位是否被占用、占用到哪一年

原户主不迁出，你可申请单独立户，但落户和入学资格仍可能受影响

七、悔拍代价：不是退钱那么简单

成交后不付款或逾期：

保证金全额没收

重新拍卖价更低，原买受人补差价

列入限制参拍名单

杭州2026年已有多起悔拍，单笔保证金罚没最高250万，别拿举牌当游戏。

八、普通家庭实操清单

拍前7步：

查购房资格（限购城市先确认）

读公告+调查表，标出所有“瑕疵”

实地看样+物业欠费查询

不动产查册（抵押/查封/居住权）

派出所查户口、教育局查学位

银行预审法拍贷，备好全款备用金

算总账，设心理底价

拍后流程：

付尾款 → 领成交裁定+协助执行通知书 → 解封解押 → 缴税过户 → 申请腾退（如需）→ 收房

九、哪些标的最好别碰

看不到实景、不组织看样

公告写“占有不明”或疑似的虚假占用

长租约+已付多年租金

小产权、划拨地没算补缴金

产权共有人有异议

原房主涉黑、涉赌、情绪对抗

法拍房不是不能买，它是“专业选手市场”。自住买家想试水，记住一句话：宁可错过十套漏，别踩一套雷。

我是艳妮，懂房更懂风险账。

低价只是表象，尽调才是底价。
