## 二、活动框架通用公式（福彩/体彩）

四份方案虽品牌不同，但底层框架高度一致，可归纳为 **「三段式 + 五板块」通用公式**：

### 2.1 时间轴（三段式）

```
预热期（5-10天） → 引爆期（活动日） → 续热期（5-7天）
```

| 阶段 | 典型动作 |
|------|---------|
| **预热期** | ① 话题制造（微博/小红书话题 + KOL/KOC 引流）② 倒计时海报/快闪视频 ③ 线上 H5 游戏提前上线积攒用户 ④ 官媒+朋友圈广告投放 ⑤ 悬念内容（空降神秘嘉宾/巨型装置预告） |
| **引爆期** | ① 快闪店/路演现场开放 ② 舞台表演+抽奖互动 ③ 通关打卡+彩票售卖 ④ 直播/网红到场 ⑤ 拍照打卡社交裂变 |
| **续热期** | ① 官媒收官视频 ② KOL/KOC 发帖 ③ 社群持续运营 ④ 媒体新闻稿后期报道 |

### 2.2 空间轴（五板块，福彩体彩共用）

```
主舞台区 + 互动游戏区 + 彩票售卖区 + 打卡传播区 + 公益展示区
```

| 板块 | 福彩侧重 | 体彩侧重 |
|------|---------|---------|
| **主舞台** | 公益宣讲/启动仪式/抽奖 | 团体操课/AR体感游戏/网红直播 |
| **互动游戏** | 闯关集章制（游园式） | 打卡完成兑奖（关卡式） |
| **彩票售卖** | 自助机+人工，捆绑公益叙事 | 突出产品（大乐透/七星彩/即开） |
| **打卡传播** | 巨型装置+心愿墙+拍照道具 | DP点装置+网红墙+吉祥物 |
| **公益展示** | 公益金透明展示+肝病防治联动 | 公益行为展示+体育正能量 |

## 四、品牌调性关键差异：福彩 vs 体彩

虽然框架相似，但两品牌在调性和叙事上有本质差异。对上海福彩投标至关重要——**方案可以借鉴体彩的玩法模块，但不能照搬体彩的调性**。

| 维度 | 福彩 | 体彩 |
|------|------|------|
| **核心叙事** | 「公益」是主语：扶老/助残/救孤/济困 | 「运动/活力」是主语：体育精神、全民健身 |
| **情感基调** | 温暖、治愈、责任（心愿墙、肝炎日联动） | 刺激、好玩、年轻（大乐透送福利、魔性视频） |
| **色彩语言** | 红色+蓝色（双色球色），温暖治愈 | 多色活泼（乐小星七彩），运动潮流 |
| **IP 策略** | 弱 IP（emoji 表情叠加双色球） | 强 IP（乐小星吉祥物全场景贯穿） |
| **公益表达** | 直接：公益金成果展板 + 联动社会议题（肝炎） | 间接：运动能量收集 → 公益行为 → 正能量 |
| **产品露出** | 低调：刮刮乐/快乐8融入游戏 | 高调：大乐透/七星彩/顶呱刮全产品线 |

> ⚠️ **对上海福彩投标的警示**：方案中绝不能出现「体育精神」「健身」「运动闯关」等体彩调性的表达，应走「公益温暖 + 国潮文化 + 年轻治愈」的福彩路线。但南昌体彩的关卡式体验、衍生品抓取等**玩法模块**可二次创作嫁接。

## 五、对上海福彩项目的直接借鉴点

### 5.1 可直接复用的福彩玩法（已验证）

1. **闯关集章制**（襄阳福彩 → 上海低档/中档）
   - 寻"福"记通关卡：打卡 4-5 个点 → 全部盖章 → 兑刮刮乐
   - 低成本、高参与度、适合 200㎡ 室内动线

2. **emoji × 双色球视觉**（湖南福彩 → 上海高档国潮化改造）
   - 原版偏青春潮流，上海版可改造为「国潮表情×双色球」
   - 巨型彩票 + 夜间投影互动可嫁接为「唐韵祈福灯」

3. **公益视听间 · 不一 YOUNG 盲盒**（湖南福彩 → 上海高档）
   - 用声音/文字传递公益历史 → 上海版改造为「国潮公益故事阁」
   - 扫码听福彩公益故事，每个「盲盒」版本不同

4. **福气投注区+「彩民名义捐助」**（湖南福彩 → 三套通用）
   - 活动期间累积购买金额以所有彩民名义捐助指定公益项目
   - 强化「每个人都在做公益」的叙事

### 5.2 可二次创作嫁接的体彩模块

5. **衍生品抓取机**（南昌体彩 → 上海中档/高档）
   - 完成通关 → 领游戏币 → 抓娃娃机抓取文创 IP 礼品
   - 改造要点：去掉乐小星 IP，用上海福彩自有 IP 礼品

6. **AR 体感追踪小游戏**（南昌体彩 → 上海高档）
   - 原版运动主题 → 改造为「国潮好运追踪」（接福气/避晦气）
   - 需开发但冲高分值（创意 + 技术亮点）

7. **交通枢纽 DP 打卡点**（重庆体彩 → 上海多场景延展）
   - 原版机场/高铁站 → 可改造为徐汇地铁站/商圈入口的快闪打卡点
   - 兼顾「5 家福彩网点配套」的标书要求

### 5.3 传播层面的借鉴

8. **线上 H5 游戏提前上线预热**（重庆体彩/南昌体彩 → 上海通用）
   - 体彩用「摇一摇/乐透大作战」→ 上海改造为「双色球祈福/国潮闯关」H5
   - 游戏积分 → 到现场兑换礼品，线上线下闭环

9. **KOL/KOC 现场参与 + 话题发起**（南昌体彩 → 上海通用）
   - 邀请本地 KOL 到场打卡 + 带话题发帖
   - 统一规划好转发内容（H5/短视频），扫码一键转发不依赖自主编辑

### 5.4 执行管理层面的借鉴

10. **《活动执行手册》+ 岗位职责说明书**（南昌体彩 → 上海高档）
    - 南昌方案人员管理非常细致：甄选→培训→彩排→执行→考核五步
    - 上海投标可参考做人员保障章节，对冲「应急预案 10 分」
